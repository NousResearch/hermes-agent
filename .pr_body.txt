## Summary

Adds **hermes-lossless-context-manager** as a community plugin in the catalog.

Lossless Context Management is a SQLite-backed DAG context engine that never loses a message — even after compression. It exposes 15 retrieval tools and 3 hooks via the plugin interface, giving Hermes agents full drill-down capability through compressed context histories.

### Why the Catalog Needs This

hermes-lossless-context-manager is a well-established, actively maintained community plugin that solves a real problem: context loss during compression. Agents routinely lose message history when the context window compresses. hermes-lcm preserves every message in a SQLite store organized as a directed acyclic graph, enabling full reconstruction after compression.
