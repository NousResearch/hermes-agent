# Hermes Agent ☤ — راهنمای فارسی

**عامل هوش مصنوعی خودبهبوددهنده ساخت [Nous Research](https://nousresearch.com).** عاملی که از تجربه مهارت می‌سازد، حافظه دارد، گفتگوهای گذشته خود را جستجو می‌کند و با هر نشست شناخت عمیق‌تری از شما پیدا می‌کند. روی یک VPS پنج‌دلاری، کلاستر GPU یا زیرساخت بدون‌سرور اجرا کنید — و از ترمینال، داشبورد وب، برنامه دسکتاپ، Telegram، Discord، Slack، WhatsApp و Signal با آن گفتگو کنید.

> این سند راهنمای کاربری فارسی است. مرجع کامل، [README اصلی](README.md) و [مستندات رسمی](https://hermes-agent.nousresearch.com/docs/) است.

## ۱) نصب

### لینوکس، macOS، WSL2 و Termux

```bash
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
```

### ویندوز (PowerShell بومی)

```powershell
iex (irm https://hermes-agent.nousresearch.com/install.ps1)
```

نصب‌کننده همه پیش‌نیازها را خودکار نصب می‌کند: `uv`، Python 3.11، Node.js، ripgrep، ffmpeg و (روی ویندوز) یک Git Bash قابل‌حمل.

پس از نصب:

```bash
source ~/.bashrc   # یا: source ~/.zshrc
hermes             # شروع گفتگو!
```

## ۲) راه‌اندازی اولیه

سریع‌ترین مسیر، اشتراک [Nous Portal](https://portal.nousresearch.com) است که مدل، جستجوی وب، تولید تصویر، TTS و مرورگر ابری را زیر یک اشتراک پوشش می‌دهد:

```bash
hermes setup --portal    # ورود با OAuth + پیکربندی کامل
```

اگر ترجیح می‌دهید کلیدهای API جداگانه بگیرید، جادوگر کامل را اجرا کنید:

```bash
hermes setup             # پیکربندی گام‌به‌گام همه چیز
hermes model             # انتخاب ارائه‌دهنده و مدل
hermes tools             # انتخاب ابزارهای فعال
hermes doctor            # بررسی سلامت نصب
```

## ۳) فارسی‌سازی رابط

از این نسخه، پیام‌های ثابت رابط (پرش‌های تأیید دستور خطرناک، پاسخ‌های دستورهای اسلش مانند `/model`، `/usage`، `/context`، `/resume` و بقیه) از جمله **فارسی** پشتیبانی می‌کنند.

### روش ۱ — متغیر محیطی (سریع‌ترین)

```bash
export HERMES_LANGUAGE=fa
hermes
```

### روش ۲ — فایل پیکربندی (دائمی)

در `~/.hermes/config.yaml`:

```yaml
display:
  language: fa
```

یا با یک دستور:

```bash
hermes config set display.language fa
```

### روش ۳ — داخل گفتگو

پس از تنظیم، پاسخ‌های دستورهای اسلش و پرش‌های تأیید به فارسی نمایش داده می‌شوند. نمونه:

```
⚠️  دستور خطرناک: rm -rf /tmp/build
      [o] یک‌بار  |  [s] این نشست  |  [a] همیشه  |  [d] رد
      انتخاب [o/s/a/D]:
```

> **نکته:** نام دستورها، کلیدهای پیکربندی، مسیرها و شناسه مدل‌ها عمداً به همان شکل استاندارد باقی می‌مانند تا سازگاری با مستندات و اسکریپت‌ها حفظ شود. خروجی تولیدی خودِ عامل (پاسخ‌های مدل) به زبانی که با آن حرف بزنید پاسخ می‌دهد — اگر فارسی بنویسید، فارسی جواب می‌گیرید.

## ۴) داشبورد وب و برنامه دسکتاپ

### داشبورد وب

```bash
hermes web --no-open        # سرور API روی پورت 9119
cd web && npm install && npm run dev   # رابط توسعه Vite روی 5173
```

زبان را از **انتخابگر زبان** پایین نوار کناری عوض کنید — گزینه **فارسی** را برگزینید. کل رابط راست‌به‌چپ (RTL) می‌شود: نشست‌ها، تحلیل‌ها، پیکربندی، کلیدها، گزارش‌ها، cron، پروفایل‌ها، افزونه‌ها و مهارت‌ها.

### برنامه دسکتاپ

در تنظیمات برنامه دسکتاپ، بخش **زبان**، گزینه **فارسی** را انتخاب کنید. جهت چیدمان به‌صورت خودکار RTL می‌شود و تنظیم روی `~/.hermes/config.yaml` نیز ذخیره می‌گردد.

## ۵) استفاده روزمره از CLI

```bash
hermes                      # شروع گفتگوی تعاملی
```

دستورهای پرکاربرد داخل گفتگو:

| دستور | کار |
|---|---|
| `/new` یا `/reset` | شروع گفتگوی تازه |
| `/model <name>` | تغییر مدل (با `--global` دائمی می‌شود) |
| `/usage` | مصرف توکن و هزینه این نشست |
| `/context` | وضعیت پنجره زمینه |
| `/compress` | فشرده‌سازی گفتگوی طولانی |
| `/resume <name>` | بازگشت به نشست ذخیره‌شده |
| `/skills` | فهرست مهارت‌ها |
| `/undo` / `/retry` | بازگشت یا تکرار آخرین نوبت |
| `/bg <prompt>` | اجرای وظیفه در پس‌زمینه |
| `/btw <question>` | پرسش جانبی بدون قطع کار جاری |
| `/goal <objective>` | تعیین هدف با سقف نوبت |
| `/voice on` | پاسخ صوتی به پیام‌های صوتی |
| `/help` | فهرست کامل دستورها |

وقتی Hermes بخواهد دستوری خطرناک اجرا کند، پرش تأیید فارسی نمایش داده می‌شود؛ با `o` (یک‌بار)، `s` (این نشست)، `a` (همیشه) یا `d` (رد) پاسخ دهید.

## ۶) اتصال به پیام‌رسان‌ها

دروازه (Gateway) به Hermes اجازه می‌دهد از Telegram، Discord، Slack، WhatsApp، Signal و ایمیل در دسترس باشد:

```bash
hermes gateway setup    # پیکربندی پلتفرم‌ها
hermes gateway start    # اجرای دروازه
```

همه پاسخ‌های دستورهای اسلش در پیام‌رسان‌ها نیز از کاتالوگ فارسی پیروی می‌کنند (همان `display.language`).

## ۷) وظایف زمان‌بندی‌شده

```bash
hermes cron list
hermes cron add --schedule "0 9 * * *" --prompt "خلاصه اخبار دیروز را بده"
```

یا از تب **وظایف زمان‌بندی‌شده** در داشبورد وب. خروجی به پلتفرم دلخواه (محلی، Telegram، Discord، Slack، ایمیل) تحویل داده می‌شود.

## ۸) مهارت‌ها، حافظه و پروفایل‌ها

- **مهارت‌ها** در `~/.hermes/skills/` زندگی می‌کنند؛ Hermes پس از وظایف پیچیده خودش مهارت جدید می‌سازد و در طول استفاده بهبودش می‌دهد. مدیریت: `hermes skills`.
- **حافظه**: `hermes memory status` — حافظه پایدار، جستجوی گفتگوهای گذشته و نمای کاربر.
- **پروفایل‌ها**: چند شخصیت/محیط جدا (مثلاً `coder`، `writer`) با مدل، کلید و حافظه مستقل:

```bash
hermes profile list
hermes profile create coder
```

## ۹) امنیت و تأیید دستورها

- دستورهای خطرناک همیشه پیش از اجرا تأیید می‌گیرند (پرش فارسی).
- حالت‌های تأیید: یک‌بار / این نشست / همیشه / رد — و فهرست سفید دائمی.
- **YOLO** (`/yolo`) تأیید خودکار را روشن می‌کند؛ فقط در محیط ایزوله استفاده کنید.
- جزئیات کامل: [مستندات امنیت](https://hermes-agent.nousresearch.com/docs/user-guide/security).

## ۱۰) عیب‌یابی

| مشکل | راه‌حل |
|---|---|
| متن فارسی به‌هم‌ریخته در ترمینال | فونت ترمینال را به یکی از فونت‌های پشتیبان RTL تغییر دهید (مثلاً Vazirmatn، JetBrains Mono). |
| فارسی اعمال نشد | `hermes config get display.language` را بررسی کنید؛ مقدار باید `fa` باشد. متغیر `HERMES_LANGUAGE` بر config اولویت دارد. |
| برخی پیام‌ها هنوز انگلیسی‌اند | خروجی تولیدی عامل و لاگ‌ها عمداً انگلیسی می‌مانند (به «محدوده ترجمه» در `agent/i18n.py` توجه کنید). |
| خطای کلی | `hermes doctor` را اجرا کنید. |
| به‌روزرسانی | `hermes update` |
