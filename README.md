# Hermes Execution Router API

This project follows Hermes Project Standard v2.

Canonical product work lives in `specs/<version-feature>/spec.md`, `plan.md`, and `tasks.md`.

Execution discipline (Feature 006): after the three canonical artifacts are ACCEPTED,
the task map is the sole execution route; only the user adds scope; tests must cite
described behavior or a cited material risk; a Ponytail pass is valid only with a
removal list plus requirement/component/risk mapping of everything retained.
