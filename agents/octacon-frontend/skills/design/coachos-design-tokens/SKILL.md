# CoachOS Design Tokens

## Brand colors
- **Primary Green:** `#2D6A4F` — accents, CTAs, headers
- **Light Green:** `#52B788` — secondary accents, highlights
- **Pale Green:** `#D8F3DC` — subtle backgrounds, dividers
- **Dark Background:** `#1A1A1A` — main backgrounds
- **Mid Background:** `#2A2A2A` — cards, containers
- **Light Text:** `#E8E8E8` — body text
- **Muted Text:** `#9CA3AF` — captions, metadata
- **White:** `#FFFFFF` — on green CTAs

## Typography
- **Family:** System font (SF Pro on iOS, Roboto on Android)
- **Headings:** Bold, 22-30px — editorial-style, spacious
- **Subheadings:** Semibold, 16-18px
- **Body:** Regular, 14-16px, high leading (1.6)
- **Caption:** Regular, 11-13px
- **Drill/formation labels:** Bold, 12px, uppercase tracking 0.5px

## Spacing
- **XS:** 4px
- **SM:** 8px
- **MD:** 16px
- **LG:** 24px
- **XL:** 32px
- **2XL:** 48px

## Border radius
- **SM:** 4px (drill cards, small elements)
- **MD:** 8px (formation cards, player cards)
- **LG:** 12px (session cards, modals)

## Elevation
- **Card shadow:** 0px 1px 4px rgba(0,0,0,0.3)
- **Sheet shadow:** 0px -4px 16px rgba(0,0,0,0.4)

## Iconography
- Filled icons, 20px default
- Color: Light Text `#E8E8E8` default, Primary Green `#2D6A4F` for active states
- Football-specific icons: pitch, cone, bib, whistle, ball, stopwatch

## Editorial design principles
- Generous whitespace — content needs room to breathe
- Bold typographic hierarchy — headings as design elements
- Near-monochrome palette — green is the only accent, used sparingly
- Photographic elements preferred over illustrations where possible
- Session/formation views are information-dense but visually clear
- Mobile-first, touch-friendly (minimum 44x44 tap targets)
