# Dezzy Design Systems

A curated reference library of real-world design systems. Not copy-paste — understand the design principles, token structures, and visual languages, then apply the insights to KENSEI's brand work.

## When This Skill Activates

- "What can we learn from Stripe's design?"
- "How does Linear handle dark mode?"
- "Show me Vercel's typography system"
- "Research design patterns for our dashboard"
- "/dezzy-design-systems"

## Reference Architecture

Each design system entry includes:
- **Palette** — 8-12 core colours with hex values and usage
- **Typography** — font choices, scale, weights, line-heights
- **Spacing** — grid system, padding conventions, gap patterns
- **Component highlights** — what makes their buttons/forms/cards distinctive
- **Key takeaway** — one thing KENSEI can learn from this system

## What to Look For

| Aspect | Questions |
|--------|----------|
| Colour | How many shades per hue? How is accent used? |
| Typography | Font pairing strategy? Scale increments? |
| Layout | Grid columns? Max content width? Breakpoints? |
| Elevation | When do they use shadows? Card vs modal depth? |
| Motion | Duration patterns? Easing curves? Scroll vs hover? |
| Form | Input styles, validation, error patterns, button hierarchy |

## Application to KENSEI Brands

- **Plenishd** — reference kitchen/productivity apps (clean, warm, high-contrast)
- **CoachOS** — reference sports/editorial sites (bold, typographic, minimal)
- **MatchdayMaestro** — reference entertainment/gaming (vibrant, dense, interactive)
- **Kick-tionary** — reference education/tools (simple, accessible, icon-driven)

## Verification

- Each reference has a concrete "what KENSEI can use" section
- Insights are specific — not "good colours" but "their 4-shade accent system reduces decision fatigue"
- Don't reproduce the design — explain the pattern

## Pitfalls

- Don't copy — extract the thinking, not the CSS
- Don't overload — pick the 3 best references for the current task
- Don't use proprietary brand assets — discuss patterns only
