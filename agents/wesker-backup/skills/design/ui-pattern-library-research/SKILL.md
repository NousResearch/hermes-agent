# UI Pattern Library Research

## Overview

Use this skill to research modern UI patterns and convert inspiration into implementable product specs for Sahil's apps.

## When to Use

- Designing new screens or components.
- Looking for modern UI inspiration.
- Comparing interaction patterns.
- Translating design references into mobile specs.

## Primary Sources

Use where relevant:

- `21st.dev`
- `styleui.dev`
- `shadcn/ui`
- `nextlevelbuilder/ui-ux-pro-max-skill`
- `VoltAgent/awesome-design-md`
- `DovAmir/awesome-design-patterns`
- local `/home/kensei/TeardownSkill.md` via `site-teardown`

## Research Method

1. Define the product context and user job.
2. Identify relevant pattern category: navigation, onboarding, cards, forms, dashboards, empty states, gamification, search, settings, content feed.
3. Collect 3 to 7 strong references.
4. Extract reusable principles, not copy-paste aesthetics.
5. Map patterns to Sahil's app brand tokens.
6. Produce an implementable spec for Coding Lead.

## Output Contract

```text
Pattern needed:
Product context:
References checked:
Useful patterns:
What to avoid:
Recommended pattern:
Brand adaptation:
Implementation notes:
```

## Pitfalls

- Do not recommend web-only interactions for mobile without adaptation.
- Do not copy visual style that conflicts with app brand.
- Do not use inspiration as a substitute for solving the user job.
- Do not ignore accessibility.

## Verification Checklist

- [ ] References are relevant.
- [ ] Pattern fits mobile if app work.
- [ ] Brand adaptation is explicit.
- [ ] Implementation notes are clear.
- [ ] Accessibility considered.
