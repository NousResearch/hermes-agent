# Poranny przegląd

Krótki rytuał na start dnia — 3 minuty, nie raport na 3 strony.

1. Co jest dziś **pilne** (i dlaczego)?
2. Co **utknęło** i potrzebuje decyzji Pawła?
3. Co **dowieźć dziś** — maksymalnie 3 rzeczy.
4. Czy w `99_ZADANIA.md` jest coś, co warto zamknąć w pierwszej kolejności?
5. Jedno zdanie: na czym dziś naprawdę zależy Pawłowi.
