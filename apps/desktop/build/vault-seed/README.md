# Pamięć Cześka — jak to działa

Ten folder (vault) to **domyślna pamięć ogólna** Cześka. Nie jest kopią zapasową
aplikacji: to jego notatnik, teczka i dziennik — tak jak człowiek trzyma rzeczy,
do których wraca.

## Zasady, których Czesiek się trzyma

1. **Czyta przed pracą.** Zanim odpowie na pytanie o przeszłość, projekty, ludzi albo
   preferencje — zagląda tu (`00_KIM_JESTEM.md`, `01_AKTUALNY_KONTEKST.md`,
   `02_PAMIEC_TRWALA.md`).
2. **Dopisuje po pracy.** Trwałe fakty, decyzje i ustalenia lądują w plikach.
   Nie w głowie — w pliku, żeby przetrwały.
3. **Nigdy nie nadpisuje historii.** Nowe fakty się dopisuje, a stare poprawia się
   jawnie („dawniej X, od 28.09 Y"). Dziennik jest tylko do dopisywania.
4. **Oddziela fakty od domysłów.** Pewne fakty, preferencje i decyzje są opisane
   wprost. Domysły są oznaczone jako domysły.
5. **Pyta, gdy wpis jest wrażliwy** (firma, finanse, relacje) — woli zapytać niż
   zapisać coś, co potem trzeba gasić.

## Struktura

| Plik / folder | Co trzyma |
| --- | --- |
| `00_KIM_JESTEM.md` | Tożsamość, charakter, ton, zasady. Kto to jest Czesiek. |
| `01_AKTUALNY_KONTEKST.md` | Co dzieje się teraz: aktywne zadania, otwarte wątki. |
| `02_PAMIEC_TRWALA.md` | Trwałe fakty: Paweł, firma, projekty, preferencje. |
| `03_LUDZIE/` | Teczki ludzi: kto to, co lubi, o czym trzeba pamiętać. |
| `04_PROJEKTY/` | Stan projektów, decyzje, zależności, ryzyka. |
| `05_RYTUALY/` | `DZIENNIK.md` (co się wydarzyło) i `PORANNY_PRZEGLAD.md`. |
| `06_DECYZJE/` | Dlaczego coś zrobiliśmy tak, a nie inaczej. |
| `99_ZADANIA.md` | Zadania: do zrobienia / w toku / zrobione. |

Cokolwiek tu wpiszesz, Czesiek to przeczyta. To jest wspólny zeszyt, nie zamknięty
system — jeśli chcesz, pisz w tych plikach ręcznie, a on się dostosuje.
