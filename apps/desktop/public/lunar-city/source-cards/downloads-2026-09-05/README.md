# Lunar City source-card archive

This directory preserves the PNG source cards copied from the user's Downloads
folder on 2026-09-05. It is an intake archive, not an approval manifest: the
cards include the 2x2 leader, worker, and building turnarounds plus earlier
variants. The generated GLBs elsewhere in this asset tree remain reference-only
until each model is visually checked against its approved card.

The archive is intentionally kept outside the production asset manifest so
source provenance is preserved without silently promoting an unapproved
variant.
