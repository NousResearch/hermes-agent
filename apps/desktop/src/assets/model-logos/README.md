# Model logo assets

Monochrome SVG marks from [LobeHub Icons](https://github.com/lobehub/lobe-icons), commit `a94750e3f5f8fc33757b839d85030e742284e43a` (`packages/static-svg/icons/`), under the included MIT license.
Brand names and marks belong to their respective owners; this use identifies the model author, not an endorsement.

Bundled locally and rendered as CSS masks in ModelLogo: no favicon service or runtime network fetch, adaptive currentColor, no native title tooltip or focus target. Unknown model names use the existing neutral CPU icon.
