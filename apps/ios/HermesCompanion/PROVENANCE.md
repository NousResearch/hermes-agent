# Source provenance

This self-contained SwiftUI client uses Hermes HTTP authentication and JSON-RPC
APIs. It has no dependency on another application's source tree or runtime.

The application mark and icon are copied from Hermes Desktop; see README and
HERMES-LICENSE for attribution. No backend source, credentials, signing team,
device identifiers, provisioning profiles or generated build caches are bundled.

Personal installations may maintain a standalone copy. Local deployment receipts
and scheduler identifiers remain outside version control.
