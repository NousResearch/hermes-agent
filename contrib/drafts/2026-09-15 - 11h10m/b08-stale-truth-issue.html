B08 incorporation-status surface on the live site is factually stale (merged batches are shown as unmerged)

Finding ID: E-PROTEUS-070. Severity: HIGH. Type: content accuracy (wording/docs).

Summary

The incorporation-status surface shipped by PR #40 (squash commit ca88fea72130245f9e2d488f3856ae2e30f2a4e7, merged 2026-09-15T14:01:14Z) is serving text that was already false at merge time and is false now on the live public site. The page tells visitors that none of the reviewed batches have merged and that a set of batches is sitting in open pull requests. The repository it links to says the opposite: zero pull requests are open, and most of the batches named on the page are already merged into main.

The wording was accurate when it was authored in the morning (before the batch pull requests merged), but it was stale by the time PR #40 was squash-merged and it is still served in the present tense as current truth. It is a dated snapshot presented as live fact.
