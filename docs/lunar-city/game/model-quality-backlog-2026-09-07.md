# Model-quality repair backlog — 2026-09-07

This is the static-quality work queue for all **36 current designs: 20 workers, eight leaders and eight buildings**. Animation tuning is deferred. The audit only read source cards, saved review images, inventories and projection/bake scripts; it changed no model, image, Blender scene, runtime code or live application. Existing game implementation remains in its separate handoff. No asset is accepted as polished by this document.

P1 means a visible defect must be repaired before static acceptance. P2 means a narrower shape/material polish gap; it is still unfinished. Saved images can predate the newest GLB. Each repair must produce a new, version-specific turnaround before its row is closed.

## Repair the cause before repeating the batch

1. **Repeated artwork is not necessarily repeated geometry.** Core/CI/community roofs show duplicated eyes or beacons; owl/fox/monkey roofs repeat displaced architectural landmarks. Inspect neutral solid, base-color-only and normal-only views to decide whether to edit faces, texture projection or normals. Do not remove a true antenna, tool or roof sign because another painted copy exists.
2. **Projection needs semantic regions and visible-surface registration.** `lunar_project_card_colors.py` samples front/back/left only. Upward normals without a strong facing weight fall back to front/back colors. The separate `lunar_four_view_colors.py` adds top sampling, but both scripts write the same `color-study-v4.json` method/output text. Neither establishes per-part occlusion or landmark registration. Therefore a saved building receipt does not prove which projector produced its colors. Do not label all top defects “PLAN projection.” Record actual producer script/hash, crop hashes, output hash and matching render hashes on the next bake.
3. **Exclude nonphysical drawing content before reconstruction.** Data worker airflow arrows and knowledge worker flashlight beam appear in the model; confirm their solid geometry, then remove annotation/beam artifacts while preserving real vents/lamp. Card annotations, backgrounds and illumination volumes need separate masks from objects.
4. **Repair fused/missing parts before surface polish.** Prioritize elephant tree pods/branches, worker fine probes/clamps/extra arms, and monkey hand/cuff/skirt boundaries. Smoothing and a successful rig stress test cannot create missing negative space or distinct props.
5. **Water is not ground stone.** Building finishing assigns stone to low, nearly horizontal faces (`max vertex Z < 2% height`, `abs normal Z > .85`). This can capture pool/channel faces. Beaver and capybara need explicit water/bed/masonry regions; inspect selected faces to confirm the particular bad assignment.
6. **Preserve fixes and design intent.** Cat studio reconstruction-v2 has removed the old backdrop sheet. Cat leader current rigged front no longer shows historical black belt openings. Rejected leader v5 files remain rejected. Cat building roof lettering and several worker roof badges are authored on the cards; they are not automatically erroneous repetition.

The actual building finishing chain is `source-color-study-v4.glb` → `lunar_bake_asset.py` → `material-review.glb` → `lunar_building_surface_finish.py` → `building-review.glb`. The building batch invokes the latter two; producer identity for the earlier color study is not uniquely encoded. Global washed-out appearance may combine baked shading, lighting, color management and materials; compare under neutral lighting before applying a universal color adjustment.

## Finishing sequence and closure

Start with a single representative projection repair (core worker roof), one appendage repair (CI probes or arts arms), and one building roof repair (fox telescope/skylights). Inspect all angles before applying any automated batch change. In parallel, the elephant tree needs a geometry-specific reconstruction/repair, and beaver water needs explicit material regions. These are different causes and should not share one blanket smoothing or repaint operation.

For each candidate, preserve the original and record the intended part inventory from all four card panels. Resolve ambiguous support/antenna counts explicitly from the card rather than silently deleting parts. Review front, rear, both sides, top and underside in clay and normal materials at a consistent camera/lighting setup; confirm no displaced second faces/tools/roof features, isolated shards, fused intended gaps or contaminated appendages. Recheck selected metre height and base/foot contact after shape edits. Buildings retain their architectural heights; workers must not set building normalization. Keep materials separate for water, glazing, metal, cloth/fur and ground when their behavior differs.

Then save the new GLB, its checksum, matching six-view images and a per-defect closure note. A passing import, skeletal motion, triangle count, edge-stretch metric or game test is technical evidence only. It does not close a static-quality defect. Resume animation refinement after the static candidate passes visual review.
