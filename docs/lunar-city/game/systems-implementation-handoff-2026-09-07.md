# Lunar City operational systems implementation — 2026-09-07

This work fills recovered operational-city gaps. It does not declare the game or its assets production-ready. The complete source-by-source audit and unresolved acceptance conditions are in `comprehensive-systems-gap-matrix-2026-09-07.md`; immutable historical Git links distinguish recovered intent from current authored choices.

## Implemented behavior

- Attention items retain exact owner/entity identity, deduplicate observations, support local acknowledgement, resolve only from fresh healthy evidence, preserve incidents through missing/stale data, and reopen on recurrence. Equivalent text and inspection controls accompany visual badges.
- Worker personalities are explicitly authored city presentation. Configured titles/groups retain provenance; optional SOUL reads use exact connection/profile identity and discard late responses for former owners. Local demo controls cannot call the gateway.
- Nearby resting workers can exchange actual imported talk/listen gestures with mutual facing and a finite greeting/exchange/farewell sequence. Selection exposes gesture/greeting controls and exact observed delegation relationships. Work, movement, removal, stale authority, reduced motion and efficient quality cancel ambient behavior. Hidden UI stops polling; idle lists avoid unnecessary React commits.
- Exact connection/project identities from sessions, delegated children and Kanban records receive stable physical site signs and source-record counts. Two review sites are surveyed; overflow remains explicit and retains inspectable identities. A project's existence does not reroute resting workers out of the garden.
- Parent/child travel and finite handoff/completion lines require exact observed relationships. An actual supported finite completion clip takes precedence; a newly observed completion may use a short imported handoff/celebrate fallback when needed. Neither creates an artifact, receipt, task success or backend message.
- Existing imported building prop clips respond to authoritative observed activity, with work/alerts ahead of garden/bus decoration. Actual settled arrivals can trigger the imported triage door once. Playback stops for stale data, reduced motion or disabled decoration. New zero-animation review buildings remain static. The old bus rotation is not presented as transport choreography.
- Runtime SHA-256 verification imports the exact validated bytes through a temporary blob URL. Corrupted declared GLBs fail before import, including the navigation mesh; integrity errors cannot silently select the optional Recast fallback. Missing clips stop safely with diagnostics instead of manufacturing motion.
- Source polling preserves in-progress worker navigation unless the authoritative origin genuinely changes. Arrival positions are stable and bounded by authored approach length; overflow does not manufacture more physical room. Historical worker fixtures now have a runtime-only 1.2m wrapper and grounded pivot across near/mid/far levels; source GLBs and reviewed models are preserved.
- Recovered Electron performance bridge, fixture runner/orchestrator/validator and package scripts integrate with current lifecycle APIs. Their authenticated gateway adapters remain explicitly unavailable until supported ownership/preseed infrastructure exists.
