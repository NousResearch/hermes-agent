North Forge

A brandable AI-agent chassis

One agent engine. Your identity, your voice, your workflow — nothing tied to a single industry.

Built on the Hermes Agent engine by Nous Research, used unmodified. Whatever Hermes does, North Forge does — under a face that's yours.

See a session Source

What it is

An AI agent you can make your own

North Forge is Hermes Agent — the self-improving agent engine by Nous Research — carrying a North Forge identity, voice, and workflow: its own SOUL.md, its own conventions, its own mark. The engine underneath is used unmodified, so the whole learning loop comes with it.

Identity

Yours, not a demo's

A distinct persona, prompt symbol, help header, and a full forge-gold session skin — all inside the documented skin contract, engine untouched.

Learning loop

Sharpens as it works

Curates its own memory, writes skills from experience and improves them in use, and searches its own past sessions for recall.

Reach

Lives where you do

One gateway process bridges Telegram, Discord, Slack, WhatsApp, Signal and a real terminal TUI — with voice-memo transcription.

Anywhere

Not tied to a laptop

Seven terminal backends — local, Docker, SSH, Modal, Daytona and more. Idle-cheap serverless persistence; a $5 VPS is plenty.

The session

The forge, lit

The North Forge CLI skin — forge-gold and ember over dark iron — carried through the whole session: banner, prompt, tool lines, response box, spinner and status bar.

Under the face

What the engine brings

All of it, unmodified, under the North Forge identity.

A real terminal

Full TUI: multiline editing, slash-command autocomplete, history, interrupt-and-redirect, streaming tool output.

A closed learning loop

Agent-curated memory with nudges, autonomous skill creation, self-improving skills, FTS5 session search, dialectic user modelling.

Scheduled automations

Built-in cron with delivery to any platform — daily reports, nightly backups, weekly audits, in plain language, unattended.

Delegates and parallelises

Isolated subagents for parallel workstreams; Python that calls tools over RPC, collapsing pipelines into zero-context turns.

Runs anywhere

Seven terminal backends. Daytona and Modal hibernate when idle and wake on demand — near-zero cost between sessions.

Any model

Nous Portal, OpenRouter, OpenAI, your own endpoint. Switch with hermes model — no code changes, no lock-in.
