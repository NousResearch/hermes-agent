## 2. Full Request Prefix Measurements (T0.3)

Measured via `evals/samagent_bench/tool_footprint.py` instantiating the real `run_agent.AIAgent` and `agent.system_prompt.build_system_prompt_parts` (offline, `chars/4` proxy):

### A. Static Tool-Schema Registry (`toolsets.py`)

| Posture | Tools | Schema Tokens (≈) | Share of 32K Window | Share of 128K Window |
|---------|------:|------------------:|--------------------:|---------------------:|
| Core (`_HERMES_CORE_TOOLS`) | 59 | 24,882 | 75.9% | 19.0% |
| Coding (`_CODING_TOOLS`) | 37 | 14,435 | 44.1% | 11.0% |
| SamAgent Lean-8 (`read`, `search`, `patch`, `write`, `terminal`, `todo`, `delegate`, `clarify`) | 8 | 3,992 | 12.2% | 3.0% |
| SamAgent Lean-5 (`read`, `search`, `patch`, `write`, `terminal`) | 5 | 2,576 | 7.9% | 2.0% |

### B. Full `AIAgent` Request Prefix (System Prompt + Tool Schemas)

| Environment | Posture | Resolved Tools | Tool Tokens (≈) | System Prompt Tokens (≈) | Total Prefix Tokens (≈) |
|-------------|---------|---------------:|----------------:|-------------------------:|------------------------:|
| **Clean Project** | `hermes-cli` default | 18 | 8,752 | 1,757 | **10,509** |
| **Clean Project** | `coding` posture | 17 | 8,291 | 1,757 | **10,048** |
| **Clean Project** | `samagent_lean_worker` (`file`+`terminal`, `skip_memory=True`) | 8 | 3,392 | 1,265 | **4,657** |
| **Hermes Repo Root** (with 37KB `AGENTS.md`) | `hermes-cli` default | 18 | 8,752 | 11,625 | **20,377** |
| **Hermes Repo Root** (with 37KB `AGENTS.md`) | `samagent_lean_worker` | 8 | 3,392 | 11,132 | **14,524** |

**Key takeaway:** In a clean project, `samagent_lean_worker` cuts the initial request prefix from **~10.5K tokens** (or **~16.2K** when all 37 coding tools have active backends) down to **~4.7K tokens** (and **~3.8K** with `tool_search` off on leaf workers) — a **56%–76% reduction** before a single line of user code is read.

## 3. Empirical Spike Verdicts (S1–S9)

All 9 spikes passed in `evals/samagent_bench/run_spikes.py`:

| Spike | Verdict | Impact on Plan |
|-------|---------|----------------|
| **S1** (Packaging) | **PASS** — `[tool.setuptools.packages.find]` + `plugins/**/plugin.yaml` in `pyproject.toml` packages `samagent/` with 1 patch (P2). | Keep P2 in `CORE_PATCHES.md`. |
| **S2** (`pre_llm_call` cache stability) | **PASS** — `agent/turn_context.py` injects `{"context": "..."}` into the user message via `compose_user_api_content` and stamps `api_content` for intra-turn and cross-turn replay. System prompt is untouched. | **Eliminate Patch P4.** Use `pre_llm_call` for Ledger injection. |
| **S3** (Per-task routing) | **PASS** — `kanban_swarm.SwarmWorkerSpec` routes via `profile`, and `delegate_tool.delegate_task` already accepts `credentials_cfg` (`model`, `provider`, `base_url`, `request_overrides`). | **Eliminate Patch P1.** Zero core changes needed in `delegate_tool.py`. |
| **S4** (`pre_tool_call` in children) | **PASS** — Delegated children invoke `_dispatch_pre_tool_call_hooks` with `{"action": "block", "message": ...}`, `"approve"`, or `"modify"`, plus `set_thread_tool_whitelist` exists in `hermes_cli/plugins.py`. | Keep two-layer ownership guard (`pre_tool_call` + post-hoc `git diff`). |
| **S5** (Dashboard plugin UI) | **PASS** — Bundled dashboard plugins use a zero-build JS IIFE on `window.__HERMES_PLUGIN_SDK__`, mount FastAPI routes via `plugin_api.py`, and stream events via `broadcast_plugin_event`. | Build Mission Control in `plugins/samagent/dashboard/` + standalone server for direct browser preview. |
| **S6** (Local runtime & grammar) | **PASS** — `local_runtime/presets.py` emits `--spec-type` flags, `chat_completion_helpers` forwards `request_overrides`, and `schema_sanitizer.py` normalizes tool schemas for `llama.cpp`. | Ship `ModelProfile` + `bench_model` micro-suite in `samagent/router/`. |
| **S7** (`pre_verify` gate) | **PASS** — `get_pre_verify_continue_message` accepts `changed_paths` and `final_response` and continues the loop when a hook returns `{"action": "continue", "message": "..."}`. | Wire L0–L4 verification into `pre_verify` hook + conductor. |
| **S8** (`kanban_swarm` blackboard) | **PASS** — `create_swarm`, `post_blackboard_update`, and `latest_blackboard` work atomically on SQLite. | Use `kanban_swarm` + `.samagent/ledger.db` as the conductor's backing store. |
| **S9** (`tool_search` deferral) | **PASS** — Earlier probe lacked `snowballstemmer` in `/tmp/hvenv`; with it installed, `assemble_tool_defs` activates by default and defers `session_search`, `todo_list`, and `process_manage`. | Configure explicit `samagent-lean` toolsets per role. |

---

## 4. Decision

**Gate G0 is PASSED.** Architecture **D+** holds with only **1 active core patch (`P2` in `pyproject.toml`)**, down from the budgeted 4. Proceed to implement the `samagent/` library, `plugins/samagent/` plugin & Mission Control UI, and `evals/samagent_bench/` v0 benchmark suite.
