# Browser Use

Deployment selects native `browser.backend: browser-use`, direct Browser Use
Cloud and `browser.use_gateway: false`. `browser_exec` uses the native CLI,
session, authentication and profile behavior without a fork-specific lifecycle.
Follow its current tool description for commands and screenshots. Native Browser
Use settings and account state determine persistence; do not assume this fork
creates a durable cloud profile automatically. Record service access and any
profile/session details you verify in the service manual.
