# NDR HTML email preferences — counterparty / investor pitch emails

Verified 2026-09-09 (Samudra ORR forward-purchase pitch to Saurabh Vashishth
@ Godrej Fund Management).

1. **HTML body = FULL WIDTH.** NDR's instruction verbatim: "Make sure that the full
   width of the email is used. Don't limit the width. Don't use HTML where it shows
   it as a limited width one." Do NOT wrap content in a fixed / max-width container
   (no `max-width:600px` style, no centered narrow table). Content spans the client's
   full pane.

2. **Number-heavy pitch emails: get include/exclude approval BEFORE drafting.**
   For investor/counterparty emails that cite deal numbers, present the proposed
   INCLUDE list vs KEEP-INTERNAL list first, let NDR confirm, then build the draft.
   Never silently decide what is shareable. Typical keep-internal items for a
   forward-purchase pitch: supportable land answer per acre, construction cost/sf,
   financing carry engine, regulatory/FAR+TDR outlay, staged draw schedule.

3. **Attach the proof-of-delivery artifacts in the same draft** — sketch PDFs as
   real attachments, location map pin embedded, and name the source spreadsheet
   (so the recipient can ask for it without a blind spot).

4. Deal state for the Samudra ORR example (spreadsheet IDs, numbers, counterparty,
   open gaps): `real-estate-financial-modeling` → `references/samudra-orr-forward-purchase.md`.
