# NDR Paragraph + Formatting Rule for Emails

User preference, stated explicitly 2026-09-09 while dictating the PropLion (Nabeel Shiraz / Ranka Amber sole mandate) reply, and REINFORCED as a UNIVERSAL rule 2026-09-22 (Gunjur next-steps email to Dharmesh + Manish): "This last rule has to be applied to my entire email drafting skill... So let's update the email drafter skill to know this. So this rule is always and always followed."

1. **No mid-sentence / mid-line return characters — EVER.** Complete paragraphs and complete lines only. A newline character goes ONLY between paragraphs or where a genuinely new line starts — never inside a sentence. NDR's words (09-Sep): *"please don't truncate the lines and put them into new lines in the middle of a sentence... Complete the paras and new line characters only between the paras."* Reinforced (22-Sep): *"Don't throw it as one text mass and don't throw unnecessary line terminations, that is return characters. Let the sentences run right till the end and return character should only be applied for new line, whether new paragraph or a new line is starting and nothing mid-sentence."* Applies to BOTH the HTML body and the plain-text alternative. This is the top formatting rule for EVERY email draft — not just voice-dictated ones.

2. **When NDR asks for formatting for visual ease, use HTML with real structure — bullets, bold section headers, paragraphs.** He accepts "even just rich text format" but the default is HTML with inline CSS: `<p>` per paragraph, `<ul>/<li>` for bulleted lists, `<strong>` on key phrases/asks. Always ship a plain-text multipart alternative alongside (same content, no markup). Trigger phrases: "format it", "bullets", "highlight", "easy to read", "HTML".

3. **Mirror the counterparty's formatting.** If the email being replied to uses bold on key phrases (e.g. Nabeel's reply bolds "all-inclusive selling price", "performance gates" clause text), bold OUR key phrases too — use `<strong>` in the HTML body so our points are equally clear. NDR: *"using bold and other formatting as he has done in his reply, so our points are very clear to him."*

4. **Missing original proposal → ask, don't guess.** When the user doesn't have / can't download the counterparty's original proposal or quotation, DO NOT reconstruct their fee numbers from memory. Explicitly ask them to re-share the original PDF in the reply, and structure the negotiation reply point-by-point against their LATEST email (numbered sections matching their points).
