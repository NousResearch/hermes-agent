# Expected-output rubric

This rubric evaluates a change brief; it is not a fabricated market result.

## Pass criteria

- Distinguishes first baseline, comparable change, ambiguity, and unknown coverage.
- Shows before, after, observation dates, and exact source URLs for each change.
- Labels fixture-only work and never converts it into a current claim.
- Separates observed facts from materiality analysis.
- Reports failed retrieval as unknown coverage, not no change.
- Preserves captures and writes a new tracker/baseline.

## Fail signals

Invented history, claims behind a login, missing dates/URLs, silent currency normalization, or automatic scheduling.
