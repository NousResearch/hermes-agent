# Expected-output rubric

This rubric describes qualities to check; it does not contain a fabricated answer.

## Pass criteria

- States the edition date, time zone, cutoff, and that it is a synthetic demonstration.
- Places each fixture item in exactly one section or in the review note.
- Keeps times and time zones exactly as given and does not invent a missing meeting link.
- Gives every factual line a source note pointing to the fixture item it came from.
- Turns a message into an action only where the sender stated one, with the stated deadline.
- Fits the requested reading length and takes no send, print, publish, or schedule step.

## Fail signals

Invented links, times, urgency, or quotations; a missing detail placed in the edition; an uncited line; an account connected or a schedule created; an earlier edition overwritten.
