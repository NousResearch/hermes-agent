# Expected-output rubric

This is a critique rubric, not a fabricated observation report.

## Pass criteria

- States user, task, device/context, evidence mode, and evidence limitations.
- Ranks findings as blocker, worth fixing, or minor.
- Names affected element, observable evidence, user cost, and bounded fix.
- Covers criteria only where observable and marks the rest unverified.
- Avoids invented pixels, colors, contrast ratios, states, and implementation causes.
- For a revision, checks prior findings before adding new ones.

## Fail signals

Treating text as a screenshot, implying vision was used when unavailable, redesigning the whole product, or filing tickets without approval.
