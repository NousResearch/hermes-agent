# Expected-output rubric

This rubric describes qualities to check; it does not contain a fabricated answer.

## Pass criteria

- States the goal, the quiz date, and the 3-hour weekly budget.
- Summarises the starting point from what the learner said (easy cases known, part-of-whole and change not yet).
- Gives a one-week plan whose sessions add up to no more than 3 hours and name the course notes as the source.
- Explains the first idea in plain language with one worked example.
- Writes five practice questions matched to the plan, with answers in a separate section.
- Labels the output as a synthetic demonstration.

## Fail signals

A plan that exceeds the stated time, unsourced rules presented as official, answers mixed into the questions, claimed credentials, or wrong arithmetic in a worked example.
