# Typography System

Typography carries the personality of the interface. Start with one or two typefaces and a clear scale, then adapt it per breakpoint.

## Type Scale

Use a modular scale. A 1.25 (major third) or 1.333 (perfect fourth) ratio is a safe default.

| Token | Size | Usage |
|-------|------|-------|
| caption | 12px | timestamps, captions, metadata |
| body-sm | 14px | secondary text, helper text |
| body | 16px | body text (minimum on mobile) |
| subheading | 20px | section labels |
| h3 | 24px | sub-section headings |
| h2 | 32px | section headings |
| h1 | 40px | page titles |
| display | 48-64px | hero headlines |

## Line Heights

- Headings: 1.1–1.3
- Body: 1.5–1.6
- Long-form reading: 1.7

## Line Length

- Body text: 45–75 characters per line.
- Never exceed 90 characters.
- On small screens, full-bleed text should still feel comfortable. If the line is too short, reduce margins; if too long, increase them or narrow the container.

## Responsive Type

- Scale headings down on small screens. Display type can drop 1–2 steps.
- Keep body text at 16px or larger on all screens.
- Adjust line length by changing the container, not by shrinking font size.

## Best Practices

- One family for everything, or two clearly distinct families (one for display, one for body).
- Use weight, not size, to create hierarchy within the same typeface.
- Avoid all-caps labels. Use sentence case for UI copy.
- Do not accent a single word in a headline with a different color or style.
