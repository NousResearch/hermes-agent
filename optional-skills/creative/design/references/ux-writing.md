# UX Writing

Words are interface. They should guide, not decorate. Every label, button, error, and empty state is a design decision.

## Voice

- Use active voice.
- Use sentence case.
- Be specific. "Save changes" is better than "Submit."
- Match the brand, but never at the cost of clarity.

## Buttons and CTAs

- Name the action: "Create account," not "Continue."
- Primary actions are the outcome the user wants.
- Secondary actions are cancel or go back.
- Destructive actions are explicit: "Delete project" not "Yes."

## Errors

- Say what happened and what to do next.
- Do not apologize. Do not blame the user.
- Be specific: "Enter a date after 2024-01-01" not "Invalid date."

## Empty States

- Explain what is missing.
- Tell the user what to do next.
- Add an action if appropriate.

## Forms

- Labels are nouns: "Email address."
- Placeholders are examples, not labels.
- Helper text explains format or constraints.
- Error text explains how to fix the value.

## Best Practices

- Write for one action per sentence.
- Avoid jargon, unless the user expects it.
- Test copy by reading it out loud.
