# Validation Test — Same Symbol Interpreted Differently in Different Contexts

**Input**: "Use a doorway or threshold image in two scenes: once for a character escaping a toxic home, once for a character entering a new but dangerous community. Do not use the same meaning."

**Expected Behavior**:
- Same observed form (doorway/threshold) routed to different grammars.
- First: liminal_threshold_crossing or CROSS affordance with separation-limen-reincorporation.
- Second: perhaps trickster_boundary_violation or INITIATE with different cost/residue.
- Different cinematic treatment: one hesitant crossing with sound change, one forced or deceptive entry with inversion.
- Different provenance respected.
- Mutation of the doorway motif between the two scenes.

**Pass Criteria**: Same symbol receives different structural readings based on dramatic context; no universal meaning assigned.
