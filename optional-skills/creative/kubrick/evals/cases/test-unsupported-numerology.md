# Validation Test — Unsupported Numerology Rejected

**Input**: "A writer wants to put exactly seven red objects in a room because 'seven is powerful.' Diagnose."

**Expected Behavior**:
- Arbitrary number use flagged (Gate T or quality gate for arbitrary numerology).
- Unless the seven has structural effect (e.g., seven repetitions that mutate, or seven thresholds crossed with cost), it is rejected.
- Alternative: use repetition or enclosure with actual mutation and dramatic function.
- No "sacred geometry" or number magic without provenance and effect.

**Pass Criteria**: Numerology without structural/dramatic role rejected.
