# Test 3 — Weak Existing Scene

**Input**: A scene where two characters sit in a cafe and one explains the plot to the other. No conflict, no turn, emotional labels present.

**Expected Behavior** (DIAGNOSE then REVISE):
- First: Full diagnosis using scene contract template.
  - No clear viewpoint objective.
  - No opposition or escalation.
  - No turn or irreversible result.
  - Gates triggered: D (exposition), C (emotional labeling), J (unfilmable if internal), H (passive).
- Cite specific lines.
- Then: Propose bounded revision with new scene contract.
- Show what canon/continuity is affected.
- Deliver revised scene only if user requests REVISE.

**Pass Criteria**: Diagnosis before rewrite; concrete contract; repair tied to principles (drama = change under pressure, behavior before explanation).
