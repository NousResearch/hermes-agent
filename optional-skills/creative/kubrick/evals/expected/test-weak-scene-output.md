# Expected Output for Test 3 (Weak Scene)

**Mode**: DIAGNOSE (then optional REVISE)

**Scene Diagnosis (using contract)**:
- Viewpoint: Unclear / shifting.
- Scene objective: None stated (characters "catch up").
- Opposition: None.
- Tactics: None.
- Turn: None (information transfer only).
- Irreversible result: None.
- Gates triggered: D (exposition dump), C (emotional labeling), J (unfilmable if internals), H (passive protagonist), I (repetitive if similar to prior).

**Rubric Scores** (example):
- Scene function: 1 (no change)
- Causality: 2
- Dialogue: 2 (on-the-nose)
- Visual storytelling: 1

**Repair Strategy**:
1. Give one character a clear, active objective in this location.
2. Introduce resistance (the other character has conflicting goal or information).
3. Create a turn (revelation or decision that changes their relationship or knowledge state).
4. Ensure exit condition differs from entry (new obligation, damaged trust, raised stakes).
5. Externalize emotions via behavior and objects.
6. Make exposition motivated (e.g., one character is trying to persuade or extract something).

**Bounded Revision Proposal** (if REVISE requested): New scene contract + 1-page revised draft preserving any approved facts.
