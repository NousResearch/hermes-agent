# Genre Pack: Melodrama

## Core Patterns

### Recurring Object as Emotional Residue Across Time
- Transformation: integration with retained residue.
- Affordances: TRANSFER, REPEAT (with mutation), HAUNT.
- Cinematic: object starts ordinary, accumulates meaning through subtle changes in framing, light, sound.
- Counterpoint example: warm, stable color palette while the object reveals fracturing relationships.
- Low-cost: use a single prop that travels between scenes; mutate its state (broken, repaired poorly, stained).

### Blocking That Maintains Distance in Intimate Spaces
- Affordances: BIND (ironic), INVERT.
- Characters share a frame but never cross into each other's space.
- Camera stays at medium or wider even in "close" moments.
- Sound: intimate dialogue mixed with distant or muffled elements.
