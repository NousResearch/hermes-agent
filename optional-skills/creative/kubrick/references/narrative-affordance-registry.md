# Narrative Affordance Registry
# Organized by symbolic operation (not dictionary meaning). Each operation maps patterns to narrative/cinematic functions.

## Operations

### BIND
- Compatible patterns: conjunction, marriage, oath, knot, mirror-dual.
- Scene functions: alliance formation, trap setting, vow enforcement.
- Character functions: commitment under pressure, shared fate.
- Sequence functions: setup for later rupture or convergence.
- Cinematic functions: matching compositions, shared frame, linked movement, sound bridge.
- Setup: Establish two distinct elements with tension.
- Payoff: Elements become interdependent; separation costs something.
- Incompatibilities: Pure opposition without prior bond.

### DIVIDE
- Compatible patterns: separation, threshold crossing, schism, broken symmetry.
- Scene functions: conflict escalation, identity split, revelation of hidden difference.
- Character functions: choice that severs prior unity.
- Cinematic functions: split screen, opposing screen directions, occlusion, negative space between figures.
- Setup: Prior unity or proximity.
- Payoff: Irreversible separation expressed spatially or rhythmically.
- Incompatibilities: Mere physical distance without relational cost.

### INITIATE
- Compatible patterns: threshold, death-rebirth, first crossing, alchemical calcination.
- Scene functions: entry into new state, loss of innocence or prior self.
- Character functions: voluntary or forced transformation.
- Cinematic functions: movement across frame edge, light change, sound shift from known to unknown, entry into new depth.
- Setup: Ordinary world or prior equilibrium.
- Payoff: Irreversible change in capability, knowledge, or relation.
- Incompatibilities: Reversible or merely informational passage.

### CONCEAL / REVEAL
- Compatible patterns: veil, hidden center, mask, revelation through inversion.
- Scene functions: suspense, recognition, power shift.
- Cinematic functions: occlusion, focus pull, offscreen sound, graphic match that hides then reveals, negative space that later contains.
- Setup: Audience or character lacks full information.
- Payoff: Revelation changes prior understanding without exposition dump.
- Incompatibilities: Revelation that explains rather than transforms.

### INVERT
- Compatible patterns: reversal, upside-down world, role exchange, alchemical solve et coagula.
- Scene functions: power flip, moral inversion, expectation subversion.
- Cinematic functions: upside-down framing, reversed screen direction, color inversion in grading, role-swapped blocking.
- Setup: Established order or expectation.
- Payoff: The inversion is legible through behavior and form, not statement.
- Incompatibilities: Inversion without consequence or prior order.

### REPEAT (with Mutation required)
- See motif_lifecycle in symbolic-dramaturgy.md.
- Mutation required on every recurrence (state, context, ownership, geometry, sound, consequence).
- Cinematic: repeated composition with one variable changed; same shot scale, different occupant.

### CONTAMINATE
- Compatible patterns: alchemical putrefaction, infection, haunting residue.
- Scene functions: corruption of prior purity, slow transformation of a space/relationship/character.
- Cinematic: color bleed, sound bleed, object migration, blocking that gradually incorporates the contaminant.
- Setup: Clean or stable state.
- Payoff: The contaminant alters the original without full replacement.

### MIRROR / SUBSTITUTE
- Compatible patterns: double, doppelganger, exchange, shadow self.
- Scene functions: identity questions, proxy action, denied difference.
- Cinematic: matched framing with subtle difference, same actor in different role, graphic match that substitutes one figure for another.
- Setup: Clear original.
- Payoff: The substitute reveals something about the original through difference.

### SACRIFICE / RELEASE
- Compatible patterns: offering, renunciation, alchemical projection, death-rebirth.
- Scene functions: cost that enables transformation or protection.
- Cinematic: object or person removed from frame with lingering trace (sound, light, empty space).
- Setup: Attachment or claim.
- Payoff: The release changes the remaining elements.

### CROSS / ENCLOSE / DESCEND / RETURN
- Threshold operations. Map to liminal patterns.
- Cinematic: crossing frame edge, enclosure in architecture or light, descent into lower frame or darker exposure, return with mutation.
- Always track cost and residue.

### HAUNT / ERASE / RESTORE
- Ghosting (residue without presence), erasure (absence that structures), restoration (return with difference).
- Cinematic: lingering sound after source gone, negative space where something was, restored composition with one element altered.

**General Rules for All Operations**
- Prefer process and relation over icon.
- Always specify setup → transformation → residue.
- Link to cinematic affordances.
- Record provenance of the pattern.
