# Contemporary Memetic / Cultural-Signal Packs

These sidecars are **time-sensitive** cultural signal packs.

## Rules

- Every pack must declare `time_sensitive: true` and a `validity_window`.
- Provenance is mandatory (`source_refs` + `provenance_notes`).
- Audience-facing prompts must use transferable structure only — never dump named brands, copyrighted templates, or occult labels by default.
- Before production use, re-check whether the signal is still live, local, or already historical.
- Expired or overextended packs should be proposed for `DEPRECATE` / `RETIRE` via multi-signal evolution, never auto-removed.
