# Marionette in the Mirror Brand Profile

このプロファイルは `generate-event-post` の既定値であり、現在のGPTs指示を正とする。補助仕様書と競合する場合は、このファイルとSKILL.mdの項目別優先順位を使う。

公式X: https://x.com/mari_mira_idol

過去の公式投稿は文体・改行・絵文字の参考にできるが、新しいイベントの日時、料金、出演枠の根拠にはしない。現在の入力資料とチケットサイトを正として照合する。

## 対象

- Marionette in the Mirror（マリミラ）
- 心春るり
- 日向れいら
- 甘海老えびな
- 星屑あめ
- 姫鈴らぶか

対象外の演者は出演者一覧の照合には使えるが、マリミラの出演枠として抽出しない。

## 表記

- 日付: `2026年7月19日（日）` の形式。月日をゼロ埋めしない。
- 時刻: 24時間表記、範囲は `HH:MM〜HH:MM`。
- 既知の表示: `🍊日向れいら`、`💙心春るり`、`🪞マリミラ`。
- 甘海老えびな、星屑あめ、姫鈴らぶかの絵文字は提供仕様にないため、勝手に付けず名前だけを使う。
- 「予定」「仮」は保持する。
- 不明値は「未定」とする。

## チケット欄

券種はすべて列挙し、券種ごとのドリンク条件を残す。

```text
🎫チケット

前方 ¥3000（+1D）
一般 ¥0（+2D）
当日 各券種＋¥500
```

全券種が同じ「各+1D」の場合だけ次の形にまとめられる。

```text
前方 ¥3000
一般 ¥1500
（各+1D）
```

情報源にある場合は、次の条件もチケット欄へ残す。

- 女性無料
- DD料金
- 当日料金
- 再入場
- 現金払い
- 優先入場
- 入場順

## 予約欄

チケットサイトがある場合:

```text
🔗予約

https://tiget.net/events/123456
```

チケットサイトがない場合:

```text
🔗受付

当日受付払い
```

「各運営予約」とは記載しない。

## お目当て特典

予約価格が2,000円以上なら「マリミラルーレット」、2,000円未満なら「写メ」。ドリンク代と当日加算は判定に含めず、当日券は特典欄へ記載しない。

```text
🉐お目当て特典

前方：マリミラルーレット
一般：写メ
```
