# Web Scraping Reality

## Bot-Protected (DO NOT USE)
- LinkedIn — fully bot-protected
- Indeed — fully bot-protected
- G2 — fully bot-protected
- Capterra — fully bot-protected
- Search engines (Google, Bing) — bot-protected

## Accessible
- Direct company career pages
- Greenhouse, Lever, Workable job boards
- /academy paths on company sites
- Product blogs and changelogs
- RSS feeds
- Documentation sites

## Fallback Strategy
When Brave Search API fails:
1. Use DuckDuckGo HTML search (no auth needed, reliable)
2. Use CloakBrowser for Google search fallback (C++-patched Chromium)
3. Use Cloudflare Browser Rendering for JS-heavy competitor pages
