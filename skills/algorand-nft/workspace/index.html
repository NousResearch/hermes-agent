04

ASA settings

The ASA URL points to media, not JSON. Optional type fragments: #i image, #v video, #a audio, #p PDF, #h HTML. No assetMetadataHash is set.

Immutable: no later manager metadata updates or destruction to reclaim the asset minimum balance. Creator-manager: later ARC69 updates need a new asset configuration transaction; existing history and ASA name/unit/URL do not change. This workspace implements creation only.

05

Mint on MainNet

One ASA: total 1, decimals 0, default frozen false. Ordinary unrekeyed single-Ed25519 Pera accounts only. No payment, rekey, close, group, lease, reserve, freeze or clawback. Optional manager is the creator only.
