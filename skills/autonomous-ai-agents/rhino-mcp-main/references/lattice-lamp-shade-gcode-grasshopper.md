## Overview

This video demonstrates how to bypass traditional slicers (Cura, PrusaSlicer, etc.) and generate G-code directly from Grasshopper for 3D printing. The technique enables:

- **Mid-air printing** (printing without support structures)
- **Lattice/voronoi structures** for lamp shades
- **Direct G-code control** for non-planar printing
- **Parametric design-to-fabrication workflow**

## Key Concepts

### 1. Why Bypass the Slicer?

| Traditional Slicer Workflow | Direct G-code from Grasshopper |
|----------------------------|-------------------------------|
| STL → Slicer → G-code | Geometry → Grasshopper → G-code |
| Limited to planar layers | Non-planar, curved, mid-air paths |
| Fixed infill patterns | Custom lattice/voronoi infill |
| Support structures required | Support-free mid-air printing |
| Black-box processing | Full parametric control |

### 2. Mid-Air Printing Principles

**Mid-air printing** = Extruding filament in free space without previous layer support.

Requirements:
- **High cooling** (100% fan, often additional part cooling)
- **Slow print speed** (10-20 mm/s for bridges)
- **Optimal temperature** (lower than normal, e.g., 190-200°C for PLA)
- **Retraction tuning** (prevent stringing during travel moves)
- **Path planning** (bridge before overhang, proper sequencing)

### 3. Lattice Structure Generation in Grasshopper

#### Voronoi/Wireframe Approach
```
1. Base surface (lamp shade form)
2. Populate with points (Poisson disk / random)
3. Voronoi 3D / Delaunay triangulation
4. Extract edges as curves
5. Pipe curves with variable radius
6. Convert to G-code paths
```

#### Key Grasshopper Components
| Component | Purpose |
|-----------|---------|
| `Populate3D` / `PopulateGeometry` | Point distribution |
| `Voronoi3D` | Cell generation |
| `MeshEdges` / `Wireframe` | Edge extraction |
| `Pipe` / `Tube` | Curve thickening |
| `CurveToPolyline` | G-code compatible segmentation |
| `GCodeWriter` (custom) | G-code output |

### Step 3: G-code Generation
```python
def generate_gcode(paths, settings):
    """
    settings = {
        'nozzle_dia': 0.4,
        'filament_dia': 1.75,
        'extrusion_multiplier': 1.0,
        'feedrate_xy': 1200,  # mm/min
        'feedrate_z': 300,
        'temp_hotend': 200,
        'temp_bed': 60,
        'retraction_dist': 2.0,
        'retraction_speed': 25,
        'cooling_fan': 255
    }
    """
    gcode = []
    gcode.append("; Generated by Grasshopper")
    gcode.append(f"; Nozzle: {settings['nozzle_dia']}mm")
    gcode.append(f"; Filament: {settings['filament_dia']}mm")
    
    # Startup
    gcode.extend([
        "M104 S{temp_hotend}".format(**settings),
        "M140 S{temp_bed}".format(**settings),
        "G28",  # Home all
        "G90",  # Absolute positioning
        "M82",  # Absolute extrusion
        "M106 S{cooling_fan}".format(**settings),
    ])
    
    # Wait for temps
    gcode.append("M109 S{temp_hotend}".format(**settings))
    gcode.append("M190 S{temp_bed}".format(**settings))
    
    # Prime line
    gcode.append("G1 X10 Y10 Z0.2 F3000")
    gcode.append("G1 X100 Y10 E15 F1000")
    gcode.append("G92 E0")
    
    # Print paths
    current_e = 0
    for i, path in enumerate(paths):
        # Travel to start
        start = path.PointAtStart
        gcode.append(f"G0 X{start.X:.3f} Y{start.Y:.3f} Z{start.Z:.3f} F{settings['feedrate_xy']}")
        
        # Retract before travel
        if i > 0:
            gcode.append(f"G1 E{current_e - settings['retraction_dist']:.5f} F{settings['retraction_speed']*60}")
        
        # Print segments
        for seg in path.Segments:
            length = seg.Length
            # Extrusion calc: π * (nozzle/2)² * length * multiplier / (π * (filament/2)²)
            vol = 3.14159 * (settings['nozzle_dia']/2)**2 * length * settings['extrusion_multiplier']
            e_inc = vol / (3.14159 * (settings['filament_dia']/2)**2)
            current_e += e_inc
            
            end = seg.PointAtEnd
            gcode.append(f"G1 X{end.X:.3f} Y{end.Y:.3f} Z{end.Z:.3f} E{current_e:.5f} F{settings['feedrate_xy']}")
        
        # Deretract
        if i < len(paths) - 1:
            gcode.append(f"G1 E{current_e + settings['retraction_dist']:.5f} F{settings['retraction_speed']*60}")
    
    # Shutdown
    gcode.extend([
        "G92 E0",
        "G1 E-5 F1800",  # Final retraction
        "G1 Z+10 F3000",
        "M104 S0",
        "M140 S0",
        "M84"
    ])
    
    return "\n".join(gcode)
```

## Critical Parameters for Lattice Lamp Shades

| Parameter | Typical Value | Notes |
|-----------|---------------|-------|
| Nozzle diameter | 0.4mm (0.6mm for faster) | Affects minimum feature size |
| Layer height | 0.15-0.2mm | Not used in non-planar |
| Extrusion width | 0.45-0.5mm | ~1.2x nozzle |
| Print speed | 15-25 mm/s | Critical for mid-air |
| Travel speed | 150-200 mm/s | Minimize stringing |
| Hotend temp | 190-205°C (PLA) | Lower = better bridging |
| Bed temp | 50-60°C | First layer adhesion |
| Fan speed | 100% (255) | Essential for bridging |
| Retraction | 1.5-2.5mm @ 25mm/s | Bowden: 4-6mm |
| Coasting | 0.2-0.4mm | Reduce blob at end |

## Mid-Air Printing Tips

1. **Bridge before overhang** - Sequence paths so bridges print first
2. **Fan direction** - Aim cooling at bridge point, not nozzle
3. **Z-hop disabled** - For mid-air, Z-hop creates gaps
4. **Combing mode** - "Within infill" or "All" to reduce travel
5. **Avoid crossing perimeters** - Plan lattice paths to not cross
6. **Variable extrusion** - Thicker at nodes, thinner on spans

## Common Issues & Solutions

| Issue | Cause | Solution |
|-------|-------|----------|
| Stringing | High temp / low retraction | Lower temp, increase retraction |
| Sagging bridges | Insufficient cooling | 100% fan, lower temp, slower speed |
| Layer delamination | Poor layer adhesion | Increase temp, slower cooling |
| Nozzle clog | Filament grinding | Check extruder tension, clean nozzle |
| G-code too large | Too many segments | Increase polyline tolerance |
