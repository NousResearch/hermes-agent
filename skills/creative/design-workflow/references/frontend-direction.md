# Frontend Direction

Use this before crafting visuals or code. The key move is to make an explicit aesthetic/product decision instead of accepting default AI/SaaS patterns.

## Direction Brief

Answer compactly:

```markdown
- Product category:
- Target user:
- Moment of use:
- Main promise:
- Desired feeling:
- Trust signal:
- Aesthetic family:
- Anti-references:
- Style dials:
```

## Avoid Unconscious Defaults

Be suspicious of:
- blue/purple gradient hero
- centered headline + generic subhead + two buttons
- three equal feature cards
- "AI-powered", "seamless", "unlock", "empower", "all-in-one" copy without proof
- random glowing orbs
- overly round glass cards
- icon grids that do not explain product value
- screenshots with fake empty data

These are not banned. They are only acceptable when they are intentional and fit the product.

## Direction Families

Use these as vocabulary, not templates:

- **Product clarity** — restrained, sharp hierarchy, trust-first SaaS/product UI.
- **Soft premium** — spacious, refined, warm, gentle contrast, careful detail.
- **Editorial minimalist** — strong typography, asymmetry, narrative rhythm, fewer boxes.
- **Developer utility** — dense, fast, monospace accents, clear states, low decoration.
- **Operational dashboard** — compact, scan-first, high information scent, strong tables/filters.
- **Industrial brutalist** — high contrast, raw edges, grid discipline, confident copy.
- **Playful consumer** — approachable, tactile, expressive illustrations/motion, friendly copy.
- **Native platform** — iOS/Android conventions with brand accents rather than web page metaphors.

## Good Direction Tests

A useful direction should say:

- What to emphasize.
- What to avoid.
- How dense the UI should be.
- How expressive motion should be.
- How much asymmetry or novelty is acceptable.
- How to maintain trust.

Bad direction: "make it modern".

Good direction: "B2B procurement dashboard: low motion, high density, calm neutral palette, strong table hierarchy, trust-first copy, one accent color for action and risk."
