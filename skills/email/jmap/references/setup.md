# JMAP Setup Guide for Hermes Agent

This guide explains how to connect Hermes Agent to any JMAP (RFC 8620 / RFC 8621) compliant email service.

---

## 1. Provider Configuration Presets

### Option A: Atomic Mail
- **Session URL**: `https://api.atomicmail.io/jmap/session`
- **Token**: Generate an API Key / Bearer Token in your Atomic Mail dashboard (`Settings > API Keys`).
- **Account ID**: Auto-discovered from session.

### Option B: Fastmail
- **Session URL**: `https://api.fastmail.com/jmap/session`
- **Token**: Generate an API Token in Fastmail (`Settings > Password & Security > API Tokens > Mail (Read & Write)`).
- **Account ID**: Auto-discovered from session.

### Option C: Self-Hosted Stalwart / Apache James / Cyrus JMAP
- **Session URL**: `https://mail.yourdomain.com/.well-known/jmap` or `https://mail.yourdomain.com/jmap/session`
- **Token**: Personal Access Token or App Password generated by your server administrator.
- **Account ID**: Auto-discovered.

---

## 2. Setting Up Credentials

You can configure credentials via Environment Variables or a JSON config file.

### Method 1: Environment Variables (Recommended for CLI / Containers)
Add to your environment or `~/.hermes/.env`:
```bash
JMAP_SESSION_URL="https://api.atomicmail.io/jmap/session"
JMAP_API_TOKEN="your_bearer_token_here"
```

### Method 2: Credentials File
Create `~/.hermes/jmap-credentials.json` (or copy from `templates/credentials.template.json`):
```json
{
  "session_url": "https://api.atomicmail.io/jmap/session",
  "token": "your_bearer_token_here",
  "account_id": null
}
```

Ensure permissions are restricted to user-only:
```bash
chmod 600 ~/.hermes/jmap-credentials.json
```

---

## 3. Verifying the Connection

Run the list command to verify the connection:
```bash
python3 skills/email/jmap/scripts/jmap_client.py list --limit 3
```

If successful, you will see a list of recent emails in your INBOX.
