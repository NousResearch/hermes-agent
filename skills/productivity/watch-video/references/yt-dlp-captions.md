# yt-dlp Caption Extraction Reference

## Overview
This document describes the caption/subtitle extraction strategy using yt-dlp for the watch-video skill.

## Supported Platforms

yt-dlp supports captions from 1000+ sites including:
- **YouTube**: Auto-generated + manual captions, multiple languages
- **Vimeo**: Captions/subtitles
- **Twitch**: VOD captions
- **TikTok**: Auto-captions
- **Twitter/X**: Video captions
- **Facebook**: Video captions
- **Instagram**: Reels/IGTV captions
- **Loom**: Video captions
- **Generic**: Any site with WebVTT/SRT tracks

## Extraction Strategy

### 1. Caption-First Approach
Attempt caption-only download before full video download:
```bash
yt-dlp --write-auto-sub --sub-lang en --sub-format vtt --skip-download <url>
```

Benefits:
- Saves bandwidth (no video download if captions suffice)
- Faster for caption-only workflows
- Works even if video is geo-blocked but captions available

### 2. Language Priority
Try languages in order:
1. `en` (English)
2. `en-US` (US English)
3. `en-GB` (UK English)
4. `auto` (auto-generated, any language)

### 3. Format Preference
Prefer **WebVTT** (`.vtt`) over SRT:
- Native timestamp format (HH:MM:SS.mmm)
- Supports styling/positioning metadata
- Better parsing support in Python

## Caption Types

### Auto-Generated Captions
- Generated by platform's ASR (YouTube, TikTok, etc.)
- Usually available for most videos
- May have errors, but timestamps generally accurate
- Accessed via `--write-auto-sub`

### Manual/Uploaded Captions
- Created by video uploader
- Higher accuracy
- May include multiple languages
- Accessed via `--write-sub`

### Translation Captions
- Auto-translated versions
- Accessed via `--sub-lang` with language codes
- Lower priority (use only if no original)

## yt-dlp Command Reference

### Metadata Only (No Download)
```bash
yt-dlp --dump-json --no-warnings <url>
```
Returns full `info_dict` with: title, duration, uploader, thumbnails, chapters, formats, subtitles, etc.

### Caption Extraction
```bash
yt-dlp \
  --write-auto-sub \
  --write-sub \
  --sub-lang en,en-US,en-GB,auto \
  --sub-format vtt \
  --skip-download \
  --no-warnings \
  -P <work_dir> \
  <url>
```

### Full Video + Captions
```bash
yt-dlp \
  -f "bestvideo+bestaudio/best" \
  --merge-output-format mp4 \
  --write-auto-sub \
  --write-sub \
  --sub-lang en,en-US,en-GB,auto \
  --sub-format vtt \
  -o "video.%(ext)s" \
  --no-warnings \
  -P <work_dir> \
  <url>
```

## Output File Patterns

| Type | Pattern | Example |
|------|---------|---------|
| Auto-captions | `video.<lang>.vtt` | `video.en.vtt` |
| Manual captions | `video.<lang>.vtt` | `video.en.vtt` |
| Video | `video.<ext>` | `video.mp4` |

Note: Auto and manual captions may overwrite each other. Last written wins.

## WebVTT Parsing

### Format
```
WEBVTT

00:00:01.000 --> 00:00:04.000
Hello world

00:00:05.000 --> 00:00:08.000
This is a test
```

### Timestamp Format
`HH:MM:SS.mmm` (hours:minutes:seconds.milliseconds)

### Special Tags to Ignore
- `NOTE` — Comments
- `STYLE` — CSS styling
- `REGION` — Positioning regions

### Parsing Logic
1. Skip `WEBVTT` header
2. For each timestamp line (`-->`), parse start/end
3. Accumulate text lines until next timestamp or EOF
4. Create `TranscriptSegment(start, end, text)`

## Edge Cases

### No Captions Available
- yt-dlp exits 0 but no `.vtt` files created
- Pipeline continues with vision-only analysis
- Notes will indicate "Transcript: none available"

### Multiple Caption Tracks
- yt-dlp downloads all matching languages
- Skill uses first successfully parsed track
- Future: could merge multiple languages

### Live Streams / Premieres
- May not have captions until processing complete
- yt-dlp may fail or return partial captions
- Handle gracefully with vision fallback

### Age-Restricted / Private / Members-Only
- yt-dlp requires authentication (`--cookies`, `--username/--password`)
- Skill does not handle auth (out of scope)
- Clear error message from yt-dlp

### Geo-Blocked Content
- May work for captions even if video blocked
- Caption-first strategy helps here
- If both blocked, clear error from yt-dlp

## Common yt-dlp Errors

| Error | Cause | Resolution |
|-------|-------|------------|
| `ERROR: [youtube] Video unavailable` | Deleted/private | Cannot fix |
| `ERROR: This video is only available for registered users` | Age/members | Needs auth |
| `ERROR: Video is not available in your country` | Geo-block | VPN/geo-bypass |
| `WARNING: Unable to extract uploader` | Minor | Ignore |
| `ERROR: No video formats found` | Live stream ended | Try different format selector |

## Version Compatibility

Tested with yt-dlp >= 2023.01.00. Older versions may lack:
- `--sub-format vtt` support
- Improved auto-caption detection
- Platform-specific fixes

## Rate Limiting

- YouTube: ~1 request/second without auth
- Use `--sleep-interval` for bulk processing
- Skill processes one video at a time (no bulk)
