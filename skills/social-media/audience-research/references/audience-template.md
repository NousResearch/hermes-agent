# audience.md Template

The output of this skill. Every field must be something that **changes how content gets made** —
if it wouldn't change a post, it doesn't belong. Keep it tight; the content skills read it
constantly.

Copy everything below the line into `audience.md` and fill it in.

---

---

## How downstream skills read this

- **`content-pillars`** turns the **jobs and pains** into ownable, audience-relevant pillars.
- **`batch-content-plan`** uses **segments, pains, and objections** to assign goals and angles.
- **`hook-writer` / `caption-writer`** pull hooks, pains, and CTAs from the **language bank** so
  copy mirrors the audience's own words.
- Treat the **language bank** and **jobs-to-be-done** as the highest-signal sections.

If a segment's fields are thin or marked "(assumed)", write conservatively and prioritize
validating them with real evidence.
