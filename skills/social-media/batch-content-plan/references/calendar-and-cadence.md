# Calendar & Cadence

How the balanced mix gets placed in time — realistically, sustainably, and in a sensible order.

---

## Cadence — consistency beats volume

The right cadence is the one the user can **sustain**. A consistent 3 posts/week for a year
beats 2 posts/day for three weeks and then silence. Start from capacity, not ambition.

Reasonable starting cadences (adjust to the brand and platform, and to capacity):

- **Instagram / TikTok:** ~3–5/week.
- **LinkedIn:** ~2–4/week.
- **X / Threads:** higher volume tolerated (daily+), shorter posts.
- **Pinterest:** steady, SEO-driven; volume helps over time.
- **YouTube long-form:** weekly or biweekly; Shorts more often.

These are starting points, not targets to max out. Match volume to what the user can keep up.

## Capacity check (do this before sizing the plan)

Ask, or infer:

- How many posts can they realistically create per week?
- How much raw material exists (assets, stories, products, footage)?
- Solo or a team? Time available?

Then size the plan to that, and make up the difference with **repurposing** (one idea → several
posts) rather than demanding more net-new ideas than they can produce. A plan the user abandons
in week two is worse than a smaller plan they finish.

## Sequencing rules

Order matters across the period, not just the count:

- **Space out promotions** — never stack two asks back-to-back; cushion them with value.
- **Vary formats day to day** — don't run three carousels in a row.
- **Lead with strength** — open the week/month with your best hook to set the tone.
- **Anchor recurring series** on fixed days (e.g., Tip Tuesday) so the audience learns the
  rhythm.
- **Cluster a campaign deliberately** when there's a launch — a few coordinated posts, still
  buffered by value content.

## Timing (advisory — not analytics-backed)

Suggest posting times from general principles — post when the audience is active, respect time
zones, weekday business hours for B2B, evenings/weekends for some consumer audiences. **State
clearly that these are general suggestions, not data from the user's own analytics** — WoopSocial
has no analytics surface yet, so the timing isn't personalized. When analytics ships, this can be
tuned to real performance. Don't present generic timing as if it were the user's data.

## The batching workflow (why this skill saves time)

The efficiency comes from doing like with like:

1. **Plan the whole period** (this skill) — all slots, briefs, calendar.
2. **Produce in batches by format** — write all captions together, script all Reels together,
   make all graphics together. Context-switching is the tax; batching removes it.
3. **Schedule the batch** — hand the approved set to `scheduling-and-queue` once.

Plan once, make in batches, schedule once — instead of starting from zero every day.

## Calendar output

Present the plan as a scannable calendar table the user can review and edit before anything is
scheduled:

| Date | Platform | Pillar | Intent | Format | Hook angle | Status |
|---|---|---|---|---|---|---|

Make it editable and reviewable — the user should be able to spot and fix a wrong day, a doubled
promo, or a format clash *before* it's committed.
