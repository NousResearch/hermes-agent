# Post Brief — the unit the content skills execute

The plan's value is that every slot is a **brief**, not a vague idea. A brief is specific enough
that `caption-writer`, `reels-script`, or any content skill can turn it into a finished,
on-voice post with no further conversation. "Post about productivity, Tuesday" is not a brief.

## The brief schema

Each calendar slot carries:

```
- date / time (+ timezone)      when it goes out
- platform(s)                   where (and per-platform variants if fanning out)
- pillar                        which theme it belongs to
- goal / intent                 educate / entertain / inspire / connect / promote (+ the metric)
- format                        carousel / Reel / single image / text / thread / story
- hook angle                    the opening direction (drafted via hook-writer)
- core idea                     the one point or story the post makes
- CTA                           the single action (matched to goal + platform)
- asset / creative tool         photo needed? video via Veo? graphic via Nano Banana? none?
- repurposed from               source idea, if adapted from another post
- status                        planned → drafted → approved → scheduled
```

A good brief answers "what is this post, exactly?" — not "what topic is it near?"

## How content skills execute a brief

The plan is the spine; the content skills fill it:

1. `hook-writer` → sharpens the **hook angle** into the actual opening (for the format).
2. `caption-writer` / `reels-script` / `thread-writer` → writes the finished post from the
   brief, in the brand voice, hitting the goal and CTA.
3. Creative-tool mini-skills (`veo-3`, `nano-banana`, …) → produce any **asset** the brief
   calls for.
4. `scheduling-and-queue` → schedules the approved post at the brief's date/time.

Because the brief already fixes goal, format, hook angle, and CTA, the content skill isn't
guessing — it's executing. That's what makes a batch fast *and* consistent.

## Brief quality checklist

A slot is ready when:

- [ ] It names **one** clear idea and **one** goal.
- [ ] The **format** suits the idea and platform.
- [ ] There's a real **hook angle**, not just a topic.
- [ ] The **CTA** matches the goal and the platform's mechanics.
- [ ] Any **asset/tool** dependency is flagged (so production isn't blocked later).
- [ ] It inherits the brand's **voice and guardrails**.

## Level of detail

Default: write the **brief** for every slot, plus fully draft a few exemplars so the user can
see the voice and approve the direction. Write *all* the final copy only if asked — otherwise
the content skills do that, on demand, from the briefs. This keeps planning fast and avoids
producing a month of copy the user may want to reshuffle first.
