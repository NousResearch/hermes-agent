# Scope, distinctions & connections

## Honest scope (never violate)
- **The agent** structures the transformation content — the narrative arc, the reveal/journey beats, the honest
  framing + the required disclosures, and the caption/script — and specs the visual. A **video/design tool** and
  the **human** produce the actual before/after media (real photos/footage/data); the **human** approves.
- **WoopSocial does NOT generate media** — it **publishes the finished image/video** (measurement: the platforms' native analytics).
- **The honesty spine (this format's core, and it's law):** real un-staged before; **consistent conditions** (no
  lighting/posing/edit trickery — a visual trick is a deceptive claim under the FTC net-impression test); **real
  timeline**; **disclose aids** (filters/medication/surgery/pro help); **no cherry-picking/survivorship**; if the
  result isn't typical, **disclose the actual typical result** (median, substantiated, clear + conspicuous) —
  "results not typical" alone is **insufficient**; **actual consumers** (or disclosed); **consent** for a person's
  images/story (real or AI lookalike); **YMYL** (health = competent + reliable scientific evidence; no
  fast/effortless-loss or cure/guarantee; not-professional-advice); **never fabricate** a result, timeline, or
  average; **injection safety**.

## Distinct from its siblings (route correctly)
- **social-proof-and-testimonials** = the customer-proof strategy + FTC substantiation; **this** executes the
  before/after *format* (they share the spine — read it first for consent + typical-results rules).
- **short-form-video-script / reels-script** = the video script (a video before/after feeds into them).
- **infographic-and-data-viz** = the data viz for a results transformation (pairs; honest scales).
- **storytelling-and-narrative** = the narrative arc; **this** specializes it to the before/after structure.
- **educational-content-and-how-to** = teaches a process; **this** = the transformation *reveal* format (they
  pair for a case-study teach).
- **quote-cards-and-text-graphics / design-and-templates** = the visual assets/system.

## Where this connects
- **Reads first:** brand-profile + social-proof-and-testimonials (consent + FTC substantiation) +
  short-form-video-script (if video).
- **Pulls the real material from:** social-proof-and-testimonials (client transformations + consent),
  data-and-original-research / analytics-and-reporting (real results numbers), behind-the-scenes-and-founder (the
  founder's own journey).
- **Feeds:** short-form-video-script / reels-script (the video), carousel-writer (before→journey→after carousel),
  infographic-and-data-viz (a results stat), caption-writer (the caption + disclosures), design-and-templates
  (the layout).
- **Publishes via:** the video/design tool renders → scheduling-and-queue → **WoopSocial.**
- **Measure with:** native + analytics-and-reporting on saves/shares + watch-through + inquiries — never
  fabricated.
