# Transformation types, the honesty checklist & worked examples

## Transformation types (the craft varies; the honesty doesn't)
| Type | The reveal | Highest-risk honesty issue |
|---|---|---|
| Fitness / weight / health | body/photo | FTC + YMYL: typical-results, disclose aids (GLP-1/surgery), substantiation |
| Beauty / skin / hair | photo | filters/retouching disclosure; consistent lighting; realistic timeline |
| Business / results | numbers | survivorship, real tracked numbers, "not typical" if outlier |
| Skill / progress | work samples | real timeline, don't hide the reps/setbacks |
| Space / design makeover | photo/video | consistent framing; disclose staging |
| Product (used vs after) | photo/demo | no misleading conditions; real usage |

## The honesty checklist (run before publishing — this is the deliverable)
Before is real + un-staged ✓ · same angle/lighting/framing for both ✓ · real timeline shown (not implied faster) ✓
· aids disclosed (filters/meds/surgery/pro help) ✓ · no cherry-pick / no survivorship ✓ · if not typical, actual
typical result disclosed (median, substantiated, clear + conspicuous) ✓ · actual consumers (or disclosed) ✓ ·
consent for the person's images/story ✓ · numbers real + tracked ✓ · YMYL: not-professional-advice, no
cure/guarantee ✓.

## Structure that works (before → journey → after → tie)
Hook on the reveal or the relatable before → the journey (what changed it + a real setback + the real timeline) →
the honest reveal (consistent conditions) → the required disclosure → the viewer takeaway. Route the video to
`short-form-video-script`, the carousel to `carousel-writer`, the numbers to `infographic-and-data-viz`.

## Worked example A — "Blunt indie founder" (business, honest outlier)
"a client went 2k → 41k followers in 6 months. real numbers, and no — this is NOT typical (most clients we've
tracked land ~3-8k in that window; median ~5k). what actually did it wasn't a hack: 6 months of 3 posts a week,
one that flopped hard in month 2, and fixing the offer. here's the exact process." — real, non-survivorship,
median disclosed, journey shown.

## Worked example B — "Warm bookkeeping studio" (client, consented, no numbers game)
"With her okay: a client came to us 8 months behind and dreading every email. Same desk, same messy shoebox of
receipts — here's month 1 vs now. It wasn't magic or fast; it was one 20-minute weekly habit and a rough January.
Results like this aren't guaranteed, but the habit is the part anyone can copy." — consented, honest timeline, no
cure/guarantee, attainable takeaway.

## Never
Stage/exaggerate the before · use different lighting/posing for after · imply an unrealistic timeline · hide
filters/meds/surgery/pro help · cherry-pick or show only survivors · say only "results not typical" for an
outlier · use stock/other people's before-afters as clients · fabricate an average · post a client without
consent · claim WoopSocial generates the media.
