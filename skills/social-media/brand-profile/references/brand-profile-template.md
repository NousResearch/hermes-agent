# Brand Profile Template

This is the exact structure to write to `brand-profile.md`. Keep it **tight and skimmable** —
other skills read it on every task, so favor specifics over prose. Delete sections that
genuinely don't apply (e.g., compliance for an unregulated business), but keep the order.

Copy everything below the line into `brand-profile.md` and fill it in.

---

---

## How other skills should read this

Treat **Voice → "We sound ___, never ___"**, **Guardrails**, **Operational defaults**, and
**Show-don't-tell examples** as the highest-signal sections — check them on every task.
Identity, Positioning, and Audience set the strategy; Proof and Offers/CTAs feed the
specifics and the close. Tool skills (avatars, voice, music, image generation) must check
**Operational defaults** before generating anything synthetic. If a section is empty, ask
the user rather than inventing content to fill it.
