# Launch plan templates + two worked examples

## One-page launch brief (write first, share with everyone)
```
WHAT is launching:            [product/series/feature]
WHO it's for:                 [audience]      WHY now: [the hook/timing]
PRIMARY GOAL + metric:        [one goal]      LAUNCH TYPE: soft / hard / phased
PLATFORMS (1-3):              [...]           LAUNCH DATE: [date/time + tz]
THE OFFER + urgency:          [credible scarcity/bonus/deadline]
CAMPAIGN HUB (all links ->):  [waitlist/landing page URL]
WHO OWNS WHAT:                [content / email / press / community / publish via WoopSocial]
```

## Week-by-week map (compress/expand to the runway)
```
W-6..-4  TEASE: problem-awareness + transformation tease; open the waitlist + hub; BTS
W-3..-2  TEASE->PROOF: beta group, proof drops, founder story; personalized press/creator outreach
W-1      RAMP: countdown posts, "something's coming", priority-access email, readiness checks
DAY 0    LAUNCH: coordinated push (one morning), one CTA, drop/countdown/live, waitlist announce email
W+1..+4  REINFORCE: testimonials/UGC/demos, objection content, onboarding nudges; debrief + numbers
```

## Phase x platform grid (repurpose, don't copy)
```
Per phase, 1-2 HERO posts + evergreen support. One 60s asset -> 9:16 TikTok + 15s IG Story + 30s LinkedIn cut.
Channels reinforce (IG -> TikTok -> hub). All scheduled via WoopSocial (SCHEDULE_FOR_LATER, per-platform fields).
```

## Waitlist + urgency mechanics (credible only)
```
Waitlist promise: "Get first access + a launch-week bonus" (specific > "join the waitlist"). Referral: unique link + reward.
Urgency: real scarcity (first 100) / meaningful bonus / honest deadline + clearly-communicated price increase.
NEVER: resetting "24h left" timers, invented signup counts, fake "selling fast". Credible urgency converts better.
```

## Worked example 1 — indie SaaS feature, phased (blunt indie-founder voice)
```
GOAL: 300 activations in launch week. Type: phased. Platforms: X + LinkedIn. Hub: waitlist landing page (external).
TEASE: 3 weeks of build-in-public BTS + waitlist ("early access + founder pricing"). LAUNCH: one Tuesday-morning
coordinated push, one CTA (start free), live demo. WoopSocial schedules every post; email via my ESP. REINFORCE: user
demos + objection threads. YIELD: activations vs 300, per-channel. No fake scarcity - founder pricing ends honestly Friday.
```

## Worked example 2 — small product drop, soft launch (warm studio voice)
```
GOAL: sell the first 100 units. Type: soft (waitlist + VIP first). Platforms: IG + email. TEASE: packaging/naming BTS,
waitlist with a real first-100 bonus, one link-in-bio hub. LAUNCH: a timed drop with a countdown sticker + a go-live,
one CTA. WoopSocial publishes the coordinated IG posts; checkout + emails external. REINFORCE: customer photos (UGC) +
restock interest. YIELD: units vs 100 + waitlist conversion. Urgency is the genuine first-100 bonus, nothing invented.
```

Both: one goal + brief; three-phase arc as one story; credible urgency; coordinated publish via WoopSocial;
hub/email/checkout external; measured per-channel; nothing fabricated.
