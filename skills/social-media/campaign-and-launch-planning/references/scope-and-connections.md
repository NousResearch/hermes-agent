# Scope, distinctions + connections

campaign-and-launch-planning is a **strategy/orchestration skill** — it plans the time-boxed campaign (goal,
phases, week-by-week map, the brief, the per-platform posts) and **WoopSocial schedules + publishes the
coordinated social posts** on the timeline. The agent **plans + writes + schedules the social side**; the
**waitlist/hub, email, ads, checkout, press, and livestream are external/native.**

## Honest scope (never violate)
- **The agent** plans the campaign, writes the **one-page brief** + the **week-by-week map** + the **posts**,
  and designs the phases/urgency/hero moments.
- **WoopSocial schedules + publishes the coordinated social posts** across the connected platforms on the
  planned timeline (`SCHEDULE_FOR_LATER` + per-platform fields; validate via `platform-specs-and-validation`).
  This is the launch's coordinated-publish engine.
- **WoopSocial does NOT:** host the **waitlist / landing page / campaign hub**, send the **email sequence**
  (an ESP does), process **checkout / the sale**, run **paid ads**, do **press/creator outreach** (human/DM),
  run the **livestream** (native — `livestream-and-realtime`), or measure **conversions/ROI** (native
  analytics + the store).
- **Credible urgency only** — no fake/resetting countdowns, no invented scarcity or signup counts. **Never
  fabricate** anticipation or results. **Coordinate, don't spam** (hero moments, not hourly blasts).
  **Verify-quarterly.**

## Distinct from its siblings
- **campaign-and-launch-planning (this)** — the **time-boxed spotlight campaign** (phases toward one goal).
- **content-calendar** — the **ongoing always-on cadence** (the lights, not the spotlight).
- **goals-and-kpis** — the **targets** a campaign serves (read first).
- **collabs-and-cross-promotion** / **lead-magnets-and-funnels** / **email-and-newsletter** /
  **link-in-bio-and-traffic** / **livestream-and-realtime** / **ugc-and-influencer** — the **pieces a launch
  orchestrates**, each owned by its skill.

## Where this connects
- **Reads first:** `brand-profile` (audience/voice), `goals-and-kpis` (the goal + metric);
  `competitor-analysis` (positioning/timing).
- **Orchestrates:** `lead-magnets-and-funnels`/`link-in-bio-and-traffic` (the hub/waitlist),
  `email-and-newsletter` (the parallel sequence), `collabs-and-cross-promotion`/`ugc-and-influencer` (press/
  creator/partner moments), `livestream-and-realtime` (the launch live), the **format skills** +
  `thumbnail-design` (the assets), `cross-platform-repurposing` (one asset → many cuts).
- **Publishes via:** `scheduling-and-queue → WoopSocial` (the coordinated timeline) +
  `platform-specs-and-validation` (validate each post); `content-calendar` reserves the campaign's slots.
- **Measures with:** `analytics-and-reporting` (per-channel numbers vs targets) + the store/landing page;
  `experimentation-and-ab-testing` (A/B the headline/creative). **Hub, email, ads, checkout, press, live + conversion
  measurement stay external/native.**
