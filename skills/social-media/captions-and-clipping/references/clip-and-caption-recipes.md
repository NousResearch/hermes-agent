# Clip selection, captions + two worked examples

## Picking clippable moments (the human part)
A good clip candidate is: a **complete thought** (no missing setup), a **hook in the first 1–3s**, a
**standalone payoff** (makes sense with zero context), and **on-strategy** (matches a content
pillar). Reject AI picks that are just loud/animated but don't stand alone. Expect to keep ~3 of 10
auto-clips without rework.

## Caption spec (sound-off default)
- Word-by-word / karaoke highlight; ~2 lines per frame; 32–42 chars/line; inside safe zones, clear of
  the platform UI.
- Review transcription for names, brand terms, numbers, jargon — fix before render.
- On-brand font/color (brand-profile); Submagic for the most polished animated styling.

## Tool division of labor
| Stage | Tool | Note |
|---|---|---|
| Find/cut at scale (any genre) | Opus Clip (ClipAnything) | virality score = hint; ~70% need cleanup |
| Caption styling | Submagic | best animated captions; ≤30-min source |
| Free hands-on edit | CapCut | manual; watch for watermark/commercial-asset limits |
| Full transcript-native edit | Descript | edit the whole episode, then clip |

Common pattern: **Opus Clip to cut → Submagic to caption → clean export.**

## Recipes
- **Podcast/webinar → Shorts batch:** Opus Clip ClipAnything on the full recording → human-pick the
  self-contained moments → Submagic captions → clean export → each routed to youtube-shorts /
  reels-script / tiktok-script for its hook → scheduling-and-queue.
- **Long YouTube → Reels/TikTok:** clip, reframe 9:16, caption, **strip watermark**, re-version the
  hook per platform (don't copy-paste); see cross-platform-repurposing.
- **Evergreen reuse:** re-clip/re-caption a strong old long-form months later — see content-recycling.

## Worked example 1 — podcast clip (blunt indie-founder voice)
```
SOURCE: 52-min founder podcast → YouTube Shorts + Reels (9:16)
PICKED MOMENT (0:00 hook): "I almost missed four grand in tax. Here's the catch."
WHY: complete thought, standalone, on-pillar (freelance finance). Virality score said 38 — shipped anyway.
CAPTIONS: word-by-word, dry style, brand mono font. Reviewed "€4,000" + "set-aside".
CLEAN: no watermark. HOOK/CAPTION → reels-script / youtube-shorts. DISCLOSURE: AI-edited label.
```

## Worked example 2 — webinar clip (warm studio voice)
```
SOURCE: 40-min tax webinar → Reels + TikTok
PICKED MOMENT (0:00): "If tax season makes your stomach drop -- here's the one rule."
REFRAME: 9:16, keep presenter centered; trim the "um" intro.
CAPTIONS: soft animated, 2 lines, emoji off (brand is calm). Transcript reviewed.
CLEAN export. BRIDGE: pin the full webinar (youtube-long-form). DISCLOSURE: AI-edited.
```

Both: read brand-profile + voice-builder first; human-selected self-contained clips; captioned for
mute; watermark-free; hook/caption handed to the platform writer; publish via scheduling-and-queue →
WoopSocial. Generative B-roll → veo-3 / ai-video; narration → ai-voiceover; avatars → heygen.
