# Clipping + caption tools 2026 — verified

*Volatile. Re-verify quarterly against each tool's /pricing and docs. Prices checked ~June 2026.*

## The universal pipeline (every tool, same five stages)
transcribe → an LLM picks the moments that matter → crop/reframe to follow the speaker → draw
word-by-word captions → render. Knowing this, you can mix tools per stage rather than marry one.

## Opus Clip — find + cut at scale
- **ClipAnything 2.0** — moment-detection across any genre (not just talking-head) from visual/audio/
  sentiment cues; 2.0 added **natural-language search** ("find every time I mention pricing").
- **ReframeAnything** — subject-tracking 9:16 auto-reframe (manual tracking available).
- Auto-captions ~97% accuracy (25+ languages); **Virality Score 0–99**.
- Pricing: Free (60 min/mo, **watermark**, 3-day clip expiry, no editing) · Starter $15/mo (150
  credits, watermark removed) · Pro ~$29/mo. **1 credit = 1 source minute.** API **gated to Business**.
- **Honest caveat:** Opus's own help center has a "how to avoid 0 views" guide. Reviews flag the
  virality score as **unreliable** (clips rated 40 can beat 85), clip-selection accuracy ~60–70% on
  solo-speaker dropping to ~40% multi-speaker, and **~70% of generated clips need manual cleanup.**

## Submagic — best-in-class captions (not the clipper for long sources)
- **Animated/word-by-word captions**, emoji, trendy styles; ~98.9% accuracy, 50+ languages; magic
  B-roll; AI clip detection via a Magic Clips add-on.
- **Per-video source caps by tier:** ~2 min (Starter $19) / ~5 min (Pro $39) / **~30 min max
  (Business+API $69)** → **cannot clip a full podcast** on any plan; API on the Business+API tier.
- The reviewer pattern: **Opus Clip (or your own cut) to find the clip, then Submagic to caption it.**

## CapCut — free, manual, hands-on
- Best **free** full editor (effects, transitions, templates, music, auto-cut, noise removal,
  animated captions); mobile + desktop. **No AI clip detection** — you select clips manually
  (~30–60 min/video vs 2–5 min for AI tools).
- **Cautions:** ByteDance-owned (privacy); **commercial-use restrictions on some assets**; some
  exports/templates add a **CapCut watermark/outro**; some features need a live connection.

## Cross-cutting truths
- **AI clipping is a force multiplier, not a replacement** — human judgment still owns brand voice,
  narrative flow, and on-strategy clip selection. A 60-min video → ~10–30 clips.
- **Watermarks kill cross-posting.** A TikTok/CapCut watermark trips the Originality Score on Reels/
  Shorts and throttles reach. **Export clean/native.**
- **Captions are for mute viewing** — word-by-word, ~2 lines, safe zones; review transcription for
  names/jargon; caption text is indexed for search.
- **Disclosure:** EU AI Act transparency for AI-edited/generated video applies **from August 2026** —
  label AI-edited clips (and per TikTok auto-disclosure / YouTube Altered-Content).
- Other tools in the category (context): Reap (API/CLI/MCP, multilingual), Vizard, Klap, Choppity,
  Ssemble, Descript (transcript-native full edit). Pick by stage, verify-quarterly.
