# Collab formats, cross-promo plan + two worked examples

## Format menu (by effort / goal)
| Format | Effort | Best for | Indicative lift |
|---|---|---|---|
| Shoutout swap / featured-channel | low | quick cross-pollination, smaller channels | slow steady (shoutouts fade — pair with value) |
| Mutual Story shoutout | low | awareness, follower nudge | small spike |
| Guest appearance / podcast swap | medium | authority, interview/Q&A | single-upload spike |
| Duet / stitch (TikTok) / Shorts chain | medium | algo signal, fast turnaround | spike + reach |
| **Joint giveaway** | medium | awareness + follower growth | follower spike (combined prize) |
| **Joint video** (YouTube native Collaboration: one upload, up to 5 channels credited — or both upload) | high | max reach, all audiences see it | ~50–300 subs/creator |
| **Collab series** (3–6 over months) | high | community + binge-subscribe | ~200–1,000+/creator |
| **Live co-stream / premiere** | high | shared room, deep engagement | spike + loyalty |
*Shared VALUE beats shared exposure — co-create, don't just shout out.*

## Cross-promo plan checklist (agree BEFORE creating)
```
[ ] Format + concept (low-risk for a first collab)
[ ] Who does what (film/edit/thumbnail/upload)
[ ] Upload timing (both sides coordinated)
[ ] The ONE CTA ("check out [Partner]'s version on their channel")
[ ] What each says in the shoutout (mention 3-5x; in title/first ~50 chars)
[ ] Success metric (subs/followers per source, referral CTR)
[ ] Disclosure? only if money/free product changed hands (then it's a sponsorship)
```

## Outreach pitch template (human sends it — no DM surface in WoopSocial)
```
Hi [Name] - I'm [you], I make [niche] for [audience]. Love your [specific recent piece].
Our audiences overlap but don't compete, and we're a similar size. Idea: [specific low-risk format].
You'd do [their light lift]; I'd handle [your lift]. Aim to film around [3-4 weeks out]. Open to it?
```
Follow up once, friendly, after ~a week if no reply.

## Mention / CTA pattern
Title or first ~50 chars include the partner's name/handle. One CTA, not five. "If you like [topic], go
check out [Partner] — they cover [their specialty]." Both sides use the same CTA + tracking param.

## Worked example 1 — joint giveaway, two complementary brands (blunt indie-founder voice)
```
FIT: you (meal-prep, 8k) + a complementary non-competing kitchenware maker (~6k). PLAN agreed pre-launch:
follow both + tag a friend to win a combined prize; both post the same day; one CTA. WoopSocial publishes
each side's OWN giveaway post to their own account on the schedule. Track followers/source. No payment -> no #ad.
```

## Worked example 2 — guest swap, first collab (warm studio voice)
```
FIT: two bookkeeping-adjacent creators, similar size, shared values. Low-risk first format: a guest Q&A each
way. Agreed up front: who hosts, upload dates, the CTA, what each says. Each records their own; WoopSocial
publishes each creator's own teaser + episode post, partner mentioned in the title. Reviewed subs/source after.
```

Both: complementary same-size genuine partner; plan agreed before creating; shared value; mention + one CTA;
coordinated publish (each side own posts); per-source measurement; disclosure only if money/product changed
hands; metrics native (never fabricated).
