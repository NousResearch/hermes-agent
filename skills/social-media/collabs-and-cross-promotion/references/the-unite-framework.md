# The UNITE framework — run a creator collab that grows both sides

A collab only delivers mutual growth when the **fit is real, the plan is set before anyone creates, and the
cross-promo actually runs.** UNITE structures that. The agent picks the partner, plans the cross-promo, and
writes both sides; **WoopSocial publishes each partner's own posts** on the coordinated schedule; the
**co-created content + the relationship are native/human.**

## U — Understand the fit
- **Complementary, NOT competing** (overlapping-but-not-identical audience). **0.5–2× your size** (equal
  value exchange). **Values-aligned + authentic** — Connection / Personality / Authenticity; **audiences
  spot fakes.** If you'd have to convince the audience the pairing makes sense, it probably doesn't.

## N — Negotiate the plan up front
- **Before anyone creates**, agree: **format**, **who does what**, **upload timing**, the **CTA**, and
  **what each says** in the shoutout (plus length/thumbnail/edit expectations). **Reach out 3–4 weeks
  ahead**; pick a **low-creative-risk** format for a first collab. **Joint goals + clear expectations ≈ 70%
  more likely to succeed.**

## I — Invest in shared value
- **Co-create real value** — match format to effort/goal (low: shoutout/featured-channel; medium: guest/
  duet/giveaway; high: joint video/series/live). **Shared value beats a bare shoutout** (shoutouts barely
  move the needle now). **Quality protects both** channels. *(The co-created content — joint video, live,
  duet, IG Collab — is produced **natively/with the partner**, not by WoopSocial.)*

## T — Tag + cross-promote
- **Mention/tag the partner** naturally (3–5×) and in the **title / first ~50 chars**. **One clear CTA**
  ("check out their version on [channel]"). **Coordinated publishing** so both sides go live on schedule —
  this is where **WoopSocial publishes each partner's own posts** to their own accounts. **~1–2 collabs/
  month.**

## E — Evaluate + escalate
- Track **per-source**: referral CTR, **new subs/followers per source**, retention from referred traffic.
  If it works, **escalate the partnership** (shoutout → giveaway → content collab → co-product) and nurture
  it for the next one. **Never fabricate** results.

## The partnership brief a request should fill
```
FIT: partner is complementary (not competing), 0.5-2x size, values-aligned, genuine
PLAN (pre-creation): format + who-does-what + timing + the CTA + what each says; 3-4 weeks lead; low-risk first
VALUE: the co-created format (native/with partner); shared value > bare shoutout; quality bar both sides
CROSS-PROMO: mention/tag partner (title/first 50 chars) + one CTA; coordinated publish (WoopSocial, each side own posts)
MEASURE: per-source CTR/subs/retention; escalate if it works; disclosure only if money/free product changed hands; never fabricate
```
