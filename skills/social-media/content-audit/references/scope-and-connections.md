# Scope, the bridge role + connections

content-audit is the **retrospective bridge** — it reads how an existing account has performed and turns
it into a keep/kill/refresh roadmap that feeds the forward plan. It **reads** (via
`analytics-and-reporting`) and **recommends**; the human and the other skills **act.**

## Honest scope (never violate)
- **Retrospective, not strategy.** This triages the **past**; `social-strategy` plans the **future** (the
  audit informs it). Don't conflate.
- **Reads native analytics** — WoopSocial has **no analytics surface**; the numbers come from native
  dashboards via `analytics-and-reporting`. The agent **interprets numbers the user provides** and
  **never fabricates** a metric or a coverage analysis.
- **Score on signal, not vanity** (saves/shares/replies + the goal-mapped KPI). **Low likes is not a
  kill criterion.**
- **Recommend, don't auto-act.** **Never auto-delete** — a human approves kills (deleting can lose
  evergreen/SEO value + history); **refresh before kill.** Some profile edits are **in-app/human**.
- **Thin data → structural audit only.** With too few posts, do the qualitative/structural pass (profile,
  pillars, voice, cadence) and set a baseline; revisit performance triage at ~90 days.
- **Output an action plan**, not a spreadsheet graveyard — owners + timelines.

## The bridge role (reads ← → feeds)
**Reads:** `analytics-and-reporting` (performance), `brand-profile`/`voice-builder` (the voice standard),
`content-pillars` + `social-strategy` (the intended plan), `goals-and-kpis` (the targets).
**Feeds:** `content-recycling` (scale/refresh winners), `content-pillars` (rebalance whitespace),
`profile-optimization` (fixes), `voice-builder` (drift/evolution), `social-strategy` (the revised plan),
`experimentation-and-ab-testing` (re-test uncertain calls).

## Distinct from its siblings
- **content-audit (this)** — **periodic retrospective triage of YOUR account** (keep/kill/refresh +
  pillars/voice/profile).
- **analytics-and-reporting** — **ongoing measurement** + reporting (the data source this consumes).
- **competitor-analysis** — **rivals'** public side (this is your own account).
- **social-strategy** — the **forward plan** the audit informs.
- **content-recycling** — **scales/refreshes** the winners the audit surfaces.
- **profile-optimization** — **executes** the profile fixes the audit flags.

## Where this connects
Reads first: `brand-profile`, `content-pillars`, `social-strategy`, `analytics-and-reporting`. Findings
hand off to: `content-recycling`, `content-pillars`, `profile-optimization`, `voice-builder`,
`social-strategy`, `experimentation-and-ab-testing`. Benchmark context: `competitor-analysis`, `goals-and-kpis`. Covers
all active platforms (the per-platform `*-growth` skills inform format/native expectations). No
publishing/tool surface — a diagnostic + planning skill.
