# The AUDIT framework — find the signal under the busy-ness

Posting consistently isn't the same as making progress. AUDIT is the retrospective reality-check that
turns a busy-but-flat account into a ranked keep/kill/refresh roadmap. It **reads** the past (native
analytics, via `analytics-and-reporting`) to **inform** the future (`social-strategy`).

## A — Assemble the inventory
- Pull **~90 days** (3–6 months) of output across active platforms. List every post by **platform,
  format, pillar, date/time**, and its native metrics. Pull the plan (`content-pillars`,
  `social-strategy`) you're auditing **against.**

## U — Uncover the signal
- Score on **saves, shares, replies + the goal-mapped KPI** — not likes/impressions/followers.
- Surface **top + bottom performers** and the **patterns**: which formats, posting times, and topics
  win or lose. (Numbers come from `analytics-and-reporting`; never fabricate them.)

## D — Diagnose pillars, voice & profile
- **Pillars:** map output to pillars → over/under-served + whitespace (`content-pillars`).
- **Voice drift (both ways):** off-brand drift, *or* winners signalling the voice should evolve
  (`voice-builder`).
- **Profile:** bio/keywords, links, pinned/featured, handle/visual consistency, native formats
  (`profile-optimization`). Plus **cadence** (consistent, not ghosting/overwhelming).

## I — Iterate: keep / kill / refresh
- **KEEP/scale** winners → `content-recycling`. **KILL/cut** chronic, off-brand, dead/cross-posted
  formats (human approves). **REFRESH** good-but-dated/underseen → update + re-publish. **Refresh before
  kill.**

## T — Turn into a roadmap
- Output **strengths / weaknesses / opportunities**, split **quick wins vs long-term**, with **owners +
  timelines.** Feed `social-strategy` (the new plan), `content-recycling` (refresh winners),
  `content-pillars` (rebalance), `profile-optimization` (fixes), `experimentation-and-ab-testing` (re-test). **No
  spreadsheet graveyard.**

## The audit brief a request should fill
```
INVENTORY: ~90 days, every post by platform/format/pillar/time + native metrics; the plan to audit against
SIGNAL: top/bottom on saves/shares/replies + KPI; patterns by format/time/pillar
DIAGNOSE: pillar whitespace; voice drift (both ways); profile fundamentals; cadence
TRIAGE: keep/scale · kill/cut · refresh/revive (refresh before kill; human approves kills)
ROADMAP: strengths/weaknesses/opportunities; quick wins vs long-term; owners + timelines
HANDOFF: social-strategy / content-recycling / content-pillars / profile-optimization / experimentation
```
