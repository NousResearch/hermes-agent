# Triage rules, scorecard + two worked examples

## Keep / kill / refresh decision rules (signal-based)
| Verdict | Signals | Action |
|---|---|---|
| **KEEP / scale** | above-median saves/shares + on-goal + on-brand | double down; add to recycle queue (`content-recycling`) |
| **REFRESH / revive** | good idea but dated info, weak hook, underseen, or cross-posted/non-native | update hook/data/format + re-publish |
| **KILL / cut** | chronic low saves/shares across reps, off-brand, dead format, misleading | stop making it; human approves any deletion |
> **Refresh before kill.** Low *likes* alone is never the kill criterion — check saves/shares + the goal.
> Don't auto-delete (evergreen/SEO value + engagement history).

## Pillar-coverage map
List your pillars → tally % of last-90-days posts per pillar → compare to intended mix. Flag
**over-served** (cut back) and **under-served / whitespace** (a winning pillar starved of posts is the
highest-leverage fix). → `content-pillars`.

## Voice-drift check (both directions)
1. Do recent posts match `brand-profile`/`voice-builder`? (drifted off-brand → realign.)
2. Are your **top performers** off the documented voice? (the voice may need to **evolve** toward what
   works → update `voice-builder`.) Record which it is.

## Profile-fundamentals checklist (compound, zero spend)
Bio clear + keyworded · links work + drive the right destination · **pinned/featured = current winners**
· handle + visuals consistent across platforms · native formats used · contact/CTA present. → `profile-optimization`.

## The audit scorecard (output)
```
STRENGTHS: what's working (winning pillars/formats/times)
WEAKNESSES: chronic losers, whitespace, voice drift, profile leaks
OPPORTUNITIES: refresh candidates, under-served winning pillars, format shifts
TRIAGE: keep[..] / refresh[..] / kill[..]
ROADMAP: quick wins (this week) vs long-term (this quarter) + owners + timelines
```

## Worked example 1 — busy-but-flat account (blunt indie-founder voice)
```
INVENTORY: 90 days, 78 posts, 3 platforms. PLAN: 2 pillars (tax tips, founder BTS).
SIGNAL: top 10 by saves/reach = all "one-rule" tax Reels at 9am; bottom = reposted landscape clips.
DIAGNOSE: tax pillar over-delivers, BTS starved (whitespace); cross-posted clips = non-native; bio link dead.
TRIAGE: KEEP one-rule Reels; REFRESH the BTS angle into vertical; KILL landscape reposts. PROFILE: fix bio link, pin top Reel.
ROADMAP: quick win = fix link + pin today; long-term = 2 BTS Reels/wk. -> content-recycling, profile-optimization.
```

## Worked example 2 — voice-drift finding (warm studio voice)
```
FINDING: the 3 best-performing posts are warmer + more personal than the documented "neutral professional" voice.
READ: this is voice-evolution signal, not off-brand drift -> propose updating voice-builder toward the warmer tone.
ALSO: "calm bookkeeping" pillar is under-served despite strong saves -> rebalance (content-pillars).
ROADMAP: quick win = 2 warmer posts this week to confirm; long-term = revise voice guide + pillar mix.
```

Both: read the plan + native analytics first; score on signal; refresh before kill; human approves
deletions; end in a quick-wins-vs-long-term roadmap that hands off — never a spreadsheet graveyard.
