## How downstream skills read this

- **`batch-content-plan`** spreads posts across these pillars, tags every slot to one, and uses
  the **example angles** as starting ideas and the **mix split** for balance.
- **Content skills** (`caption-writer`, `reels-script`, …) use the pillar's *angle* and *goal* to
  shape each post, and the **draws-on** assets/proof for substance.
- If a pillar's **example angles** run dry over time, that's the signal to refresh it — re-mine
  the brand profile or run this skill again.

Keep the signature pillar prominent: it's what the brand is building recognition for.
