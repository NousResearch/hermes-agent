# The recycling system + two worked examples

## Build the vault (the queue of proven winners)
Keep a simple library so recycling is a 30-minute habit, not a scramble. Track per asset:

| Field | Why |
|---|---|
| Asset + pillar | what it is, which content pillar |
| Original date | so you can space the cycle |
| Native metric | the proof it's worth recycling (saves / CTR / follows) |
| Evergreen? | exclude time-bound |
| Last recycled | enforce ~90–120-day spacing |
| Variants tried | which hook/format/CTA, and what won |

Pull winners from **native analytics** (WoopSocial has no analytics surface). Audit by goal.

## Cadence (verify-quarterly)
| Spacing | ~90–120 days per asset before its next cycle |
| Mix | sprinkle recycled among native new content — don't read as repetitive |
| Don't | dump a backlog at once, or repost identically |

## Refresh tactics (pick at least one per cycle)
New hook / rewritten first line · new opening visual · flipped format (carousel ↔ Reel ↔ text ↔ quote
card) · updated stat or example · seasonal angle · new proof point · different CTA. **Change one major
variable per variant** so you learn what moved the metric.

## Recipes
- **Top-post refresh:** take a proven post → new hook + new opening visual → re-queue 90 days later.
- **Evergreen → new format:** a high-save carousel → a Reel (route the clip via
  `captions-and-clipping`) or a text post; the **insight** carries over.
- **Update-and-republish:** an old "how the algorithm works / our pricing" post → update the figures →
  re-publish as "2026 update."
- **Seasonal re-run:** a general planning post → "Q4 Boost Guide" with current dates.

## Worked example 1 — top-post refresh (blunt indie-founder voice)
```
RESURFACE: "Move 30% of every invoice to a Tax account" — top saves last quarter, evergreen.
REFRESH: new hook "Almost missed €4k in tax. One missing step." (old opener retired);
  new opening visual (two-account screen-record). Variable changed = HOOK.
UPDATE: confirm the €4k figure + any tax-year reference still current.
SCHEDULE: ~100 days after original; IG + LinkedIn, native format each.
EVALUATE: watch saves vs the original; if it wins, re-queue in Q4.
```

## Worked example 2 — update-and-republish (warm studio voice)
```
RESURFACE: "How the Instagram algorithm ranks you" — strong reach, but 18 months old (facts drifted).
REFRESH: reframe as "What changed in 2026" + new clean template.
UPDATE: replace old ranking factors/figures with current ones; verify before publishing.
SCHEDULE: now (relevance-driven); carousel on IG, text on LinkedIn.
EVALUATE: track shares + profile visits; one-variable test on the CTA next cycle.
```

Both: read brand-profile + voice-builder first; recycle the **insight** refreshed (not identical);
facts updated; spaced deliberately; winners chosen from native analytics. The agent drafts; a human
reviews; publish via `scheduling-and-queue → WoopSocial` (edits = delete + recreate).
