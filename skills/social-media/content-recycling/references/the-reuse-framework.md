# The REUSE framework — recycle the insight, not the artifact

Most accounts treat content as disposable: publish once, never again — wasting their best assets.
REUSE turns proven evergreen content into multiple cycles, **refreshed each time** so it's a new asset
(not a stale duplicate Meta's 2026 rules would throttle).

## R — Resurface the winners
- Audit **native analytics** for proven evergreen pieces (by goal: engagement → saves/shares/comments;
  traffic → CTR; growth → follows/mentions). Include **strong-but-underseen** posts that deserved more.
- Keep only **evergreen** — exclude events, seasonal promos, dated news, trend-jacks.
- Maintain a **recycling library/vault** (see the system reference) so winners are easy to re-queue.

## E — Earn the slot again (refresh)
- **Recycle the insight, not the artifact.** Give it a new hook, angle, or format (carousel → Reel →
  text → quote card). **Change one major variable** per variant (hook / proof / CTA).
- **Never repeat the same opening line.** Rewrite the first sentence, swap the opening visual, tighten
  the first five seconds. Treat it as **editing, not duplication.**

## U — Update for now
- Verify **facts, stats, dates, prices, links** are still current — refresh anything outdated before
  recycling. (A two-year-old "algorithm" or "pricing" post is often wrong now.)
- Re-check **compliance/endorsement** language. **Disclose** any AI-refreshed media.

## S — Schedule the cycle
- Space each asset roughly **every 90–120 days**; don't dump a backlog. Sprinkle recycled pieces among
  native new content.
- Adapt to the **destination platform** (native format beats a copy-paste). Respect Meta's originality
  rules — refreshed, not identical.

## E — Evaluate & re-queue
- Read native analytics on each cycle: which **variant** won, which asset earns another round.
- Run **controlled tests** (one variable at a time) — one clean experiment beats a month of random
  republishing. Promote winners back into the queue; retire the rest.

## The recycling brief a request should fill
```
RESURFACE: which proven evergreen asset (+ its native metric) — and why now
REFRESH: new hook / format / variable changed; first line + visual rewritten
UPDATE: facts/stats/dates/prices/links verified current; compliance re-checked
SCHEDULE: ~90–120-day spacing; destination platform + native format
EVALUATE: which metric to watch; one-variable test; re-queue rule
```

> Not REUSE's job: same-moment multi-platform adaptation → **cross-platform-repurposing**;
> long-form → short clips → **captions-and-clipping**; calendar/planning → **content-calendar**.
