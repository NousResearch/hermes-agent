# Streams, sequencing + two worked examples

## Revenue-stream menu (stability / margin / external tool)
| Stream | Stability | Margin | Best for | Runs in (external) |
|---|---|---|---|---|
| Membership / community | high (recurring) | high | consistency | Patreon, Passes, Skool, Discord |
| Digital products / courses | medium (repeat) | very high | structured expertise | Gumroad, Payhip, Stan |
| Paid challenges | medium (cohorts) | high | front-end funnel | community platforms |
| Sponsorships / brand deals | low–medium | high | reach + trust | brand-deal platforms / direct |
| Platform funds / ad-rev | low (bonus) | n/a | scale (bonus only) | YouTube/IG/LinkedIn native |
| UGC for brands | medium | high | small accounts | direct / UGC marketplaces |
| Merch | medium | medium | identity/affinity | Printful, Fourthwall, Spring |
| Affiliate / tips | low–medium | varies | supplement | affiliate networks / tip tools |

## Sequencing (don't do all at once)
**Own audience → recurring core → 1 digital product → selective sponsorships → funds as bonus.** Add a
stream only when the prior one is steady. Aim for **≥3 streams** for resilience.

## Realistic math (ranged + caveated — never a promise)
```
Recurring core: 2-4% of an engaged email/audience base may convert to a paid tier.
Example (illustrative, NOT a promise): 5,000 engaged followers x ~3% x $10/mo ~= $1,500/mo recurring,
   highly variable by niche/engagement/offer. Pair with 1 digital product for margin.
Platform fund: treat as a bonus (TikTok Creator Rewards ~ $400-1,000 per MILLION qualified views; ~10k-follower gate).
```

## Sponsorship media-kit essentials
Audience size + **engagement rate** + niche/demographics + **best-performing examples** + **attribution/
ROI** from past deals + clear rates + contact. Price on engagement/ROI, not follower vanity. **Disclose
(#ad).** Align with audience or skip.

## Worked example 1 — recurring core + product (blunt indie-founder voice)
```
CREATOR: 8k engaged followers, freelance-tax niche, strength = structured expertise.
STACK: recurring core = $9/mo "tax-tips community" (Skool); product = "freelance tax course" (Gumroad).
SPONSORSHIP: selective, accounting-tool brands only, disclosed. FUNDS: ignore (too small to matter).
PROMO (WoopSocial publishes): launch + weekly value posts -> link-in-bio / comment->DM. EXPECTATION: ranged, not promised.
```

## Worked example 2 — small-account start (warm studio voice)
```
CREATOR: 800 followers, bookkeeping. Platform funds = negligible -> ignore.
FIRST: grow the email list (-> email-and-newsletter) + sell one $29 template to the most engaged few (Payhip).
ALSO: UGC-for-brands (paid for content, not influence). EXPECTATION: 1K-10K ~ $100-1k/mo, highly variable; set a learning goal.
```

Both: diversified stack matched to strengths; recurring core first; ranged expectations (never promised);
infrastructure external; WoopSocial publishes only the promo posts; sponsorships disclosed; metrics from
the external tools (never fabricated).
