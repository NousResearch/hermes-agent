# Platform Transforms — one atom, native everywhere

How the *same* core idea becomes each platform's native post. These are transform recipes: feed
in the atom, get out a version built for that platform. Each changes the hook, format, length,
mechanics, and register — never just the hashtags.

> For full caption mechanics see `caption-writer/references/platforms.md`; for hook craft per
> format see `hook-writer/references/formats.md`. This reference is the *transform* layer that
> sits on top of both. Re-verify platform specs periodically.

---

## → Instagram

- **Native forms:** Reel (video), carousel (visual teaching), single image.
- **Pick by atom:** a *moment/story* → Reel; a *how-to/list* → carousel; a *single point* →
  image.
- **Hook:** visual + on-screen text; caption first line within ~125 chars.
- **Mechanics:** link in bio; a few relevant hashtags. Register: warm.
- **CTA:** save / send / follow.

## → TikTok

- **Native form:** short video, 9:16, sound-on, trend/sound-aware.
- **Transform:** make it faster and looser than the Reel; lead with the hook in frame one;
  keyword the caption for search.
- **Register:** casual, native, less polished. (Hand to `tiktok-script` for trend-led ideas.)
- **CTA:** comment / follow.

## → LinkedIn

- **Native form:** text post (or a document/PDF carousel).
- **Transform:** expand the atom into a short, whitespace-heavy post; lead with the hook line
  (~140-char cutoff); more authority/insight register.
- **Mechanics:** link in comments (not body); 3–5 hashtags. Longer is fine if it earns the read.
- **CTA:** a genuine question (comments) or a soft point.

## → X / Twitter

- **Native form:** a single punchy post, or a thread for multi-atom ideas.
- **Transform:** strip to the sharpest line; lead with the point; cut everything else.
- **Mechanics:** 0–2 hashtags; conversational. (Hand multi-atom ideas to `thread-writer`.)
- **CTA:** reply / repost, or none — a strong last line earns engagement.

## → Threads

- **Native form:** short, conversational post or light thread.
- **Transform:** reactive, opinion-forward, lower-polish than LinkedIn; one topic tag.
- **CTA:** invite replies.

## → Bluesky

- **Native form:** short text post; links are clickable and welcome (no link penalty culture).
- **Transform:** like X but warmer/less combative; skeet-length punchy take; hashtags barely used.
- **CTA:** reply / repost.

## → Facebook

- **Native form:** text + image/video post; group-friendly, conversational.
- **Transform:** slightly longer and more personal than X; lead with a relatable line; minimal
  hashtags; links fine in the post.
- **CTA:** comment / share.

## → YouTube Shorts

- **Native form:** short vertical video.
- **Transform:** like the Reel, but the first line doubles as a **searchable** title; the
  lean-in audience tolerates a slightly stronger payoff.
- **CTA:** subscribe / watch the long version.

## → Pinterest

- **Native form:** a pin — image (or video) + **destination link** + keyword-rich description.
- **Transform:** make it evergreen and **searchable** (keywords, not hashtags); the visual must
  stand alone; the link is the point (real traffic driver).
- **CTA:** save / visit the link.

## The transform table (quick reference)

| Platform | Native form | Length | Hook | Links | Register |
|---|---|---|---|---|---|
| Instagram | Reel / carousel / image | short–med | visual + text | bio | warm |
| TikTok | short video | short | frame-one | bio | casual |
| LinkedIn | text post / doc | med–long | line + whitespace | comments | authority |
| X | post / thread | short | the point | inline | conversational |
| Threads | post / light thread | short | the take | inline | casual |
| Bluesky | short post | short | the take | inline | casual-warm |
| Facebook | text + media post | short–med | relatable line | inline | personal |
| YT Shorts | short video | short | searchable line | description | clear |
| Pinterest | pin + link | short | keyword | clickable | descriptive |

Same atom, nine different builds. If your versions don't differ across these columns, you
haven't repurposed — you've relocated.
