# The Repurposing Model — Atomize → Adapt

The method that separates real repurposing from lazy reposting. Internalize this and every
output is native; skip it and you produce duplicate spam.

## Why copy-paste fails

Pasting the same caption everywhere fails three ways at once:

- **It fits none of them.** A LinkedIn-length post dies on X; a TikTok caption looks lazy on
  LinkedIn. Each platform has its own format, mechanics, and audience mindset.
- **It looks like spam.** People who follow you on two platforms see the identical post twice and
  unfollow one.
- **It gets suppressed.** Several platforms down-rank obviously cross-posted content (e.g.,
  recycled Reels with another app's watermark, duplicate text).

Native-everywhere beats same-everywhere, every time.

## The model

**Atomize → Adapt.**

### Atomize — extract the reusable core
The **atom** is the smallest reusable unit of value in the source: the point, the insight, the
story, the stat, the moment, the quote. It's platform-agnostic — it's *what you're saying*, not
*how*.

- A single post usually contains **one atom**.
- A long piece (blog, 20-min video, podcast, newsletter) contains **many atoms** — each strong
  enough to be its own post. The skill of long-form repurposing is *finding the atoms*, not
  summarizing the whole.

### Adapt — rebuild the atom natively per target
Take the atom and build it fresh for each platform: a new hook, the right format and length,
native mechanics, the right CTA, the right register. You're not translating the wrapper — you're
rebuilding it around the same core.

## What stays vs what changes

| Stays constant | Changes per platform |
|---|---|
| The **atom** (core idea) | The **hook** (per platform's mechanics) |
| The **brand voice** | The **format** (Reel / carousel / thread / post) |
| The **truth** / facts | The **length** and structure |
| The brand **guardrails** | The **CTA** (matched to platform + goal) |
| | **Mechanics** — hashtags, links, tags |
| | **Register** (voice tone-map: formal ↔ loose) |

If your two versions differ only in hashtags, you changed nothing that matters — go back and
re-hook, re-format, re-length.

## The directions of repurposing

Each direction has different mechanics:

- **One → many platforms (fan-out):** one atom, re-natived for each platform. The most common.
- **Long → short (atomize):** a blog/video/podcast → many short posts, one per atom. The biggest
  multiplier — one "hero" asset can feed weeks of posts.
- **One format → many formats:** a written insight → a carousel (slides), a Reel (script), a
  thread. Same platform or across.
- **Cross-medium:** video → text (pull the spoken insights as written atoms) and text → video
  (hand the atom to `reels-script`). Never just transcribe or read aloud.
- **Across time (recycle):** evergreen atoms re-posted later, refreshed — see `content-recycling`.

## The hero → atoms mental model

The efficient operation runs on a few **hero assets** (a deep blog post, a long video, a big
launch) that each get **atomized into many small posts** across platforms and time. Plan the
heroes; the atoms fill the calendar. That's how `batch-content-plan`'s capacity math works
without burning the user out on net-new ideas.

## The gate

Volume is the goal, but **quality per platform is the gate.** Five native posts beat fifteen
copy-pastes. If a version doesn't feel built for its platform, it's not done.
