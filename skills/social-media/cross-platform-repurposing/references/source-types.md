# Source Types — repurposing by direction

Different sources atomize differently. This is how to handle each, so you pull the most posts
without padding.

---

## Long-form → many short posts (the biggest multiplier)

Sources: a blog post, a 20-minute video, a podcast episode, a newsletter, a webinar, a talk.

**Method — atomize, don't summarize:**
1. Read/scan the whole piece and **list every atom** — each distinct insight, story, stat,
   quote, contrarian take, or step. A solid blog post yields 5–10; a podcast can yield more.
2. Score the atoms — which are strongest, most surprising, most standalone.
3. Turn each strong atom into its **own** native post (per `platform-transforms.md`). One atom =
   one post, not "here's a summary of my blog."
4. Optionally keep one post that points to the full piece (the "hero" link), but the atoms each
   stand alone.

**Anti-pattern:** compressing a rich 2,000-word post into one thin "I wrote a blog, check it
out" post. That wastes 90% of the material.

## One strong post → fan out (one → many platforms)

Sources: a post that did well, or a fresh single idea.

**Method:** it's one atom — re-native it for each target platform (new hook, format, length,
CTA, register). Space the posts out; vary the angle where audiences overlap. This is the default
fan-out covered in the main flow.

## One format → many formats

Sources: a written insight you want in more shapes.

**Method:** the same atom becomes:
- a **carousel** (break the point into slides),
- a **Reel/Short** (hand to `reels-script`),
- a **thread** (hand to `thread-writer`),
- a **single post**.
Pick the formats that suit the atom and the platforms; don't force all four.

## Cross-medium (video ↔ text)

- **Video → text:** pull the **spoken insights, quotes, and moments** as written atoms — then
  build native text posts. Don't dump a transcript; transcripts aren't posts.
- **Text → video:** hand the atom to `reels-script` to build it *as a video* (hook + beats +
  shots). Don't read the caption aloud over a static image.
- **Long video → clips:** see `captions-and-clipping` for cutting clips; pair each clip with a
  native caption.

## Across time (recycle)

Evergreen atoms can run again later, refreshed (new hook, updated example, different format) so
it doesn't read as a literal repost. This is the time dimension — see `content-recycling` for
cadence and refresh rules.

---

## Choosing how far to push it

- A **hero asset** (deep blog, big video, launch) → atomize hard; it can feed weeks.
- A **single light idea** → one or two native versions; don't manufacture filler to hit a count.
- The test: every post must clear the quality bar on its own. If you're padding to reach a
  number, stop — fewer, stronger posts win.
