# Workflows, checklists & worked examples

## The weekly episode loop (repeatable)
Record (separate tracks; quiet room; SquadCast/Zoom import) → transcribe → accuracy pass (names/jargon) → Studio
Sound once per source → text edit (tangents out, Underlord filler+silence pass, restructure) → listen-through
verify → multicam + captions + layout → export long-form → clip set + show notes + chapters from the same
transcript → WoopSocial.

## The credit-aware checklist (post-Sept-2025 pricing)
Import only what you'll edit (media minutes count everything) ✓ · Studio Sound once per source, not per revision
✓ · batch Underlord actions into fewer, bigger prompts ✓ · Overdub for words/phrases, not paragraphs ✓ · watch
the credit meter mid-month ✓ · top-ups expire in 12 months — buy to need ✓ · verify tier limits in-app, not from
blogs ✓.

## The Overdub decision table
| Situation | Move |
|---|---|
| Flubbed word/product name | Overdub the word (own voice, consented) |
| Stumbled sentence | Re-record the sentence, or Overdub if short |
| New intro paragraph | Re-record — long Overdub drifts synthetic |
| Guest's flub | Ask the guest to re-record/approve; NEVER clone them |
| Anyone else's voice | Refuse — own-voice-only by design |

## Interview-integrity checklist
Meaning preserved (would the guest agree that's what they said?) ✓ · clips keep context ✓ · significant edits
offered for approval ✓ · Underlord's clip flags human-reviewed for fairness ✓ · contractual approval terms
honored ✓.

## Worked example A — "Blunt indie founder" (the flub fix)
"said 'InvoiceHero' as 'InvoiceZero' three times. old me re-records 55 minutes. new me: fixed all three in the
transcript with overdub — my own trained voice, sounds like me because legally and literally it is me. the new
intro paragraph though? re-recorded it. typed overdub past one sentence sounds like a polite robot reading my
eulogy." — own-voice correction, honest length limit.

## Worked example B — "Warm bookkeeping studio" (the guest edit)
"Our guest gave a lovely, winding answer — eight minutes for two real points. We trimmed it to ninety seconds in
the transcript, then did the part that matters: listened back and asked, would she recognize this as what she
meant? We sent her the cut anyway — she replied 'oh thank goodness, I ramble.' One small step: before you publish
anyone else's words, play their edit back with their eyes in mind." — concision with meaning preserved, consent
offered.

## Never
Skip the transcript accuracy pass · edit by ear what you could edit as text (or ship a text edit you never
listened to) · clone anyone else's voice · Overdub full paragraphs · flip a guest's meaning or strip clip context
· run Studio Sound per revision · import media you won't edit · trust blog tier-numbers over the in-app meter ·
claim WoopSocial edits media.
