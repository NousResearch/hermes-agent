# Building the system: kit, templates, workflow + two worked examples

## Brand-kit spec (the tokens)
```
COLORS: primary | secondary | accent | text-dark | text-light | background(s)  (lock the hex set)
FONTS:  heading (1 distinctive) + body (1 legible); a fixed size scale (e.g. H1 64 / H2 40 / body 28 @ 1080w)
LOGO:   primary + mark-only; clear-space rule; light/dark versions
SPACING: outer margin, grid columns, min text size at thumb scale
-> In Canva this is the Brand Kit; in Figma it's styles/variables; in Adobe Express it's the Brand.
```

## Starter template set (~5-7 — map to recurring needs, cross-link the format siblings)
```
Quote / hook card      1:1 or 4:5    one line + attribution; brand accent bar
Carousel frame         4:5           cover + body frames; copy from carousel-writer
Announcement / promo   1:1 / 4:5     headline + CTA; logo lockup
Reel / Shorts cover    9:16 (3:4-grid-safe)  -> instagram-reels-publishing / thumbnail-design
Pinterest pin          2:3 1000x1500 -> pinterest-pin-design
(Story 9:16, profile banner -> profile-optimization)  -- add only what you actually post
```

## Hierarchy + legibility rules
```
[ ] One focal point per template (the eye lands once)
[ ] Type scale: clear H / sub / body; no more than 2 fonts
[ ] Contrast: text legible on the busiest version of the background (check at thumb size)
[ ] Safe zones: keep text clear of platform UI (Reel/Story overlays, grid crops)
[ ] Mobile-first: if it doesn't read on a phone, it doesn't ship
```

## Production workflow (non-designer, minutes)
```
brand kit (once) -> pick the template -> swap text + image -> Magic Resize to other platforms ->
export -> the finished asset enters the WoopSocial flow (scheduling-and-queue -> WoopSocial publishes it).
Generated image needed? -> image-prompt (ideogram/nano-banana) or Dream Lab/Firefly -> place in the template.
```

## Worked example 1 - solo founder (blunt indie-founder voice)
```
Brand kit: 3 colors, 2 fonts, logo, one grid. Six templates, that's it -- quote card, carousel frame, launch card, Reel cover,
Pin, story. I keep them in a Canva Brand Kit. New post = swap text + image, Magic Resize, export. 80% on-brand in two minutes.
Hero launch graphic I brief in nano-banana + finish by hand. WoopSocial posts the finished files. No 40-template library I'll never touch.
```

## Worked example 2 - bookkeeping studio (warm studio voice)
```
We start from the brand-profile -- warm palette, one friendly heading font -- and turn it into a small kit, then five gentle
templates for the things we actually post weekly (a tip card, a client-win card, a carousel frame, a Reel cover, a Pin). Each
one has a single focal point and reads on a phone. We swap the words and a photo, resize, and hand the finished image to WoopSocial -- one small, repeatable step.
```

Both: brand kit first; a small named set mapped to real needs; one focal point + mobile-legible; swap-and-resize workflow;
image tools for generated/hero imagery; the finished asset enters the WoopSocial flow; ~80% on-brand fast, human finishes the hero.
