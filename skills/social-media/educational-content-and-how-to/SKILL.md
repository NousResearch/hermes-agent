# educational-content-and-how-to

The **teach-to-grow content type** — pick a useful topic, teach **one thing completely + accurately**,
structure it, and route it to the right format. The agent **teaches**; the **format writers build it**;
**WoopSocial publishes + serializes.**

## The POV: teach one thing completely, accurately
Teaching is the **highest-trust, highest-save authority builder** — **saves + sends are top-weighted 2026
signals, far above likes** and **educational/how-to content is the most reliable way to earn them** (it's
reference-worthy). The win
isn't recycled generic tips — it's **one genuinely useful idea, taught completely**, as a **flashcard, not a
chapter.** And the gate that separates authority from embarrassment: **accuracy.** Teaching wrong info destroys
trust, and **YMYL** how-tos (health/finance/legal) can cause real harm. The angle works across formats — so the
agent shapes the **lesson** and hands the format mechanics to the writers. **Saves/sends are the metric, not
likes.**

## Read these first
1. **brand-profile** — expertise + voice.
2. **audience-research** — skill level + real pain points.
3. **content-pillars** — which themes.

## The framework: TEACH
(Depth: `references/the-teach-framework.md`.)
- **T — Target one teachable thing:** one process/point/next-step; flashcard not chapter; useful + within real
  expertise; if it can't be taught well in one piece, **split into a series.**
- **E — Earn trust with accuracy:** be correct; **cite sources**; stay within expertise; **YMYL → disclaimer +
  point to a pro**; never fabricate steps/stats.
- **A — Arrange the lesson:** hook/cover ("is this for me?" + payoff) → context/problem → one step/idea per unit
  → recap → specific CTA; structure step-by-step / PAS / myth-bust / data; 8–12 units, each earns its place.
- **C — Carry it to the right format:** carousel (`carousel-writer`) / tutorial video (`reels-script`/
  `tiktok-script`) / thread (`thread-writer`) / post (`caption-writer`); cover → `hook-writer`; visual →
  `design-and-templates`/image tools; CTA → `lead-magnets-and-funnels`.
- **H — Harvest saves + serialize:** saves/sends = the top authority signal; serialize a weekly series
  (`content-calendar`); evergreen → repurpose across formats (`content-recycling`).

## The reality (verify-quarterly)
Saves + sends are top-weighted 2026 signals — sends/DM shares rank highest per Mosseri, both far above likes;
educational content earns saves best (carousels ~3× the save
rate of Reels, highest engagement ~0.55% vs ~0.50%/0.41%, longest lifespan — Socialinsider/Buffer, attribute;
tutorials inherently saveable + high completion). Teach one job well ("flashcard not chapter"). Structure:
hook/cover (specific, <8–10 words) → context → one step/idea per unit → recap → specific CTA; structures
step/PAS/myth/data; 8–12 units (12–20 deep), every unit earns its place. Format spread: carousel (save king) /
tutorial video / thread / post — same lesson, route to the writer. CTAs: save / send to X / comment GUIDE (→
lead-magnets). Serialize + evergreen → repurpose; **measure saves/sends, not likes.** **Accuracy gate:** cite
sources, stay within expertise, YMYL disclaimer + extra care, never fabricate: `references/educational-content-
2026-reality.md`. The teaching structures, the format-spread table, the accuracy/YMYL checklist, the CTA
library, the WoopSocial flow + worked examples: `references/structures-formats-and-accuracy.md`.

## Honest scope (never violate)
- **The agent** picks the **topic**, structures the **lesson**, writes the **teaching copy + CTA**, and
  **ensures accuracy + sourcing + YMYL care** — then **routes** the build to the **format writers**, the cover
  to `hook-writer`, the visual to `design-and-templates`/the image tools, and lead-gen CTAs to
  `lead-magnets-and-funnels`.
- **WoopSocial publishes + schedules the series.** It does **NOT** verify accuracy, generate the asset, or
  teach.
- **Accuracy is non-negotiable** (wrong info destroys authority); **cite sources**; **stay within expertise**;
  **YMYL → not-professional-advice disclaimer + point to a pro**; **never fabricate steps/stats** or pad;
  **saves/sends = the metric.** (Scope, distinctions + connections: `references/scope-and-connections.md`.)

## Distinct from its siblings (route correctly)
**educational-content-and-how-to (this)** = the teaching ANGLE/substance (what to teach + how to structure a
lesson, across formats) · **carousel-writer** = the carousel FORMAT (they pair — this decides the lesson,
carousel-writer builds the slides) · **reels-script**/**tiktok-script** = the video format · **thread-writer**
= the thread format · **storytelling-and-narrative** = narrative craft (story vs didactic) · **content-pillars**
= which topics · **hook-writer** = the cover/open (pairs) · **data-and-original-research** = producing original
data · **lead-magnets-and-funnels**/**social-selling-and-dm** = the comment-to-DM CTA.

## Where this connects
Reads first: **brand-profile** + **audience-research** + **content-pillars.** Feeds: the **format writers** (the
lesson → the carousel/video/thread/post), **hook-writer** (the cover), **content-calendar** (the series),
**design-and-templates**/**image-prompt** (the visuals). Pairs with: **data-and-original-research** (teach with
original data), **social-seo**/**ai-search-optimization** (how-to is highly indexable + citable in search/AI
answers), **lead-magnets-and-funnels** (the comment-GUIDE CTA). Publishes via: the format writer's output →
**scheduling-and-queue → WoopSocial**. Measure with: native + **analytics-and-reporting** on **saves/sends/
completion** (never fabricated). Accuracy stays with the human/expert.

## Definition of done
A lesson that teaches one genuinely useful thing completely (flashcard not chapter), within the brand's real
expertise, structured as hook/cover (is-this-for-me + a specific payoff) → context → one step or idea per unit
→ recap → a specific CTA (save / send to X / comment GUIDE), using the right structure (step-by-step / PAS /
myth-bust / data) at 8–12 units where every unit earns its place; accurate and sourced, within genuine
expertise, with a not-professional-advice disclaimer + a pointer to a qualified pro for any YMYL topic and
nothing fabricated; carried to the right format via the format writer, the cover to hook-writer and visuals to
the design tools; serialized into a series in the content-calendar and published via WoopSocial; measured on
saves/sends, not likes; correctly distinguished from carousel-writer, the other format writers, and
storytelling-and-narrative.
