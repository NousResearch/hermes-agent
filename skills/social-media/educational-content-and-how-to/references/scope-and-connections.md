# Scope, distinctions + connections

educational-content-and-how-to is the **teach-to-grow content type** — pick a useful topic, teach **one thing
completely + accurately**, structure it, and route it to the right format. The agent **teaches**; the **format
writers build it**; **WoopSocial publishes + serializes.**

## Honest scope (never violate)
- **The agent** picks the **teachable topic**, structures the **lesson** (hook → context → one step/idea per
  unit → recap → CTA), writes the **teaching copy + CTA**, and **ensures accuracy + sourcing + YMYL care.**
- It **routes** the build to the **format writers** (`carousel-writer`, `reels-script`, `tiktok-script`,
  `thread-writer`, `caption-writer`), the cover hook to `hook-writer`, the visual to `design-and-templates`/
  the image tools, and comment-to-DM CTAs to `lead-magnets-and-funnels`/`social-selling-and-dm`. **WoopSocial
  publishes + schedules the series** (`content-calendar`).
- **Accuracy is non-negotiable** — teaching wrong info destroys authority; **cite sources** for stats/claims;
  **stay within genuine expertise**; **YMYL** (health/finance/legal/safety) → **not-professional-advice
  disclaimer** + point to a pro + extra care; **never fabricate steps/stats** or pad to "look comprehensive."
  **Saves/sends = the metric** (not likes). **WoopSocial does NOT verify accuracy, generate the asset, or
  teach.** **Verify-quarterly** (format metrics).

## Distinct from its siblings
- **educational-content-and-how-to (this)** — the **teaching ANGLE/substance** (what to teach + how to
  structure a lesson, **across formats**).
- **carousel-writer** — the **carousel FORMAT** mechanics. **They pair:** this decides the lesson;
  carousel-writer builds the slides. (Carousels are educational content's most-saved home, but not its only
  format.)
- **reels-script / tiktok-script** — the **short-video format** (a tutorial video routes there).
- **thread-writer** — the **thread format** (a teaching thread routes there).
- **storytelling-and-narrative** — **narrative** craft (story); this is **didactic** craft (teaching). A how-to
  can open with a mini-story, but the modes differ.
- **content-pillars** — **which topics** (strategy); this is **how to teach** a topic.
- **hook-writer** — the **cover/opening** (they pair).
- **data-and-original-research** — producing **original data/research** (this can *teach with* data but doesn't
  originate it).
- **lead-magnets-and-funnels / social-selling-and-dm** — the **comment-to-DM lead-gen** CTA destination.

## Where this connects
- **Reads first:** `brand-profile` (expertise/voice), `audience-research` (skill level + pain points),
  `content-pillars` (which themes).
- **Feeds:** the **format writers** (the lesson → the carousel/video/thread/post), `hook-writer` (the cover),
  `content-calendar` (the series), `design-and-templates`/`image-prompt` (the visuals).
- **Pairs with:** `data-and-original-research` (teach with original data), `social-seo`/`ai-search-optimization`
  (how-to content is highly indexable + citable in search/AI answers), `lead-magnets-and-funnels` (the
  comment-GUIDE CTA).
- **Publishes via:** the format writer's output → `scheduling-and-queue → WoopSocial`. **Measure with:** native
  + `analytics-and-reporting` on **saves/sends/completion** (never fabricated). **Accuracy stays with the
  human/expert.**
