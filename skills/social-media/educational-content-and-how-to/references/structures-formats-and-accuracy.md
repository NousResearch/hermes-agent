# Structures, formats, accuracy + two worked examples

## Teaching structures (pick by goal)
| Structure | Shape | Best for |
|---|---|---|
| **Step-by-step** | numbered: one step per unit → recap | processes, tutorials, "how to X in N steps" |
| **PAS** | Problem → Agitate → Solve | reframing a pain point, why-this-matters lessons |
| **Myth-busting** | "Myth: … / Fact: …" per unit | correcting misconceptions; instant-authority |
| **Data-driven** | one stat per unit + what it means | industry insight, trend teaching (cite sources!) |

## Format spread (same lesson → the right writer)
| Format | When | Route to |
|---|---|---|
| Carousel (IG/LinkedIn doc) | reference, frameworks, checklists — the **save king** | `carousel-writer` |
| Tutorial video (Reel/TikTok/Short) | a process/demo, "things I wish I knew" | `reels-script` / `tiktok-script` |
| Thread (X/Threads) | numbered teaching, fast | `thread-writer` |
| How-to post / caption | a single tip or short lesson | `caption-writer` |
Cover hook → `hook-writer`. Visual/template → `design-and-templates` / the image tools.

## Accuracy + sourcing + YMYL checklist (non-negotiable)
```
[ ] Every step/claim is correct + within our genuine expertise
[ ] Stats/claims have a real, citable source (no invented numbers)
[ ] Nothing fabricated to "look comprehensive" -- every unit earns its place
[ ] YMYL (health/finance/legal/safety)? -> "not professional advice" disclaimer + point to a qualified pro + extra care
[ ] If we can't teach it accurately -> don't teach it (or narrow to the part we can)
```

## CTA library (teaching)
```
SAVE:     "Save this for your next [task]."                      SEND:  "Send this to the person who handles [X]."
LEAD-GEN: "Comment GUIDE and I'll DM you the full checklist."  (-> lead-magnets-and-funnels / social-selling-and-dm)
Place a soft CTA mid-way + a clear CTA on the last unit.
```

## WoopSocial flow
```
agent picks the topic + structures the lesson + writes the teaching copy + CTA + ensures accuracy/sourcing/YMYL
-> format writer builds it (carousel-writer/reels-script/thread-writer) + design tools make the visual
-> WoopSocial publishes + schedules the series (content-calendar). WoopSocial does NOT verify accuracy, generate the asset, or teach.
```

## Worked example 1 - SaaS, LinkedIn carousel (blunt indie-founder voice)
```
One thing: "How to set up GA4 key events in 5 steps." Flashcard per slide, one step each. Cover: "Set up GA4 key events in 5
steps (no dev needed)". I only teach this because we actually do it daily -- every step is right, and the one stat I cite links
to Google's docs. carousel-writer builds the slides, design-and-templates skins them. CTA: "Save this for your next setup." I watch saves, not likes. The other 4 GA4 topics become a series.
```

## Worked example 2 - nutrition coach, Reel tutorial (warm studio voice)
```
A how-to on building a balanced lunch -- taught as a simple 4-step Reel. Because this touches health, we keep it general,
evidence-based, and add a gentle note: "general guidance, not medical advice -- check with your dietitian for your needs." reels-script
shapes the steps to camera, captions-and-clipping burns the captions. CTA: "Save this for grocery day." We measure saves + sends, and the rest of the series follows next week.
```

Both: one teachable thing taught completely; accurate + sourced + (where YMYL) disclaimed; structured hook→steps→recap→CTA;
built by the right format writer; measured by saves/sends; serialized. Nothing fabricated, nothing taught outside real expertise.
