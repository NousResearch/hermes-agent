# The TEACH framework — teach one thing well, accurately, in the right format

A content-angle layer that **feeds the format writers.** The agent **targets the lesson + ensures accuracy +
arranges it + routes it to the format + harvests saves**; the **format writers** build it; the **design/image
tools** make the visuals; **WoopSocial publishes + serializes.**

## T — Target one teachable thing
- **One process / point / next-step.** **Flashcard, not chapter.** A **genuinely useful** topic **within real
  expertise** — not a recycled generic tip. If it can't be taught well in one piece, **split into a series.**

## E — Earn trust with accuracy
- **Be correct.** **Cite sources** for stats/claims. **Stay within genuine expertise.** **YMYL** (health/
  finance/legal/safety): add a **not-professional-advice disclaimer** + point to a pro. **Never fabricate steps
  or stats.** *Teaching wrong info destroys authority.*

## A — Arrange the lesson
- **Hook/cover** ("is this for me?" + the payoff, specific, <8–10 words) → **context/problem** → **one step or
  idea per unit** → **recap** → **specific CTA.** Pick a structure: **step-by-step / PAS / myth-bust / data.**
  **8–12 units** (12–20 for deep guides); **every unit earns its place.**

## C — Carry it to the right format
- **Carousel** (reference/frameworks — the save king) → `carousel-writer` · **tutorial video** (process/demo) →
  `reels-script`/`tiktok-script` · **thread** → `thread-writer` · **post** → `caption-writer`. The **cover
  hook** → `hook-writer`; the **visual** → `design-and-templates`/the image tools. **CTA:** save / send to X /
  **comment GUIDE** (→ `lead-magnets-and-funnels`).

## H — Harvest saves + serialize
- **Saves/sends = the top authority signal** (measure those, not likes). **Serialize** into a recognizable
  weekly series (`content-calendar`); **evergreen** → repurpose one lesson across formats
  (`content-recycling`). **WoopSocial publishes + schedules the series.**

## The lesson brief a request should fill
```
TOPIC: one teachable thing (process/point/next-step) -- within real expertise; useful, not generic
ACCURACY: sources for any stat/claim; within-expertise? YMYL -> disclaimer + point to a pro; nothing fabricated
LESSON: hook/cover (is-this-for-me + payoff) -> context/problem -> one step per unit -> recap -> CTA  | structure: step/PAS/myth/data | 8-12 units
FORMAT: carousel (carousel-writer) / video (reels-script) / thread (thread-writer) / post (caption-writer); cover -> hook-writer; visual -> design tools
CTA: save this / send to the person who handles X / comment GUIDE (-> lead-magnets). SERIALIZE: series in content-calendar. METRIC: saves/sends.
```
