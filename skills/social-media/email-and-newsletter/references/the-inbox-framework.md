# The INBOX framework — own the audience social can't take away

A platform rents you attention; a newsletter is the audience layer you **own**. INBOX builds it: a
focused, owned list grown from social, run across email (habit) and web (discovery), and looped back into
social. The agent strategizes + drafts; the **ESP is external + human-run**; WoopSocial **publishes the
social side.**

## I — Identify the one problem/audience
- Solve **one problem for one reader** so sharply nobody unsubscribes. **Personality is the moat** —
  voice + perspective + consistency (→ `voice-builder`, `content-pillars`). Generic newsletters plateau.

## N — Nurture an owned list
- **Capture from social** (the `link-in-bio-and-traffic` handoff): simple sign-up (name + email), a
  **lead magnet**, value clear on screen one. **Own your domain + list.**
- Win the **weeks 2–3 churn window**: a **welcome sequence** + a high-value **edition 2** lock subscribers in.

## B — Build habit + discovery on two surfaces
- **Email = habit/relationship** (owned, deliverable). **Web archive** (Substack/LinkedIn/published) =
  **discovery** via search + AI answer engines + social. Same core work, adapted per surface (→
  `ai-search-optimization`). Pick the platform by goal; own your data.

## O — Offer value (70-20-10)
- **70% value / 20% personal / 10% promo.** Short subject lines; scannable, mobile-first; conversational;
  interactive (polls/replies). **Respond to every reply** (community > list size). A/B test subjects + copy.

## X — eXpand via the social ↔ email loop
- **One edition → a week of social** (video + carousels + captions); your **best social → next edition.**
  Measure **clicks/replies/signups from the ESP** (+ GA4) — not opens. Monetize honestly later
  (paid subs / aligned sponsors / products).

## The newsletter brief a request should fill
```
NICHE: the one problem + one reader; the unmistakable voice
CAPTURE: lead magnet + simple form; the social->signup loop; welcome + edition-2 value
SURFACES: email (habit) + web archive (discovery, SEO/GEO-optimized); platform by goal; own domain/list
VALUE: 70/20/10; short subject; scannable; interactive; reply-driven
LOOP: edition -> a week of social; best social -> next edition
MEASURE: clicks/replies/signups from the ESP + GA4 (not opens); consent + unsubscribe always
```
