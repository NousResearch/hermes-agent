# What to test, the sprint + two worked examples

## Test-priority list (highest leverage first, in your control)
1. **Hook / first-frame** (short video) — biggest swing on retention/reach.
2. **Posting time** — easy to test, often high impact.
3. **Format** — Reels vs carousel vs photo; long vs short.
4. **Caption / CTA** — length, opening line, the ask.
5. **Thumbnail / cover + title** (YouTube/Reels) — CTR lever; on YouTube long-form use native **Test &
   Compare** (up to 3 titles/thumbnails/combos — a true audience split) instead of sequential posts.
6. **Hashtags / keywords** — branded vs generic, count, placement.
Always tie the choice to the **KPI** you're moving.

## Experiment-design template
```
HYPOTHESIS: [variable] change will lift [primary metric] for [audience/platform]
VARIABLE (one): ...                 CONTROL: same platform/format/topic/length/window
PRIMARY METRIC: ...                 DECISION RULE (pre-set): B wins if ... 
GUARDRAIL: ... must not worsen      DURATION: >=7d (small acct 2-4 wks)   REPS: 3-5 paired
READOUT: native analytics           LOG + NEXT: scale / retire / re-test
```

## The 30-day sprint
- **Week 1 — Hooks:** 3 paired posts, same topic category + posting windows; vary only the hook.
- **Week 2 — First-frame / thumbnail:** 3 paired; vary only the opening visual.
- **Week 3 — Posting time:** same content, two windows, repeated.
- **Week 4 — Format or CTA:** 3 paired; vary one.
Always have **one test running**; log each; promote only patterns seen across **3–5** reps.

## Worked example 1 — hook test on Reels (blunt indie-founder voice)
```
HYPOTHESIS: a question-hook beats a stat-hook on saves/reach.
VARIABLE: first 3s only (A: "Most freelancers overpay tax." B: "Are you overpaying tax?")
CONTROL: same Reel body, topic, 9am window, same week. PRIMARY: saves per reach.
RULE (pre-set): B wins if saves/reach +20% across 3 paired posts. GUARDRAIL: completion not worse.
READOUT: IG Insights. RESULT after 3 reps: B +27% saves/reach -> adopt question-hooks; log it.
```

## Worked example 2 — posting-time test (warm studio voice)
```
HYPOTHESIS: an 8am post reaches our audience better than 1pm.
VARIABLE: posting time only. CONTROL: same carousel template, topic, caption length; repeat 4x.
PRIMARY: reach. RULE: 8am wins if reach +15% over 4 paired posts. GUARDRAIL: ER not worse.
READOUT: native analytics. RESULT: +9% (below threshold) -> a "tie": time isn't the lever here; test format next.
```

Both: one variable; pre-set rule + guardrail; controlled context; 3–5 reps; read from native analytics;
logged; scaled or dropped honestly. Winners feed `content-recycling`/`social-strategy`.
