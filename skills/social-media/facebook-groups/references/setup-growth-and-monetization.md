# Setup, growth, monetization + two worked examples

## Setup checklist (native — the agent advises; the user creates the group)
```
[ ] Niche: one specific audience ("everyone" is not an audience)
[ ] Name: keyword-rich + searchable ("Etsy Sellers Who Want Repeat Buyers", not "Our Community")
[ ] Privacy: Private (Visible) -- found in search, content members-only (~40% higher engagement)
[ ] 2-3 membership questions (filter quality + capture email/consent) + admin approval at first
[ ] Description (what members get + rules) + branded cover + discovery tags
[ ] Automated welcome message + pinned resource/start-here post
```

## Engagement calendar (in-group -- post natively / via community-management)
```
Daily, varied: educational post / discussion question / POLL (one-click) / short-form video (~3x) / occasional promo.
First 30-60 min: respond to every comment; notify your most engaged members. Saves + shares > likes. Never post-and-ghost.
No selling in the first 30 days of a new group.
```

## Growth playbook (quality, not blasts)
```
Invite: email list + social followers (target ~30% acceptance, ~40% 30-day retention).
Partner: non-competing admins -> co-host events, joint giveaways, shout-outs.
Magnet: a lead magnet gated behind a membership question or a welcome post.
Ads: you can't advertise INSIDE a group, but you can run ads to the group JOIN LINK.
Cross-post: genuine value in 20-50 related groups (manually) -- NOT bulk-poster automation (ToS/ban) or bought members.
Pace: 200-500 members/month -> ~1,000 in 2-4 months (2-4 weeks with an email list).
```

## Value-first monetization ladder
```
Value (answer questions, free resources) -> Trust (show up daily, know-like-trust) -> Sales (offers/coaching/membership/affiliate).
Warm niche groups: ~20-23% on direct offers; $3-15K/mo is common. The community is the product; revenue follows. Never fabricate revenue.
```

## The Page -> Group funnel (what WoopSocial publishes)
```
WoopSocial publishes the FACEBOOK PAGE post/Reel (+ IG/other channels) with the group JOIN LINK + a value hook ->
drives people to JOIN. WoopSocial does NOT post inside the group (FACEBOOK = the Page; no group target).
```

## Worked example 1 - course creator (blunt indie-founder voice)
```
ASSET: "Notion for Freelancers" group, Private(Visible), 3 questions (incl. email opt-in). ENGAGE: daily -- a tip, a poll,
a 30-sec screen-record; I reply in the first hour (community-management runs the moderation). GROW: invite my list +
genuine cross-posts; ads to the join link. MONETIZE: no pitch for 30 days, then my template pack. WoopSocial publishes the
PAGE posts that drive joins; I post inside the group natively. No bulk bots, no bought members.
```

## Worked example 2 - local studio (warm studio voice)
```
ASSET: "Rotterdam Home Bakers" -- niche, Private(Visible), warm rules. ENGAGE: a weekly bake-along poll, member spotlights,
short videos; we answer every comment. GROW: invite our newsletter + partner with a non-competing local admin. MONETIZE:
value first -- our workshops come up naturally after trust. WoopSocial publishes the Page + IG posts that funnel joins;
the group itself we tend by hand (-> community-management). We watch acceptance + retention, never vanity counts.
```

Both: a niche Private-Visible community asset; two-way daily engagement (no ghosting, no day-one selling); quality
growth (no automation/bots); value-first monetization; WoopSocial funnels via the Page while the group stays native.
