# The TRIBE framework — build a Facebook Group as your organic surface

Groups are the **10–30× Page-reach goldmine** — but only if you run them as a **community, not a broadcast.**
TRIBE structures the play. The agent **designs the strategy + drafts the group posts + drafts the Page/
cross-channel content that drives joins**; **WoopSocial publishes the Page + cross-channel funnel content
(not group posts)**; **in-group posting, admin, and moderation are human/native → `community-management`.**

## T — Treat it as a community asset, not a broadcast
- A niche, **keyword-rich** group, **Private (Visible)**, with **2–3 membership questions** + clear rules.
  The 10–30× Page-reach goldmine — **community engineering, not broadcasting.**

## R — Run two-way engagement daily
- Daily varied posts, **polls**, **short-form video (~3×)**; respond in the **first 30–60 min** (velocity/MSI).
  **Never post-and-ghost.**

## I — Invite quality, not blasts
- **Email list + social** (target ~30% acceptance / ~40% retention), **non-competing admin partnerships**, a
  **lead magnet**, **ads to the join link**, and **genuine** cross-posting in related groups. **200–500/month**
  — *no bulk-poster automation or bought members (ToS/ban risk; tanks ratios).*

## B — Build trust before selling
- **Value first, trust second, sales third.** **No selling in the first 30 days.** A warm niche →
  ~20–23% conversion / **$3–15K/mo.** The community is the product.

## E — Extend from the Page (and keep the group native)
- **WoopSocial publishes the Page + cross-channel content that drives joins** (the funnel). The **in-group
  posting, admin, membership questions, moderation + Group analytics are human/native** →
  `community-management` + `crisis-and-moderation`.

## The group plan a request should fill
```
ASSET: niche + keyword-rich name + Private(Visible) + 2-3 membership questions + rules (the 10-30x goldmine)
ENGAGE: daily varied posts + polls + short video; respond in the first 30-60 min; no sell first 30 days; no ghosting
GROW: email/social invites (30%/40%) + admin partnerships + lead magnet + ads to join link + genuine cross-posting (200-500/mo; no automation/bots)
MONETIZE: value first -> trust -> sales; warm niche -> offers/coaching/membership (never fabricate revenue)
PUBLISH (WoopSocial): the PAGE + cross-channel posts that drive joins -- NOT group posts. In-group posting/admin/moderation native -> community-management.
```
