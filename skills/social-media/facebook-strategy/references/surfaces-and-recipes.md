# Surfaces, recipes + two worked examples

## The three-surface system (play each for its job)
| Surface | Job | Optimise for | Notes |
|---|---|---|---|
| **Reels** | unconnected **discovery** | first 3s, retention, completion, shares | by category not brand; beats Page posts 5–10× |
| **Feed** | connected **depth/trust** | comments, saves, shares, dwell | photos (engagement), carousels, 3–8 min video |
| **Groups** | **community** | meaningful discussion, member reach | 20–40% reach; human-run (`community-management`) |

**The pairing:** for each theme, ship a **Reel (discovery)** + a **Feed post (depth)** — discovery turns
into relationship. Don't publish "for everyone"; one viewer, ~2 themes.

## Per-surface recipes
- **Reel (discovery):** hook (first 3s) → 1–3 points → payoff; vertical, captioned, native; category
  keywords in caption. (Script: `reels-script`.)
- **Feed photo/carousel (depth):** a value post — mini-tutorial, before/after, strong opinion that
  invites thoughtful replies; **link (if any) in the first comment**; ask a real question.
- **Long video (authority):** 3–8 min explainer/demo/breakdown for "time spent" + trust.
- **Group post (community):** ask, share a win, start a discussion — as a member, not a billboard;
  human-posted, replies handled live.

## Link & format rules
- **Link in the first comment**, never the post body (links = lowest reach). Or use a native Shop.
- **No engagement-bait** ("like & share"). **Don't** mass-post identical content to many Groups (spam).
- **Saves & shares > likes** — make it save-worthy and share-worthy.

## Worked example 1 — Reel+Feed pairing (blunt indie-founder voice)
```
THEME: freelancer tax (one of 2 core themes)
REEL (discovery): "Most freelancers overpay tax. One fix." → 3 fast points → "do this today." (vertical, captioned)
FEED (depth): carousel "The 30% rule, step by step" + "What's your setup? 👇" — link to the guide in FIRST COMMENT.
ENGAGE: post 9am; reply to every comment in the first hour.
```

## Worked example 2 — Group community + Feed (warm studio voice)
```
THEME: calm bookkeeping
GROUP (human): in a small-biz Group, "What's the one money task you keep avoiding? No judgment 💛" → reply to each.
FEED (depth): soft photo + "The one rule we give every client" mini-tutorial; question to invite replies.
REEL (discovery): 20s "the panic, fixed" founder-to-camera. Link (newsletter) in first comment.
```

Both: read brand-profile + voice-builder first; ~2 themes; Reel for discovery + Feed for depth +
Group for community; links in first comment; no bait; first-hour replies. Reels scripted via
`reels-script`; Page posts/Reels scheduled via `scheduling-and-queue → WoopSocial`; Group posting +
replies are human/in-app; measured in native Meta Insights.
