# The NORTH framework — turn wishes into a measurable cascade

Most social "goals" are wishes — "grow our following," "go viral," "do better." NORTH turns them into a
cascade you can manage: anchored to the business, one clear North Star per channel, SMART, benchmarked,
and capped for focus. (Setting targets is this skill; **measuring** them is `analytics-and-reporting`.)

## N — Name the business goal
- Anchor every social goal to a **real business outcome** (awareness / leads / sales / retention / care).
- If a metric doesn't **ladder up** to that outcome, it's vanity — cut it. Pull the outcome from
  `social-strategy`.

## O — One North Star per channel
- Pick **one North Star metric per channel**, tied to its **win condition**: awareness-first → reach;
  consideration-first → CTR/clicks; conversion-first → CVR/CPA.
- Add **1–2 supporting metrics** per North Star (diagnostics), not ten.

## R — Render it SMART
- Specific, Measurable, Achievable, Relevant, Time-bound — **a number + a deadline + a method.**
- "Grow newsletter sign-ups from social 200 → 300/mo by Q3 via Story link stickers" — not "get more clicks."

## T — Target from benchmarks
- Set the number from a **benchmark**: your own **baseline** (extrapolate past performance) or comparable
  accounts — **achievable yet ambitious.** No baseline → set a **learning goal** first (don't invent one).
- Use **leading + lagging** indicators; only commit to KPIs the team can **actually influence**.

## H — Hold to 3–5 + set triggers
- Cap at **3–5 KPIs / objectives** for focus. Set **action thresholds** ("if X holds but Y drops → do Z").
- **Review** weekly (metrics) / monthly (tactics) / quarterly (the goals themselves); **miss → pivot
  tactics before moving the goal.** Hand the targets to **analytics-and-reporting** to measure.

## The goals brief a request should fill
```
BUSINESS GOAL: the outcome this ladders up to (from social-strategy)
OBJECTIVE (SMART): number + deadline + method
NORTH STAR (per channel): the one win-condition metric + 1–2 supporting
TARGET: from baseline/benchmark — achievable yet ambitious (or a learning goal if no data)
GUARDRAIL: the quality floor that prevents gaming (e.g. ER while growing followers)
TRIGGERS + CADENCE: thresholds that force a choice; weekly/monthly/quarterly review
HANDOFF: measured by analytics-and-reporting
```
