# Platform Playbook

Hashtags do a different job on every platform, and the counts differ. Never paste one block
everywhere. Match the approach to where the audience actually is.

> Counts, caps, and behaviors are current 2026 norms — re-verify quarterly; platforms change these
> without much notice.

## Instagram

- **Hard cap: 5 hashtags** (enforced, rolled out Dec 2025). More are blocked or trimmed.
- Use **~3–5 precise, relevant** tags — niche/topic/community/location/branded, not generic.
- **Mid-tier tags (~10K–500K posts)** beat mega-tags — you can actually surface there.
- **Placement: in the caption** (indexed immediately for search). Some large accounts use the first
  comment for a clean caption; for most, caption is best for SEO.
- **Hashtags follow removed (Dec 2024)** — tags no longer feed subscribers; they're search/category
  signals only.
- **Reels:** lean on **trending audio + keywords**; hashtags just categorize. Audio often does more
  for reach than tags.
- **The real lever:** keyword-rich caption + on-screen text (Instagram indexes both).

## TikTok

- **~3–5 hashtags**, and **treat them as keywords**: `#BestBudgetLaptop`, not `#Tech`. One broad
  category tag + niche tags that match real searches.
- **TikTok is a search engine** (~half of Gen Z start product research there). The ranking move is
  the **triple mention** — primary keyword **spoken + on-screen + in the caption** (front).
- **#fyp / #viral are useless** — they don't affect FYP placement.
- **Avoid the 30-tag spray** — TikTok deprioritizes it.
- Optional SEO tactic: a **pinned keyword-rich comment** acts like a second caption.

## LinkedIn

- **~3–5 specific** hashtags, treated as a **lightweight topic signal, not a reach driver**.
  LinkedIn has deprioritized hashtag distribution (its own product lead calls them "nice to have,
  not need to have"); its algorithm reads semantic meaning from the post body directly.
- So the lever is **keywords in the post body**; if you tag, specific beats broad
  (`#SaaSLeadership` > `#Leadership`) — never a broad-tag pile.

## X / Twitter

- **0–2, often zero.** X has **deprioritized hashtags** (even called them clutter in ads); more than
  one or two can *reduce* engagement.
- Use a single tag only to **join a specific conversation or event** (a conference, a live moment).

## Threads

- **One topic tag per post** (Threads' model). Keep it relevant; don't force it.

## Pinterest

- **Keywords in the title and description are the lever** (Pinterest is a visual search engine).
  Hashtags are minor/deprecated — don't rely on them.

## YouTube

- **Keywords in the title and description** drive search. A few relevant tags/hashtags help; the
  first ~3 hashtags can show above the title. Don't stuff.

## Facebook

- Minimal. **1–2** relevant tags at most; hashtags do little for reach here.

## Quick reference

| Platform | Hashtags | Real lever |
|---|---|---|
| Instagram | 3–5 (hard cap 5) | keyword caption + on-screen text; trending audio (Reels) |
| TikTok | 3–5, as keywords | triple-mention keyword (spoken+on-screen+caption) |
| LinkedIn | 3–5 specific (light signal) | keywords in the body; tags don't drive reach |
| X/Twitter | 0–2 | the post itself; tag only to join a moment |
| Threads | 1 topic tag | the post + topic tag |
| Pinterest | minor | keywords in title/description |
| YouTube | a few | keywords in title/description |
| Facebook | 1–2 | the post itself |
