# Research, Types & Branded Tags

How to choose tags that do their (modest) job well, and how to build branded/campaign hashtags —
the one place hashtags still pull real weight.

## The eight hashtag types

Mix types deliberately; each does a different job:

- **Topic** — what the post is about (`#ProductManagement`). Core categorization.
- **Niche/community** — a specific community you belong to (`#BuildInPublic`, `#BookTok`). Where
  engaged people actually browse/search.
- **Branded** — unique to you (`#MyCalvins`). Community + UGC. (See below.)
- **Campaign** — tied to a launch/event (`#[Brand]LaunchWeek`). Tracking + participation.
- **Product/service** — what you offer (`#SocialMediaScheduling`). Intent/search.
- **Location** — geo, for local discovery (`#RotterdamStartups`). Powerful for local businesses.
- **Format** — when the format is the value (`#Tutorial`, `#CaseStudy`). Use sparingly.
- **Event/seasonal** — a live moment (`#SaaStrAnnual`). Time-bound only.

A typical post uses a few across **topic + niche + (sometimes) branded/location** — not all eight.

## Research & vetting

Choosing relevant, mid-tier, safe tags matters more than the count:

1. **Relevance first.** The tag must match the actual content. Irrelevant trending tags confuse the
   algorithm and can hurt reach.
2. **Aim mid-tier (~10K–500K posts).** Mega-tags (millions of posts) bury you in seconds; ultra-tiny
   tags have no audience. Mid-tier = real demand you can compete in.
3. **Check the tag page before using it.** Are the top posts like yours? Is there genuine
   engagement? Is it overrun by bots/spam? If it looks spammy or off-topic, skip it.
4. **Avoid banned/flagged tags.** Some innocuous-looking tags are spam-associated and suppress reach.
   If a tag's page looks blocked or sketchy, don't use it.
5. **Find them natively.** Use the platform's own search/suggestions and look at what well-performing
   creators **in your niche** actually use (analyze, don't copy their list wholesale).

## Build rotating sets, don't copy-paste one block

- Build **2–4 reusable sets per pillar/topic**, then rotate by what each post is actually about.
- Rotation keeps tags **relevant per post** (the thing that matters) and avoids the low-effort
  copy-paste pattern.
- Keep **1–2 consistent branded tags** across posts; vary the rest.

## Branded & campaign hashtags (the durable use)

This is where hashtags still earn real value — community, UGC, and tracking:

**Branded hashtag** (ongoing): a short, unique, memorable tag for your brand/community that followers
use when they post about you. Aggregates user-generated content and builds identity.

**Campaign hashtag** (time-bound): tied to a specific launch/event/promo, for participation and
tracking.

Design rules:
- **Unique and unused** — search it first; make sure it isn't already taken or tied to something
  off-brand.
- **Short, easy to spell, hard to typo.** Read it out loud; check for accidental other-words.
- **On-brand** and consistent across the campaign.
- **Promote it** — put it in the bio, in captions, in the CTA ("share yours with #__"), so people
  actually adopt it.
- **Track it** via the platform's native search (WoopSocial has no hashtag analytics — see below).

## Honest measurement

WoopSocial has **no hashtag analytics surface**. To see what's working, the user pulls **native
insights** (e.g., Instagram's per-post "reach from hashtags") or reviews qualitatively. Treat
hashtag choices as **experiments to observe**, not optimizations this skill can prove. Never claim
performance data you don't have.
