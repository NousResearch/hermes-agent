# Scripts, setup + two worked examples

## Writing for avatar delivery
Avatars read a script cleanly but can't ad-lib. So:
- **One idea, conversational, short sentences.** No tongue-twisters, no rapid-fire hype.
- **Open with the point**, not a greeting. Front-load the value.
- Write in the brand's voice (voice-builder); add light, natural phrasing the avatar can deliver.
- Mark **[B-ROLL]** cutaways inline so the editor knows where to break from the talking head.

## The setup brief (fill before rendering)
```
JOB / LENGTH: explainer | training | localization | sales | faceless — target seconds
AVATAR: stock | digital twin (consented) | talking photo (<15s)   ENGINE: Avatar IV | V
VOICE / LANGUAGE: cloned | stock; primary + any translations (175+ via Video Translator)
BACKGROUND / TEMPLATE / BRANDKIT: per brand-profile
B-ROLL PLAN: where to cut away (veo-3 / screen-record / text)
DISCLOSURE: caption + on-screen label plan
CONSENT: confirmed for any likeness? (required)
```

## Worked example 1 — faceless explainer (blunt indie-founder voice, ~30s)
```
AVATAR: stock (faceless channel)   ENGINE: Avatar IV   VOICE: stock, dry/calm
SCRIPT:
"Most freelancers get surprised by tax. Not because it's hard — because of one missing step.
[B-ROLL: screen-record of a bank app, two accounts]
Move thirty percent of every invoice into a second account the day it lands.
That's it. You never see the money, so you never spend it.
[B-ROLL: calendar flipping to April, calm]
Boring. Works. Saved me a very bad April."
DISCLOSURE: on-screen "AI presenter" + caption note. CONSENT: n/a (stock).
```

## Worked example 2 — localized founder twin (warm studio voice, ~25s, 6 languages)
```
AVATAR: founder Digital Twin (Avatar V, consented)   VOICE: cloned founder voice
SCRIPT (EN master, then Video Translator → 175+ langs, lip-sync):
"If tax season makes your stomach drop -- this is for you.
We use one account and one rule, and the panic just... goes.
[B-ROLL: tidy desk, banking app]
Move thirty percent the day a client pays. Small step -- big calm."
LOCALIZE: translate the master; keep the founder's cloned voice in each language.
DISCLOSURE: "Created with an AI avatar of our founder" + EU AI Act / TikTok auto.
CONSENT: founder consent verified for the twin.
```

## Notes
- Keep clips short and **cut away** so the face doesn't fatigue (TALK's K).
- A 5-minute monologue → break into segments; don't use a Talking Photo beyond ~15s.
- Generative B-roll comes from **veo-3 / ai-video**; long→Short cutdowns from
  **captions-and-clipping**. Finished video → scheduling-and-queue → WoopSocial.
