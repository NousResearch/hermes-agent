# The Image Brief

Before any prompt: decide what image this post actually needs. A prompt with no brief produces a
pretty, purposeless picture. This is the step the tool-specific skills assume you've already done.

## Start with the "should this even be AI-generated?" gate

AI image generation is one option, not the default. Often something else wins:

- **A real photo** — your actual product, space, team, or result. **Authenticity beats AI** for trust;
  raw/real content frequently outperforms polished AI, and AI **cannot** depict your real place/people.
- **A screenshot** — a testimonial, a result, a UI, a stat in context. Concrete and credible.
- **UGC** — a customer's photo/video (with permission). Social proof AI can't fake.
- **A chart/diagram** — for data, a clean chart (or a design tool) is clearer and honest.
- **Stock** — when generic is fine and faster.

Reach for **AI generation** when you need something that doesn't exist, must match a specific brand
look, needs legible in-image text, or you want a consistent series — and a real asset isn't available.
If a real asset is better, **say so**; don't generate for the sake of it.

## If you're generating, write the brief

Four questions, answered before prompting:

1. **Job / purpose.** What is this image *for*? Common social jobs:
   - **Stop-scroll hero** — earn the pause in the feed.
   - **Explainer / infographic** — make a concept/steps clear (verify the data).
   - **Quote / text graphic** — a line of copy as the visual (text-led).
   - **Product shot** — the thing itself, in context.
   - **Lifestyle / scene** — the world around the brand.
   - **Thumbnail** — the click (high contrast, a focal point, room for a few words).
   - **Background / overlay base** — a backdrop for text added later.
   - **Ad creative** — hero + offer + CTA.
2. **The one thing it must convey.** A single idea/feeling. If it's trying to say five things, it says
   nothing. Name the one.
3. **Format / aspect ratio** for the destination — 1:1, 4:5 (feed portrait/carousel), 9:16 (Stories/
   Reels/TikTok), 16:9 (thumbnail/landscape), 2:3/3:4 (Pinterest/poster). Decide up front.
4. **Brand look.** Pull from `brand-profile.md` — palette, visual style, typographic feel, do/don't —
   so the image looks like the brand, not generic. (Or capture it as a reference image / brand model in
   the tool.)

## Output of this step

A one-line brief you can hand to a prompt: *"[Job] for [platform, aspect ratio], conveying [the one
thing], in [brand look]."* From there → `prompt-anatomy.md` (describe it) → `choosing-the-tool.md`
(pick the model).
