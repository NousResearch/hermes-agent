# The FRAME framework — publish a Reel the way Instagram displays it

The Reel is made elsewhere; FRAME gets it **out** spec-clean. The agent **specs the publish settings + the
cover brief + the specs/safe-zone checklist + advises audio/tags**; **WoopSocial publishes postType REEL +
video + caption + cover**; **trending audio, Share-to-Feed, tags, quality + Insights are native/in-app**, and
the video/cover/burned-in captions come from other tools.

## F — Frame it 9:16, spec-clean
- **1080×1920, 9:16** (off 0.5625 → crops/letterboxes); **MP4/MOV, H.264, 30/60fps, ≥1080p, ≤4GB**; export
  ~15–20 Mbps to beat compression; **remove other-platform watermarks.**

## R — Reserve the safe zone
- **Top ~250px** (username) + **bottom ~350px** (caption + buttons) are UI. Keep **hook text / face / CTA** in
  the **central safe zone** so it survives the **4:5 feed crop + the 3:4 profile-grid crop.**

## A — Art the cover for the grid
- Choose the cover **before publishing**; a **custom upload beats a video frame**; key elements + **bold ≥60px
  text** in the **3:4-grid-safe center**; **can't edit after upload.** (→ `ideogram`/`nano-banana`.)

## M — Match caption + audio
- Publish the **keyword caption** (← `instagram-seo`); **audio beats silent + trending audio is pushed**
  (native, in-app); the **first-3-sec hook** (← `reels-script`); burned-in captions in the safe zone (←
  `captions-and-clipping`).

## E — Emit on schedule + mind what's native
- **WoopSocial publishes postType REEL + video + caption + cover**, scheduled + **spec-validated** (→
  `platform-specs-and-validation`). **Native/in-app:** trending audio, **Share-to-Feed**, collaborator/product
  tags, media-quality, **Reel Insights.**

## The publish brief a request should fill
```
FRAME: 9:16 1080x1920, MP4/MOV H.264 30/60fps <=4GB, ~15-20 Mbps; no other-platform watermark
SAFE ZONE: hook/face/CTA centered; clear of top ~250 + bottom ~350; survives 4:5 feed + 3:4 grid crops
COVER: custom upload, key elements + bold >=60px text in the 3:4-grid-safe center; CAN'T edit after (-> image tool)
CAPTION + AUDIO: keyword caption (instagram-seo); with-audio + trending audio (native); hook (reels-script); burn-in (captions-and-clipping)
PUBLISH (WoopSocial): postType REEL + video + caption + cover, scheduled + validated (platform-specs-and-validation)
NATIVE/IN-APP: trending audio, Share-to-Feed, collab/product tags, media-quality, Insights. Never fabricate reach.
```
