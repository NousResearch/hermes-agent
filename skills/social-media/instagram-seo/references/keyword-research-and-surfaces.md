# Keyword research, surfaces + two worked examples

## Keyword-research method (the agent advises; IG search is native)
```
1. Top-Reel scan: search your topic in IG; read the captions + on-screen text of the top 5 Reels. Recurring phrases = high-value keywords.
2. Competitor Name fields: if 4/5 use "| Business Coach", that's a high-volume term -- add it.
3. Google "People Also Ask": Google indexes IG, so PAA questions ("how do I...") become caption phrases.
-> Build a CLUSTER of 3-5 related terms (primary + supporting). NEVER fabricate a volume.
```

## Surface map (publishable vs native vs other-tools)
| Surface | Keyword | Who sets it |
|---|---|---|
| Caption (first sentence first) | primary + cluster, long-tail | **WoopSocial (content.text)** |
| Hashtags (3-5 labels, in caption) | niche topic tags | **WoopSocial (in content.text)** |
| Name field (display name) | "Name \| Niche" | native (advised) |
| Handle / username | keyword-relevant | native (advised) |
| Bio | niche + offer + location + CTA | native (advised) |
| Alt text | descriptive, matches caption | native / at-post (advised) |
| On-screen Reel text | the keyword overlay | image/video tool |
| First-3-sec spoken audio | the keyword out loud | creator / reels-script |
| Category + location | niche category, place tag | native |
| Auto-captions | (toggle on) | native |

## Search-first caption template
```
[Primary keyword as the first sentence -- what someone would search] . Then the value, with 1-2 supporting
cluster terms woven in naturally over 150-300 words. No stuffing. End: CTA. Then 3-5 niche hashtags.
e.g. "Easy vegan dinner in 10 minutes -- this high-protein chickpea bowl..." (not "POV: you're starving lol")
```

## Must-match checklist (Computer Vision cross-checks)
```
[ ] Caption topic == what's visually on screen (a "salad" caption on a "cake" video tanks ranking)
[ ] Alt text describes the actual image + includes the keyword
[ ] On-screen text + first-3-sec spoken keyword reinforce the same topic
[ ] Auto-captions ON; no other-platform watermark
```

## WoopSocial publish block
```
platform: INSTAGRAM | postType: POST | REEL | STORY | content.text: the search-first caption + 3-5 hashtags
(REEL: optional cover). Validate via platform-specs-and-validation. Profile/alt text/category/auto-captions are native.
```

## Worked example 1 - local coffee shop (blunt indie-founder voice)
```
CLUSTER from top-Reel scan: "best coffee shop austin", "austin specialty coffee", "where to work austin". CAPTION opens
"Best specialty coffee shop in Austin for remote work --". Name field "Brew | Austin Coffee" (I advise; owner sets it).
Alt text matches the latte photo. WoopSocial publishes the caption + 4 niche tags. No stuffing, no #coffeelover spam.
```

## Worked example 2 - fitness creator Reel (warm studio voice)
```
Reel on 10-min mobility. First 3 seconds I say "ten minute morning mobility routine" out loud; same as the on-screen text
and the caption's first line -- so Computer Vision sees a match. reels-script handles the script; the overlay -> an image tool.
Auto-captions on, TikTok watermark removed. WoopSocial publishes the caption; I advise the bio + alt text. Watch saves + watch-time.
```

Both: keyword cluster from real queries (no fabricated volume); search-first caption (publishable); profile labels +
alt text + on-screen/spoken keyword that MATCH; WoopSocial publishes the caption, the rest native/advised/other-tools.
