# Scope, distinctions + connections

instagram-seo is the **IG keyword-search layer** — research the queries and write the keyworded caption (and
advise the profile labels + visual signals) that make a post rank in Instagram search. The agent **researches
+ writes the search-first caption + specs the on-screen/spoken keyword + advises the profile/alt text**;
**WoopSocial publishes the caption**; **the Name field, handle, bio, alt text, category, and auto-captions are
native/advised**, and on-screen text/audio come from other tools/the creator.

## Honest scope (never violate)
- **The agent** researches keywords (**advises the method** — top-Reel scan + competitor Name fields + Google
  PAA — and **never fabricates volume**), writes the **search-first caption** (`content.text`, primary keyword
  first, **no stuffing**, 3–5 hashtag labels), **specs the on-screen text + first-3-sec spoken keyword**, and
  **advises** the Name field/handle/bio/alt text/category.
- **WoopSocial publishes** the IG post's **caption** (POST/REEL/STORY via `content.text`) — the publishable
  SEO surface.
- **WoopSocial does NOT:** set the **Name field/handle/bio** (profile — native), set **alt text** (native/
  at-post), set the **category/location** (native), toggle **auto-captions** (native), read **IG Search/
  Insights** (native), render the **on-screen text** (image/video tool), or record the **spoken audio**
  (creator/`reels-script`).
- **No keyword stuffing** (suppressed); **no irrelevant/clickbait hashtags** (hurt credibility); the **caption
  must MATCH the visual** (Computer Vision — no misleading); **remove other-platform watermarks**; **never
  fabricate volume or rankings.** **Verify-quarterly.**

## Distinct from its siblings
- **instagram-seo (this)** — **IG-specific** keyword search (Name field, closed-system + Google-indexed,
  Computer Vision caption-visual match, first-3-sec spoken keyword).
- **social-seo** — the **cross-cutting** platform-search framework (TikTok/IG/YouTube/Pinterest broadly); this
  is the IG depth.
- **pinterest-seo** — **Pinterest's** keyword search (boards, Trends, Rich Pins; an open, web-indexed,
  DA-94 system) — a different platform.
- **hashtag-strategy** — IG **deprioritized hashtags** to 3–5; **they pair** (tags label, keywords discover).
- **caption-writer** — the **caption craft**; this is the **search-optimization** of it (they pair).
- **instagram-growth** — the IG **account strategy**; **reels-script** — the **Reel script** (this specs the
  spoken/on-screen keyword). **ai-search-optimization** — being cited by **AI engines** (IG content is now
  indexed → can be cited).

## Where this connects
- **Reads first:** `brand-profile` (niche/voice), the **post topic/destination.**
- **Pairs with:** `caption-writer` (the caption), `hashtag-strategy` (the 3–5 labels), `reels-script` (the
  first-3-sec spoken keyword), `ideogram`/the video tools (the on-screen text overlay).
- **Routes to/from:** `instagram-growth` (the strategy), `social-seo`/`ai-search-optimization` (the
  cross-platform + AI search picture), `content-recycling` (re-cut a winning Reel into a keyworded carousel).
- **Publishes via:** `scheduling-and-queue → WoopSocial` (the caption; POST/REEL/STORY) +
  `platform-specs-and-validation`. **Measures with:** native **IG Insights** + `analytics-and-reporting`
  (profile visits from search, saves, reach from non-followers). **Profile, alt text, settings + IG Search
  stay native/human.**
