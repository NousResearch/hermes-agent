# The MATCH framework — rank an Instagram post/Reel in search

Instagram is a **keyword search engine** now — keywords (not hashtags) drive discovery, and the visual must
**match** the words. MATCH structures the SEO. The agent **researches + writes the search-first caption +
specs the on-screen/spoken keyword + advises the profile labels + alt text**; **WoopSocial publishes the
caption**; **the Name field, handle, bio, alt text, category, and auto-captions are native/advised**, and
on-screen text/audio come from other tools/the creator.

## M — Mine the real queries
- Scan **top-ranking Reels' captions + on-screen text** for recurring phrases; check competitors' **Name
  fields**; use **Google "People Also Ask"** (Google indexes IG). Build a **cluster of 3–5 related terms.**
  *Method only — can't query IG search or fabricate volume.*

## A — Anchor the caption to search
- Lead the **first sentence / first ~125 chars** with the **primary keyword** (natural long-tail matching
  intent); weave the cluster; 3–5 hashtags as **labels.** This is the **publishable** SEO surface (WoopSocial
  `content.text`).

## T — Tag the profile labels
- **Name field** = a search label ("Name | Niche"); a keyworded **handle**; an indexable **bio** (niche +
  offer + location + CTA). *Profile-level — native/advised.*

## C — Confirm the visual matches
- **Alt text**, **on-screen text**, and the **first-3-seconds spoken keyword** all reinforce the topic — and
  must **match the caption** (Computer Vision lowers ranking for a mismatch). **Auto-captions on**; **remove
  other-platform watermarks.** *On-screen text → an image/video tool; the script → `reels-script`; alt text →
  native.*

## H — Harvest over time across search + Explore
- **Search = keyword-driven; Explore = behaviour-driven.** Optimize for **saves/shares/watch-time**; the Raw
  Content Revolution rewards **human voice + retention.** Compounds over **90–120 days.** No stuffing / no
  irrelevant tags.

## The SEO brief a request should fill
```
QUERIES: top-Reel scan + competitor Name fields + Google PAA -> a 3-5 keyword cluster (method only; no fabricated volume)
CAPTION: primary keyword in the first sentence/125 chars; natural long-tail; cluster woven in; 3-5 hashtag labels (publishable: content.text)
PROFILE: Name field "Name | Niche" + keyworded handle + indexable bio (advised; native to set)
VISUAL MATCH: alt text + on-screen text + first-3-sec spoken keyword reinforce + MATCH the caption; auto-captions on; no watermark (-> reels-script + image/video tool)
HARVEST: search + Explore; saves/shares/watch-time; compounds 90-120 days; no stuffing / irrelevant tags
PUBLISH (WoopSocial): the caption (POST/REEL/STORY). Profile/alt/on-screen/audio/settings native/advised/other-tools; never fabricate volume.
```
