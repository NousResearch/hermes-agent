# Mechanics, stacks & worked examples

## The mechanic menu (pick by job + friction)
| Mechanic | Friction | Best job | Where it lives |
|---|---|---|---|
| Poll | one tap | decisions, relatable splits, validation | native sticker (human adds) / feed "comment A or B" |
| Emoji slider | one drag | nuanced feeling ("how excited?") | native sticker (human adds) |
| Quiz | a tap + payoff | teach via play, myth-busting | native sticker / feed "guess in comments" |
| Question box (scoped AMA) | typing | depth, connection, content engine | native sticker; answers batched into a series |
| This-or-that | one comment | genuine debate | feed post (WoopSocial publishes) |
| Caption-this | creative comment | fun, community energy | feed post |
| Add-Yours / challenge | create + post | UGC, community threads | native sticker / hashtag challenge (route rights to ugc-and-influencer) |
| Live AMA / Q&A | attendance | trust, real-time connection | native live (human runs; livestream-and-realtime) |

**Per-platform reality (2026 — verify-quarterly):** the sticker set above (poll / emoji slider / quiz / question
/ Add-Yours) is Instagram Stories; native poll *posts* also exist on X, LinkedIn, Threads, and YouTube (Community
tab, which also has quizzes) — Facebook polls live in Groups/Stories; TikTok has Q&A plus poll/quiz stickers on
videos. All are created in-app by the human (same native-only rule); a collab/co-authored post is a distribution
mechanic, not a participation ask → `collabs-and-cross-promotion`.

## Classic stacks (escalating friction)
Poll → Question ("tried X? yes/no" → "what happened?") · Quiz → Slider ("answer" → "how confident were you?") ·
Countdown → Poll ("launch in 3 days" → "will you be there?") · Poll result → follow-up content ("78% said X — so
here's the fix").

## Cadence that compounds
Recurring, named slots beat random asks: a Monday decision poll, a Wednesday quiz, a Friday scoped AMA. Consistency
trains participation; variety keeps it fresh. Track which mechanics *your* audience actually uses and double down.

## Worked example A — "Blunt indie founder" (decision poll, loop closed)
Story 1 (human adds poll sticker): "two landing page headlines. which one? A: 'invoices that get paid.' B: 'stop
chasing payments.'" → Story 2 next day: "1,204 votes, 71% said B. shipping it this week — you named the product's
voice. next decision coming friday." — real decision, one tap, result shared, ownership created.

## Worked example B — "Warm bookkeeping studio" (scoped AMA → series)
Story 1 (human adds question box): "It's tax-prep week — ask me anything about *getting ready for your first
filing as a freelancer*. I'll answer the best ones here all week (first names off unless you say otherwise)." →
Stories 2-6: one question per day, answered warmly, batched from the box. — scoped ask, permissioned, one box
feeding a week of content.

## Never
Run filler polls with no job · leave a loop unclosed · post a bare "AMA" · rig or fabricate results · astroturf
questions from fake accounts · punish wrong quiz answers · fabricate quiz facts · harvest sensitive data via
casual polls (answers aren't anonymous) · expose an individual's answer without consent · claim WoopSocial
attaches stickers or auto-DMs · dress a Story poll up as research.
