# The CUTS framework — direct a 4K, multi-shot, motion-driven clip

Kling isn't the all-round or the control tool — it's the **4K + multi-shot + motion-transfer**
producer. Reach for it for native 4K/60fps, a multi-shot sequence in one clip, its unique Motion
Control, or strong image-to-video at low cost. For production dialogue → **veo-3**; for edit-control/
consistency → `runway`. CUTS keeps a human directing — with consent and
disclosure as the spine.

## C — Compose the shots (the AI Director)
- Use **Multi-Shot** to storyboard up to **6 connected cuts** inside one ~15s clip — give each a shot
  size, camera, and beat; Kling holds spatial continuity.
- Introduce **characters/props up front** and keep descriptions consistent so they don't drift.
- Plan for ~15s total; for longer, stitch in the edit (extension drifts after ~30–60s).

## U — Use motion (Kling's edge)
- Describe **dynamic motion** concretely ("camera tracks back as the subject strides forward").
- **Motion Control:** transfer a motion pattern from a **reference video** onto your subject (clean
  solo motion transfers best; crowded reference degrades). **Consented/owned reference only.**
- For in-frame text (brand/price/headline), state it explicitly — Kling renders text well.

## T — Tie identity with references
- **Image-to-video is Kling's strongest mode** — animate a clean product/character still.
- Lock identity with **reference images (~4)** or a **3–8s reference video**; use Elements (up to 9
  images / 3 videos / 3 audio) for multimodal control.

## S — Scale resolution & ship
- Render **native 4K/60fps** when the job needs it; otherwise 1080p to save credits.
- **Audio is a guide track** (~3/5) → add final dialogue via **ai-voiceover**, captions via
  **captions-and-clipping**. Keep crowds ≤5; **verify** physics/hands; **Draft Mode** to iterate cheap.

## The spine: consent + disclosure (never optional)
- **Motion Control / Avatar only on consented performers / your own / licensed talent.** Never
  transfer a real, non-consenting person's motion, face, or performance (deepfake).
- **Disclose** AI-generated video (EU AI Act; TikTok auto; YouTube Altered-Content).

## The shot brief a request should fill
```
SHOTS: 1–6 cuts; per cut: shot size + camera + beat (multi-shot, ~15s total)
MOTION: described motion; Motion Control reference (consented)?
IDENTITY: image-to-video still? reference images/video to lock character/product
SCALE: 4K vs 1080p; aspect; Draft Mode to test
FINISH: audio = guide track -> ai-voiceover; captions -> captions-and-clipping
CONSENT + DISCLOSURE: confirmed
```
