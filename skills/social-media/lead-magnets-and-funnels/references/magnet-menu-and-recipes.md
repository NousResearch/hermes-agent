# Magnet menu, funnel + two worked examples

## Stage-matched magnet menu
| Goal | Best magnet | Format note |
|---|---|---|
| Want emails fast (top) | quiz, AI generator, calculator, checklist | low friction, instant result, shareable |
| Better-qualified (mid) | assessment, scorecard, template, benchmark report | surfaces intent + data to segment |
| Book calls/demos (bottom) | audit, grader, ROI/savings calculator | shows a gap you can close |
| Grow audience | shareable quiz or template | spreads naturally |
Default when torn: the format that gives an **instant, personalised result** (interactive wins). Templates
convert best when **specific-task + workflow-tied + industry-specific**.

## Funnel architecture (map before building)
```
PROMO POST (WoopSocial publishes) -> LANDING (benefit-first headline, 1 promise, trust marker, short form)
-> SUCCESS PAGE (access + what's next) -> DELIVERY EMAIL (resend asset, set expectations) -> NURTURE (3-5)
```
Form = **email (or +first name) only**. Test the whole path on mobile + desktop; small gaps = big leaks.

## Nurture sequence template (value-first, 3-5)
```
1 DELIVER: the asset + how to use it in 5 min (set expectations)
2 QUICK WIN: one specific result they can get today (reference what they came for)
3 PROOF: a short case/social proof that the approach works
4 SOFT NEXT STEP: invite the next step toward the offer (only now)
5 (optional) RECOVERY: gentle re-offer / branch for non-openers
```
**Branch on behavior:** clicked pricing -> a different track than opened-once-went-quiet.

## Worked example 1 — calculator funnel (blunt indie-founder voice)
```
AUDIENCE/PROBLEM: freelancers unsure what to charge. MAGNET: "Freelance Rate Calculator - see your number in 60s" (instant result, top-funnel).
OFFER LINK: connects to a paid pricing course. FUNNEL: landing -> email-only form -> result page -> delivery -> 4-email nurture.
PROMO: "Comment RATE or grab it in bio." (WoopSocial publishes) CAPTURE: link-in-bio + comment->DM. METRICS: builder + GA4.
```

## Worked example 2 — quiz to qualify (warm studio voice)
```
MAGNET: "What's leaking money in your bookkeeping?" 6-question quiz -> tailored 3-step result (mid-funnel, qualifies).
NURTURE: deliver result -> one quick win for their result type -> a client proof point -> soft invite to a free 15-min review.
BRANCH: "needs cleanup now" result -> faster invite; "just curious" -> more value first. TOOLS: quiz builder + ESP (external). -> email-and-newsletter
```

Both: one audience/one problem/one quick win; instant interactive result; tied to the offer; whole funnel
designed; behavior-branched nurture; WoopSocial only publishes the promo posts; metrics from external
tools + GA4 (never fabricated); no dark patterns.
