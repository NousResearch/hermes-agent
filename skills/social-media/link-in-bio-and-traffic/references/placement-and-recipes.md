# Placement, hub structure + two worked examples

## Placement + destination cheat-sheet
| Platform | Link placement | Best destination (intent) |
|---|---|---|
| Instagram | bio + Stories sticker + verbal CTA | lead magnet → email capture |
| TikTok | bio (1k+ followers) + verbal CTA | lead magnet / product (TikTok Shop) |
| X | **first comment** (or bio) | one specific page (tool/newsletter/product) |
| LinkedIn | **first comment** / Featured | booking / lead capture (high-value) |
| Facebook | **first comment** | lead magnet / event / native Shop |
| Pinterest | **link-out** on the pin | the exact relevant page (not homepage) |
| YouTube | description + pinned comment + About | deeper content / video-specific URL |

## The capture funnel (capture before sell)
```
Content (hook, value) -> CTA ("free [lead magnet] -> link") -> landing page (one promise, email field)
-> deliver the magnet -> nurture (email/newsletter) -> offer later
```
Primary CTA = the **lead magnet**, not the product. Value crystal clear on screen one.

## Bio-hub structure (when a hub is warranted)
1 **primary** CTA (the current priority — capture or launch) + **2–3 prioritized** secondary links
(newsletter, top product, best content). No graveyard. Mobile-first, high-contrast buttons, current
offers only. Rotate the primary weekly.

## UTM scheme (so you can see what converts)
`utm_source=instagram` · `utm_medium=bio` (or `story`, `comment`, `description`) ·
`utm_campaign=<offer>` · `utm_content=<post-or-video-id>`. Use a **branded short link**; read results in
**GA4** + the link tool. (A/B test the highest-traffic hub — ties `experimentation-and-ab-testing`.)

## Worked example 1 — IG lead-magnet capture (blunt indie-founder voice)
```
GOAL: grow the email list (owned).   PLATFORM: Instagram.
POST CTA: "Free 1-page freelance tax checklist. Link in bio." (verbal + caption)
BIO LINK: a single landing page -> one promise + email field -> deliver the checklist.
TRACK: branded short link, utm_campaign=tax-checklist. Rotate to next magnet in 2 weeks. -> email-and-newsletter
```

## Worked example 2 — X single-destination (warm studio voice, link in first comment)
```
GOAL: newsletter sign-ups.   PLATFORM: X (links suppressed in-post).
POST: a punchy, genuinely useful take (native, no link). 
FIRST COMMENT: "The full calm-bookkeeping checklist + monthly note -> [branded short link]"
DESTINATION: a one-promise newsletter page (no multi-step funnel — X bounces on funnels).
TRACK: utm_source=x, utm_medium=comment. -> social-strategy / experimentation
```

Both: owned-audience goal; one clear action; capture before sell; correct placement; branded short link
+ UTM; conversions read from GA4/the link tool (never fabricated). WoopSocial publishes the driving
posts; the hub/landing/email tools are external.
