# The CLICK framework — turn rented reach into owned audience

A platform rents you attention and can change the rules tomorrow. CLICK converts that rented reach into
an **audience you own** (email/SMS/community) and into outcomes — without wasting the most valuable real
estate you have. The agent designs it; WoopSocial publishes the driving posts; the hub/landing/email
tools are external.

## C — Capture an owned audience
- The real goal isn't "traffic" — it's an **owned list** that survives algorithm shifts. Lead with a
  **value-first capture** (lead magnet → email) **before** any ask to buy.
- Anchor the primary action to the **conversion goal** (`goals-and-kpis`).

## L — Lead to ONE clear action
- **Focus beats variety.** Kill the homepage and the link-graveyard. One clear next step (or a tight,
  *prioritized* hub) the visitor can take in seconds.
- Match it to the **intent of the content** that drove the click — not a generic catch-all.

## I — Intent-match the destination per platform
- **Instagram** → lead magnet + email capture (value clear on screen one). **X** → one specific
  destination, punchy, no funnel smell. **YouTube** → more substance. **LinkedIn** → booking / lead
  capture (high-value prospects).

## C — Carry the link correctly per platform
- Respect **link suppression**: **X / LinkedIn / Facebook → first comment**; **IG / TikTok → bio +
  Stories sticker + verbal CTA**; **Pinterest → link-out**; **YouTube → description + pinned comment**.
- (Mechanics: `x-growth`, `facebook-strategy`, `linkedin-growth`, `pinterest-growth`, `story-writer`.)

## K — Keep it tracked + fresh
- **Branded short link + UTM + GA4** for attribution (which post/video converts). **A/B test** the
  highest-traffic hub. **Rotate weekly, audit monthly** (dead links kill trust). **Never fabricate** a
  click or conversion.

## The traffic brief a request should fill
```
OWNED GOAL: the list/outcome to grow (email/SMS/community), tied to a KPI
PRIMARY ACTION: the ONE next step + the lead magnet (capture before sell)
DESTINATION: intent-matched page per platform (not the homepage)
PLACEMENT: per platform (first comment vs bio vs link-out vs description)
TRACKING: branded short link + UTM scheme + GA4; one A/B test running
FRESHNESS: weekly rotation + monthly audit; conversions read from the link tool/GA4 (never fabricated)
```
