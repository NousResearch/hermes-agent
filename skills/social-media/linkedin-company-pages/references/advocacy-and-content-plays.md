# Advocacy program, page content + two worked examples

## Employee-advocacy program blueprint (the growth engine — runs through personal profiles)
```
1. Leadership math: 20 employees x 500 connections = 10,000 reach vs 5,000 page followers. Get buy-in.
2. Pilot: 5-10 natural advocates (already active, real voice) before scaling.
3. Frictionless kit: give a ready post + 2-3 suggested angles. Employees PERSONALIZE (opener / opinion /
   question) -- NEVER identical copy (inauthentic + detectable + underperforms).
4. Notify Employees on high-priority page posts; coordinate engagement in the FIRST 60 MIN.
5. Light gamification (monthly recognition), not policing. Train on personal branding (-> linkedin-growth).
6. Track advocacy reach + UTM conversions to prove ROI.
-> Employees post from their OWN profiles. WoopSocial publishes the PAGE's own posts, not theirs.
```

## Page content-type table (organic)
| Format | Why | Note |
|---|---|---|
| Carousel / document | highest saves (saves ~5x a like) | step-by-step / framework |
| Short vertical video (<90s) + captions | +80% reach | completion matters |
| Custom image | 2x more comments | not text-only |
| Question / structured framework | 437% more views | sparks multi-threaded discussion |
| Text-only | ~0.42x reach -- avoid | |
| External link in body | -60% reach -- put it in the comments | |

## Content-assignment matrix
```
PAGE:     announcements, jobs/recruitment, official record, paid assets (Ads/Thought Leader Ads)
PERSONAL: thought leadership, opinions, stories (-> linkedin-growth) -- where the reach + trust are
BOTH:     product + case studies (personal for reach, page for the record)
```

## Worked example 1 - B2B SaaS, real advocacy engine (blunt indie-founder voice)
```
PAGE = credibility + paid launchpad. ENGINE = advocacy: 8-person pilot, frictionless kit they personalize,
Notify Employees + first-60-min engagement. Page posts = carousels (top saves) + short demo video, link in comments.
WoopSocial publishes the page's carousels/videos on schedule; employees post from their own profiles (-> linkedin-growth). Thought Leader Ads boost the founder's best post. Track advocacy UTM conversions.
```

## Worked example 2 - small team, founder-led (warm studio voice)
```
With a tiny team, the FOUNDER is the reach engine (people not logos; founder content ~4x). The page holds the
official record + recruitment + the Follow button, and is the launchpad for a light Thought Leader Ad on the
founder's post. WoopSocial publishes the page's announcements; the founder's profile growth -> linkedin-growth. Build the advocacy pilot as we hire. Carousels + a question post; links in comments.
```

Both: page as credibility hub + paid launchpad (honest about low organic reach); advocacy through personal
profiles is the engine; page-appropriate content (carousel/video, no text-only, links in comments); WoopSocial
publishes the page's own posts while advocacy + paid + native features stay human/native; metrics never fabricated.
