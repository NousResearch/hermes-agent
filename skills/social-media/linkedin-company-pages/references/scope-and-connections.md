# Scope, distinctions + connections

linkedin-company-pages is the **company-page (LINKEDIN_PAGES) strategy** — treat the page as a **credibility
hub + paid launchpad** and build the real organic engine, **employee advocacy.** The agent **strategizes +
designs the advocacy program + drafts page posts + drafts shareable content**; **WoopSocial publishes the
page's own posts**; **employees post from their own profiles, and the first-hour engagement, paid, and native
features are human/native.**

## Honest scope (never violate)
- **The agent** strategizes the page (its real jobs + content assignment), **designs the employee-advocacy
  program**, **drafts the page posts**, and **drafts shareable advocacy content + suggested commentary.**
- **WoopSocial publishes** the **company page's OWN posts** (`LINKEDIN_PAGES`: text + media + optional
  `link`; same fields as personal LINKEDIN — **no native document/carousel/poll field**) on a **schedule** —
  the publish bridge for the page.
- **WoopSocial does NOT:** post from **employees' personal profiles** (the growth engine — **human**, →
  `linkedin-growth`; you can't post as an employee), do the **first-hour engagement** (human), run **LinkedIn
  Ads / Thought Leader Ads** (native paid), build **native document/carousel** posts (no doc field — native),
  or run **Notify Employees / Showcase Pages / Events / Newsletters / Products / Page analytics** (native).
- **No engagement-bait** (suppressed), **no pods** (shadowban), **no forced-identical advocacy** (inauthentic
  + detectable), **no bought followers.** **Links in comments, not body** (−60%). **Organic page reach is
  genuinely low** — the page is **credibility + paid launchpad**, set expectations. **Never fabricate
  metrics.** **Verify-quarterly.**

## Distinct from its siblings
- **linkedin-company-pages (this)** — the **COMPANY-PAGE strategy** (credibility hub + paid launchpad +
  employee-advocacy program).
- **linkedin-growth** — the **PERSONAL profile strategy** (where the reach + trust are; **advocacy posting
  routes here** for each person's profile craft).
- **linkedin-post-writer** — the **single-post craft.**
- **social-selling-and-dm** — the **DM/outreach.**
- **ugc-and-influencer** / **collabs-and-cross-promotion** — **external creators** (BrandWorks/Creator
  Marketplace).
- **campaign-and-launch-planning** — campaigns the page is part of.

## Where this connects
- **Reads first:** `brand-profile` (positioning/voice), `goals-and-kpis` (awareness vs hiring vs pipeline).
- **Routes craft to:** `linkedin-post-writer` (the page post), `ideogram`/`nano-banana` (carousel/video visuals),
  **`linkedin-growth`** (the employees'/founder's **personal-profile** advocacy — the growth engine),
  `caption-writer` (lines).
- **Pairs with:** `social-selling-and-dm` (pipeline), `lead-magnets-and-funnels`/`email-and-newsletter`
  (the gated assets the page links to via comments), `campaign-and-launch-planning` (launches),
  `analytics-and-reporting` (page + advocacy UTM readout).
- **Publishes via:** `scheduling-and-queue → WoopSocial` (the page's own posts) +
  `platform-specs-and-validation`. **Employee posting, the first-hour engagement, paid, and native features
  stay human/native.**
