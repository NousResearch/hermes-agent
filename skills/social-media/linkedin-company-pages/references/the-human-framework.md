# The HUMAN framework — grow a LinkedIn company page in 2026

The page no longer carries reach — **people do.** HUMAN treats the page as a **credibility hub + paid
launchpad** and builds the real organic engine: **employee advocacy.** The agent **strategizes + designs the
advocacy program + drafts page posts + drafts shareable content**; **WoopSocial publishes the page's own
posts**; **employees post from their own profiles, and the first-hour engagement + paid + native features are
human/native.**

## H — Hub, not megaphone
- Treat the page as a **credibility hub + paid launchpad** (Ads + **Thought Leader Ads** run from it; official
  announcements, recruitment, Follow button, product pages) — **not** the organic reach engine (reach is
  structurally ~1–5%). Set honest expectations.

## U — Unleash employee advocacy
- **The primary organic lever:** people, not logos (~10× connections; 3% share → 30% engagement; ~5× leads).
  Design a **frictionless program** — shareable content + suggested commentary employees **personalize (not
  identical)**, **Notify Employees**, a **pilot** of natural advocates, light gamification, leadership math.
  Employees post **from their own profiles** (→ `linkedin-growth`).

## M — Move in the first hour
- **Employees engaging within ~60 min** is a strong quality signal → reach extends. **Coordinate** team
  engagement. **Executive/CEO content ~4×** the page.

## A — Anchor page-appropriate content
- **Carousel/document** (top saves), **short vertical video w/ captions**, **custom images** — **never
  text-only** (~0.42×). **Links in comments, not body** (−60%). **Questions/frameworks** → 437% views +
  saves (**Depth Score**). (Post craft → `linkedin-post-writer`; carousel/video visuals → `ideogram`/
  `nano-banana`.)

## N — Nurture cadence + measure
- **Consistent (weekly+)** → ~5.6× followers; respond fast; cross-promote the **Follow button**. **Track**
  followers, reach, engagement, and **advocacy UTM conversions**. **No bait / pods / forced-identical / bought
  followers.**

## The company-page plan a request should fill
```
PAGE ROLE: credibility hub + paid launchpad (Ads/Thought Leader Ads); announcements/recruitment/products
ADVOCACY: the program (frictionless kit + personalized commentary + Notify Employees + pilot); employees post from own profiles (-> linkedin-growth)
FIRST HOUR: coordinate employee engagement in the first 60 min; executive content leads
CONTENT: carousel/document/short-video/custom-image (no text-only); links in comments; questions/frameworks (-> linkedin-post-writer)
MEASURE: followers, reach, engagement, advocacy UTM conversions (native analytics; never fabricated); weekly+ cadence
```
