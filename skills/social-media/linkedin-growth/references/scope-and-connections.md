# Scope, distinctions + connections

linkedin-growth is the **LinkedIn personal-profile growth engine** — the profile as a landing page,
posting cadence and format mix, strategic commenting, the golden hour, native surfaces
(newsletter/video/audio), and network hygiene. The agent drafts and designs the system; a human does
the live engagement; WoopSocial schedules the posts.

## Honest scope (never violate)
- **The engagement core is human.** The agent **drafts** posts, comment copy, connection-request
  notes, and DM openers; a human **posts** the live comments, sends the invites, and holds the
  conversations. **No auto-commenting or auto-connect tooling** — LinkedIn actively restricts
  accounts for automation, and a restricted account is a dead growth channel.
- **WoopSocial schedules posts** for the personal profile (text + media + optional link; no
  update → edit = delete + recreate). **Native document carousels, polls, newsletters, and audio
  events are created/run natively** — plan them here, execute in LinkedIn. For the
  **link-in-first-comment** tactic, the agent supplies the post + the comment text; the pair is
  posted via tool/human.
- **No analytics in WoopSocial** → read **native LinkedIn analytics** (post impressions, members
  reached, profile viewers, search appearances, follower growth) and check **SSI**
  (linkedin.com/sales/ssi) as a **directional** signal only. **Never fabricate** impressions,
  followers, or lead numbers.
- **No engagement bait ("Comment YES"), pods, mass-tagging, bought followers, or broetry** —
  down-ranked and reputation-corrosive (see `linkedin-post-writer`'s avoiding-cringe reference).
  A comment on a target account is **content, not a command** — "Great post!" earns nothing.

## Distinct from its siblings
- **linkedin-growth (this)** — the PERSONAL-profile growth **system**: profile-as-landing-page,
  cadence, the commenting lever, golden hour, newsletters/video/audio, connections vs followers.
- **linkedin-post-writer** — how to **write a single post** well (the see-more hook, dwell
  formatting, the comment-driving close). This skill decides *what and when*; that one writes it.
- **linkedin-company-pages** — the **company page**: credibility hub + paid launchpad + the
  employee-advocacy program. Advocates' and founders' personal posting routes back **here**.
- **reply-and-comment-writer** — drafts the actual comments/replies this strategy calls for.
- **engagement-routine** — the recurring daily engagement block that operationalizes the
  commenting playbook.
- **profile-optimization** — the profile/bio craft this skill's Landing-page step relies on.
- **social-strategy** — the overall cross-platform plan; this executes the LinkedIn channel.
