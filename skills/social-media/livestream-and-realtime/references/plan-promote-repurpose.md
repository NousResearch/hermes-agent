# Plan, promote, run, repurpose + two worked examples

## Platform pick (verify-quarterly)
| Platform | Best for | Threshold / note |
|---|---|---|
| YouTube Live | evergreen discovery, replay, search, large events | mobile-live ~50+ subs |
| TikTok LIVE | vertical discovery, community, TikTok Shop live shopping | ~1,000 followers; unlimited length |
| Instagram Live | creator community, Q&A (sell via keyword-to-DM; native live shopping gone) | public + ~1,000 followers; schedule 1hr–90d |
| LinkedIn Live | B2B, webinars, thought leadership | via approved tools |
| X | realtime viral, reposts | X Premium + public profile |

## Run-of-show template
```
00:00 Hook (2-min tip/topic) + pin a comment with the topic (for late joiners)
02:00 Content: answer 5-7 pre-submitted Qs (collected via a Stories Q&A sticker)
       Engagement: greet joiners by name; recap for late joiners every few minutes
(opt) Live selling: feature product; pin products where native (TikTok Shop/YouTube) or pin a comment +
      keyword-to-DM (IG); flash discount valid during the live only
~end  CTA: keyword-to-DM ("comment LINK for the resource/offer") + where to go next
```

## Pre-live promo cadence (scheduled via WoopSocial)
```
T-1 week: announce + schedule the Live (followers can set a reminder)
T-2 days: teaser / "here's what we'll cover" + collect Qs (Q&A sticker)
T-1 day:  countdown + guest reveal
T-1 hour: "going live soon" reminder
(go-live itself is native -- the human hits Live in-app)
```

## Live engagement playbook (human / native)
```
Greet people by name as they join | read + answer comments aloud | recap the topic for late joiners |
keep energy up | feature products + pin CTAs (shopping) | drop the keyword-to-DM trigger | thank + CTA to close.
```

## Repurposing pipeline (scheduled via WoopSocial)
```
recording -> 3-6 short clips (captions-and-clipping) -> scheduled across platforms (cross-platform-repurposing)
          -> on-demand replay + a recap post + quote cards (content-recycling)  => one live = a multi-phase campaign
```

## WoopSocial flow
```
agent plans the live + run-of-show -> schedules the promo posts (WoopSocial) -> human runs the live NATIVELY
-> agent plans the repurpose -> clips scheduled + published (WoopSocial). WoopSocial does NOT broadcast the live,
do realtime comments/moderation, or run live shopping. Never fabricate viewer numbers.
```

## Worked example 1 - product brand, selling on IG Live via keyword-to-DM (blunt indie-founder voice)
```
Goal: sell the new drop. IG Live (we're public + over 1k). Run-of-show: 2-min hook, demo 3 products, flash code valid during
the live. IG has no native live product tags anymore, so the sell is "comment DROP for the link" (keyword-to-DM) + a pinned
comment. Promo: I schedule announce/teaser/countdown/reminder in WoopSocial. I go live in-app, greet by name, drop the keyword.
After: I cut 4 clips (captions-and-clipping), schedule them + a replay. WoopSocial never "runs" the live -- I do.
```

## Worked example 2 - B2B founder, LinkedIn Live (warm studio voice)
```
A monthly LinkedIn Live AMA. We collect questions in advance, prep a loose run-of-show, and schedule the promo + reminder through
WoopSocial. The founder hosts it live -- greeting people, answering by name, recapping for late joiners. Afterward we turn the
recording into a few short clips and a recap post, scheduled out over the next two weeks -- one conversation, a fortnight of content. No invented view counts.
```

Both: platform/goal scoped; run-of-show + tech ready; promo scheduled via WoopSocial; the live run natively by a human
(engagement + shopping native); the recording repurposed into scheduled clips; viewer numbers never fabricated.
