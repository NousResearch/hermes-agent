# Scope, distinctions + connections

livestream-and-realtime plans, promotes, runs, and repurposes **live/realtime moments.** The agent **plans the
live + schedules the promo + advises the live playbook + plans the repurpose**; **WoopSocial schedules the
promo + publishes the repurposed clips**; **the broadcast + realtime engagement + live shopping are native/
human.**

## Honest scope (never violate)
- **The agent** plans the **format/platform + run-of-show**, **writes + schedules the pre-live promo**,
  **advises the live-engagement playbook** (the human runs the broadcast), and **plans the repurposing.**
- **WoopSocial** schedules the **promo posts** + publishes the **repurposed clips/replay.** It does **NOT**
  broadcast/run the live (native — IG/TikTok/YouTube/LinkedIn/X), do **realtime comments/moderation**, or run
  **live shopping.**
- The **live broadcast + realtime engagement + live shopping** are **native/human.** **Never fabricate viewer
  numbers; never buy fake live views.** **Promote-before + repurpose-after is where WoopSocial adds value.**
  **Verify-quarterly** (thresholds/features).

## Distinct from its siblings
- **livestream-and-realtime (this)** — the **live-event format** (plan → promote → run → repurpose).
- **community-management** — **ongoing community** engagement, incl. **native live moderation** (this is the
  live *event*; in-the-moment moderation during it is community-management/native).
- **engagement-routine** — the **daily** engagement cadence (this is a live event).
- **campaign-and-launch-planning** — the **multi-post launch arc** (a live can be a **beat** in it).
- **captions-and-clipping** — the **clip craft/tool** (the repurposing **routes the recording there**).
- **content-recycling / cross-platform-repurposing** — the **reuse axes** (the recording is a **source**).
- **social-selling-and-dm / lead-magnets-and-funnels** — the **keyword-to-DM capture** during the live routes
  there.
- **reels-script / tiktok-script** — **scripted** short video (live is realtime/unscripted — a loose
  run-of-show, not a script).

## Where this connects
- **Reads first:** `brand-profile` (voice/goal), the **live's goal + audience.**
- **Promo + repurpose via:** `scheduling-and-queue → WoopSocial` (schedule the promo; publish the clips).
- **Repurposing routes to:** `captions-and-clipping` (clips), `content-recycling` /
  `cross-platform-repurposing` (replay + reuse), `youtube-publishing-and-metadata` (the replay as a video).
- **Capture routes to:** `social-selling-and-dm` / `lead-magnets-and-funnels` (keyword-to-DM intent).
- **Native moderation during the live:** `community-management`. **A live as a launch beat:**
  `campaign-and-launch-planning`. **Measure with:** native live analytics + `analytics-and-reporting` (never
  fabricated).
