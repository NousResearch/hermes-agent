# Formats, fit, safety + two worked examples

## Format + platform literacy (verify-quarterly)
| Platform | Meme shape | Note |
|---|---|---|
| TikTok | video + trending sound, green screen, duet | best distribution; trending audio = licensing risk for brands (ai-music-and-sound) |
| X | reactive screenshot + pithy text; copypasta | wit + speed; real-time conversation |
| LinkedIn | work-life / industry humor | witty not edgy; 1-2/week mixed with substance |
| Reddit | meme-native, subreddit-specific | participate genuinely -- brand broadcasting gets downvoted |
| Instagram | image macro + Reels | volume; carousel + reaction formats |
Formats: classic image macro (picture + text), reaction image, "which one are you", "tag a friend who...", nostalgia, self-own/meta, niche in-group joke.

## The brand-fit filter
```
[ ] Matches our voice/audience/values (not just "it's funny")
[ ] Would work even WITHOUT our logo on it
[ ] Niche/specific enough that our in-group says "I see you"
[ ] We genuinely understand it (not faking fluency)
-> if it fails, sit it out + use an evergreen on-brand format instead
```

## Safety -- the "don't" list
```
NO tragedies / disasters / sensitive events    NO divisive politics / culture-war bait
NO private moments / real people without consent NO appropriation of a culture/subculture that isn't yours
NO punching down at any group                    RESEARCH the origin + connotations first   ("if you have to ask, don't")
```

## IP checklist
```
[ ] Original meme visual (AI + human pass / custom photo / commissioned) -- not a copyrighted character
[ ] No celebrity/identifiable-person likeness used commercially without permission -- real OR an AI lookalike (2026 likeness crisis: actionable under US state right-of-publicity law; federal NO FAKES Act advancing -- verify-quarterly)
[ ] Catchphrase not trademarked by its creator
[ ] Trending audio cleared/licensed for a brand (or skip it) -> ai-music-and-sound
[ ] Credit the original creator when remixing UGC
```

## Execution playbook
```
Lo-fi + authentic > high-budget. Self-aware/self-deprecating/meta humor. AI for concepts -> HUMAN adds the final
~10% wit + sensitivity screen (beat the AI-slop filter). Cut approvals to ~1 person -> react in hours. Keep 40-50% of
the calendar open for reactive posts. Measure dark-social shares + brand search, not just likes.
```

## Worked example 1 - B2B SaaS, niche meme (blunt indie-founder voice)
```
Our audience: ops managers. The meme: a hyper-specific "the report that could've been a dashboard" format -- works without
our logo, lands only if you live that pain. Original visual in ideogram (no copyrighted character). One-person approval, posted
same day on LinkedIn + X. No tragedy, no trending-audio risk. If a format doesn't fit ops humor, I skip it -- forced is worse than nothing.
```

## Worked example 2 - cafe brand, cultural moment (warm studio voice)
```
A gentle, on-brand take on a seasonal moment our regulars actually share -- nothing divisive, nothing borrowed from a culture
that isn't ours. We build an original graphic in our template (design-and-templates), keep it warm and self-aware, and add the
human touch that makes it feel like us. If the trend doesn't suit our voice, we let it pass and post something evergreen instead -- one small, safe step.
```

Both: format understood + on-brand + safe + original visual; lo-fi + human-finished; posted fast or sat out; never a
copyrighted character, a tragedy, or a borrowed culture; relevance never faked.
