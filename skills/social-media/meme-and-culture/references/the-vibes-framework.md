# The VIBES framework — participate in culture without the cringe

Meme-done-wrong > no meme. VIBES is two creative steps wrapped in three hard gates. The agent **advises +
writes the copy/concept**; the **human/creator makes the asset + adds the final wit + sensitivity pass**;
**WoopSocial publishes/schedules** (reactive ones often posted in the moment).

## V — Verify you understand the format
- Know the **origin, meaning + connotations** before touching it (sketchy origins → backlash). If you have to
  **explain** the joke, it's dead. If you have to ask **"is this still cool?"**, it isn't.

## I — Is it on-brand?
- The **fit filter:** does it match the **voice/audience/values**? **"Would it work without your logo?"**
  **Niche/hyper-specific beats broad.** Off-brand/forced = worse than nothing.

## B — Brand-safety lines
- **Never** tragedies, sensitive topics, divisive politics, private moments, **appropriation**, or **punching
  down.** Research the origin. **Participation, not exploitation.** **If you have to ask, don't.**

## E — Earn the rights
- **Make ORIGINAL meme visuals** (AI + human pass / custom photo / commissioned) to dodge copyright; **no
  copyrighted characters or celebrity likeness without permission**; mind **trademarked** catchphrases;
  **trending audio is risky for brands** → `ai-music-and-sound`. The asset → `image-prompt`/
  `design-and-templates`.

## S — Ship it native + fast, or sit it out
- **Lo-fi + authentic**, not corporate; the **human adds the final wit + sensitivity pass** (AI is a start);
  **speed** matters (cut approvals; → `trend-jacking`). But if it **doesn't fit or you're late → sit it out.**
  WoopSocial publishes/schedules.

## The go / no-go a request should clear
```
FORMAT: origin + meaning understood? not reliant on explaining? still live (not peaked)?
FIT: matches voice/audience/values? works without the logo? niche enough?
SAFETY: no tragedy/sensitive/divisive/private/appropriation/punching-down? origin clean?  ("if you have to ask, don't")
IP: original visual (not a copyrighted character/celeb)? trending audio cleared? credit the creator?
SHIP: lo-fi + native? human wit + sensitivity pass done? fast enough? -> if any gate fails, sit it out.
```
