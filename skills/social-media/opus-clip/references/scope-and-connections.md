# Scope, distinctions & connections

## Honest scope (never violate)
- **The agent** plans the pipeline (source prep, genre/prompt settings, the triage plan, the QA checklist, the
  drip schedule, the credit math) and drafts caption fixes/hooks. **The human reviews every clip** — the
  three-question pass (stands alone / fair / serves) and final approval; the agent can't see the video and never
  fabricates "that clip works."
- **Automation honesty:** the OpusClip **API is reported Business-tier-only**; Zapier/Make integrations exist
  lower — but **no unreviewed auto-post pipeline regardless of tier.** Where no connection exists, the agent
  writes exact steps and the human executes.
- **WoopSocial publishes** the approved exports (measurement: the platforms' native analytics); it does **not** clip, edit, or score
  video. OpusClip's own scheduler exists — the WoopSocial split (10 platforms, validation, one queue) is a stated
  stack choice, not a fabricated limitation. Native-only bits (trending audio, stickers) are added in-app by the
  human either way.
- **The score spine:** the Virality Score is a proprietary prediction — triage, never truth, never a guarantee,
  never quoted as a performance metric. **The fairness spine:** clips of anyone else's words keep context and
  meaning (no manufactured endorsements/gotchas — deception/defamation risk); consent/likeness rules apply.
- **Never fabricate** tier prices, gates, capabilities, or metrics — tiers conflict across sources and the
  operational reliability (processing hangs, no SLA) is real; verify in-app, build slack into deadlines
  (verify-quarterly).

## Distinct from its siblings (route correctly)
- **captions-and-clipping** = the general clipping/repurposing *craft* skill; **this** = the OpusClip-specific
  tool execution of it (read it first; they pair — `tools/integrations/clipping.md` covers the multi-tool
  clipping layer, `tools/integrations/opus-clip.md` goes deep on OpusClip itself).
- **descript** = the long-form talk EDIT (master the episode there; Underlord's clip flags overlap — either can
  find candidates; this specializes the clip pipeline at volume).
- **capcut** = short-form styling/pace craft (polish OpusClip output there when clips need more than the built-in
  editor).
- **short-form-video-script** = the retention craft the QA pass applies (hooks, first seconds).
- **tiktok-video-publishing / instagram-reels-publishing / youtube-shorts** = platform publish specifics.
- **podcast-and-audiograms / youtube-long-form** = the source content strategies feeding this.

## Where this connects
- **Reads first:** captions-and-clipping (the craft) + the source skill (podcast-and-audiograms /
  youtube-long-form) + brand-profile/design-and-templates (the clip template).
- **Pulls the master from:** descript (the edited episode), livestream-and-realtime (VODs), webinar recordings.
- **Feeds:** capcut (extra polish), tiktok-video-publishing + instagram-reels-publishing + youtube-shorts,
  content-recycling, scheduling-and-queue.
- **Publishes via:** approved exports → scheduling-and-queue → **WoopSocial.**
- **Tool file:** `tools/integrations/opus-clip.md` (tiers, credit mechanics, API gating, reliability cautions).
- **Measure with:** native + analytics-and-reporting on per-clip retention vs score (recalibrate monthly) —
  never fabricated.
