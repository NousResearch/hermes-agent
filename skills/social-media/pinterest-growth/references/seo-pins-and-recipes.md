# SEO workflow, pin checklist + two worked examples

## Keyword research workflow
1. Start with a **pillar** (one topic at a time). 2. In **Pinterest search**, type the seed term and
read **autocomplete** + the **guided-search tiles**. 3. Check **Pinterest Trends/Predicts** for
seasonality + rising terms. 4. Scan **related pins** of top results for the language people use. 5.
Collect **long-tail, high-intent** phrases ("budget freelance tax tips", not "tax"). (Cross-check with
`social-seo`.)

## The pin SEO checklist (every pin)
- **Title:** keyword + clear benefit ("5 Freelance Tax Tips to Stop Overpaying").
- **Description:** 2–3 natural keyword phrases + context + a CTA ("Read more").
- **Board:** keyword-themed, specific ("Freelance Finance Tips").
- **Alt text + image file name:** keyworded (e.g. `freelance-tax-tips-2026.jpg`).
- **Link:** the **relevant** page that delivers (not the homepage).
- **Design:** 2:3 (1000×1500), keyword text overlay, on-brand, scroll-stopping.

## Boards / cluster structure
Pick one pillar → 3–6 keyword-themed boards under it → 3–7 fresh pins/week per board. Keep boards
unmistakably on-topic (cluster authority). Don't dump 5 pins to one board in a day — **space them.**

## Fresh-design strategy
For each blog/product/landing page, make **3–5 distinct pin designs** (different image, layout,
overlay, angle) and publish them **over time** (≥72h apart for the same URL). Distinct designs = more
fresh pins = more distribution + more shots at the top 1% that drive most traffic.

## Pin type by goal
| Goal | Pin type | Note |
|---|---|---|
| Traffic / clicks | Static (links out) | the workhorse |
| Engagement / reach | Video (9:16, 6–15s) | ~2× engagement; links too |
| Shopping | Product / Collage / Rich | shoppable |

(Idea Pins are retired — Pinterest unified everything into one Pin format; every pin can carry a link.)

## Worked example 1 — evergreen blog traffic pin (blunt indie-founder voice)
```
PILLAR: freelance finance   BOARD: "Freelance Tax Tips"
TITLE: "The 30% Rule That Saved My Tax Bill"
DESC: "Most freelancers overpay tax. Move 30% of every invoice to a second account the day it lands.
Simple freelance tax tip that actually works. Read the full breakdown."
DESIGN: 2:3, bold overlay "THE 30% RULE", terminal-green accent (via ideogram). FILE: freelance-30-percent-tax-rule.jpg
LINK: the specific blog post (not homepage). VARIANTS: 4 distinct designs, 72h apart.
```

## Worked example 2 — seasonal gift-guide pin (warm studio voice)
```
PILLAR: gifting   BOARD: "Gifts for Small-Business Owners"
TITLE: "12 Calm Gifts for the Overworked Founder (2026)"
DESC: "A gentle gift guide for the small-business owner in your life -- practical, calm, and under $50.
Save for later." LAUNCH: 60-75 days before the holiday.
DESIGN: 2:3 collage-style, soft palette, "2026 GIFT GUIDE" overlay. LINK: the gift-guide page.
```

Both: keyword-led; 2:3; relevant link (not homepage); brand voice; designs via `ideogram`/`nano-banana`;
scheduled steadily (72h between same-URL) via `scheduling-and-queue → WoopSocial`; measured in native
Pinterest Analytics. Evergreen ones pair with `content-recycling`; seasonal ones launch early.
