# Scope, distinctions + connections

pinterest-pin-design is a **design-craft skill** — it designs the pin's concept, composition, and overlay,
produces the **brief**, and plans the **fresh-pin variants**. The agent **designs + briefs + critiques +
plans**; a **human or image tool makes the raster**; **WoopSocial publishes the finished pin** (image +
title + description + board + link).

## Honest scope (never violate)
- **The agent** designs the **concept**, the **composition**, the **overlay text**, and the **design
  brief**, plans the **3–5 fresh variants per URL**, and can **critique a mockup** — but a **HUMAN or an
  image/design tool** (`ideogram` for in-image text / `canva` / `nano-banana` / a designer) **creates the final
  raster.** The agent doesn't render the pixels.
- **WoopSocial publishes** the finished pin — **image + title (≤100) + description + board
  (`pinterestBoardId`) + link (≤2048)** — and that is ALL it does here: it does **NOT** design, template,
  or generate the visual, and it has **no analytics** — saves/outbound clicks/impressions come from
  **native Pinterest Analytics.**
- **The words are pinterest-seo's:** the keyword research, the keyword-led title/description, and board
  names/descriptions. This skill **renders the keyword visually** (the overlay) — it doesn't pick it.
- **No misleading pins** — the image must promise what the destination delivers (**Pin → Board → Page
  match**; long clicks rank, bounces punish, and a pin lives ~4 months, so deception compounds against
  you). **No repin-as-fresh dupes** (a color swap is not a fresh pin; near-identical volume gets
  suppressed). **No unconsented real-person faces.** **Disclose GenAI imagery** (users can filter it) and
  **FTC-disclose affiliate pins.** **Never fabricate engagement.** **Verify-quarterly** (formats/feed
  rendering move — idea pins especially).

## Distinct from its siblings
- **pinterest-pin-design (this)** — the pin's **VISUAL craft + brief + fresh-variant plan** (2:3, overlay,
  focal point, brand template, covers).
- **pinterest-seo** — the **keyword / search-RANKING layer.** **They PAIR:** the keyword goes in the
  **overlay AND the title** — pinterest-seo picks it, this skill renders it legibly.
- **pinterest-growth** — the **account strategy** (boards/clusters, cadence, ~72h same-URL spacing,
  seasonal 45–90-day lead, link-out strategy). It calls for "3–5 distinct designs per destination" — this
  skill is where those designs get made.
- **design-and-templates** — the **brand template SYSTEM**; the pin template is **one asset type in** that
  system (its 2:3 1000×1500 slot routes here).
- **thumbnail-design** — the **same craft for YouTube's 16:9** click decision; different job (click-to-watch
  vs save-and-click-out), different canvas, different text rules.
- **ideogram** / **canva** / **nano-banana** / **flux** — **generate/produce the raster** this skill briefs
  (ideogram especially for the overlay text; flux for backgrounds).
- **quote-cards-and-text-graphics** / **infographic-and-data-viz** — other single-asset graphic types; a
  quote card or infographic **repurposed to 2:3 for Pinterest** comes through here for the pin treatment.

## Where this connects
- **Reads first:** `brand-profile` (palette/fonts/style), the **destination** (the page the pin links to),
  and the **keyword** from `pinterest-seo`.
- **Pairs with:** `pinterest-seo` (keyword in the overlay + title), `image-prompt` → `ideogram`/`nano-banana`/
  `flux` (render the brief), `canva` (template production), `ai-image-editing` (crops/variants/cleanup),
  `design-and-templates` (the pin template family), `before-after-and-transformation` (honest split-frame
  pins).
- **Routes to / from:** `pinterest-growth` (strategy/cadence/boards), `content-recycling` +
  `cross-platform-repurposing` (which evergreen URLs deserve fresh variants; what gets re-cut to 2:3),
  `seasonal-and-moment-marketing` (the 45–90-day seasonal window), `competitor-analysis` (preview against
  the pins ranking for the keyword).
- **Publishes via:** `scheduling-and-queue → WoopSocial` (pin image + title + description + board + link) +
  `platform-specs-and-validation` (2:3 checks). **Measures with:** native **Pinterest Analytics** +
  `analytics-and-reporting` (saves, outbound clicks, impressions). **The raster stays with the image tools/
  designer; the keyword stays with pinterest-seo; cadence stays with pinterest-growth.**
