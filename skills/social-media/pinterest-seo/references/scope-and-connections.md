# Scope, distinctions + connections

pinterest-seo is the **keyword / search-ranking layer** — it researches the queries and writes the keyworded
words that make a pin rank. The agent **researches + writes the title/description + specs the on-pin keyword +
advises the board/link**; **WoopSocial publishes the pin's title + description + board + link**; **profile,
board setup, alt text, Rich Pins, and the research tools are native/advised.**

## Honest scope (never violate)
- **The agent** researches keywords (**advises the method** — autocomplete + Guided Search bubbles + Trends —
  and **never fabricates volume**), writes the **keyword-led pin title (≤100)** + **description**
  (`content.text`, natural, no stuffing), **specs the on-pin overlay keyword** (rendered by an image tool),
  and **advises** board names/descriptions + a **keyword-aligned link.**
- **WoopSocial publishes** the pin's **title (≤100) + description + board (`pinterestBoardId`) + link
  (≤2048)** — the **publishable SEO surfaces.**
- **WoopSocial does NOT:** set **profile name/bio** keywords, **create/rename/describe boards**, set **alt
  text** or **image file names**, **claim the website** or enable **Rich Pins**, query **Pinterest Trends/
  autocomplete/Analytics**, or render the **on-pin text** — all **native/human** (the agent advises them).
- **No keyword stuffing / over-optimization** (recognized + suppressed); **natural language.** **Pin → Board
  → Page must actually match** (the page delivers the pin's promise — no misleading). **Fresh pins, not
  dupes.** **Never fabricate search volume or rankings.** **Verify-quarterly.**

## Distinct from its siblings
- **pinterest-seo (this)** — the **keyword / search-RANKING layer** (research + keyworded title/description +
  board alignment).
- **pinterest-pin-design** — the **VISUAL craft** (2:3, overlay, focal point). **They PAIR:** the keyword
  goes in the **overlay AND the title.**
- **pinterest-growth** — the **account / visual-search STRATEGY** (boards, link-out, evergreen, fresh-pin
  cadence).
- **social-seo** — **cross-cutting** platform search (TikTok/IG/YouTube broadly); this is **Pinterest-specific
  depth** (autocomplete/Guided Search/Trends/board alignment/Rich Pins).
- **ai-search-optimization** — being cited by **AI engines** (optimized pins also influence AI visual/product
  results). **hashtag-strategy** — Pinterest **deprioritizes hashtags** (keywords win).

## Where this connects
- **Reads first:** `brand-profile` (niche/voice), the **destination** (the page the pin links to).
- **Pairs with:** `pinterest-pin-design` (the keyword in the overlay + title), `caption-writer` (the
  description), `ideogram` (the on-pin keyword overlay).
- **Routes to / from:** `pinterest-growth` (the strategy/cadence), `content-recycling` (fresh variations of an
  evergreen URL), `social-seo`/`ai-search-optimization` (the cross-platform search picture),
  `link-in-bio-and-traffic` (the destination).
- **Publishes via:** `scheduling-and-queue → WoopSocial` (title + description + board + link) +
  `platform-specs-and-validation`. **Measures with:** native **Pinterest Analytics** + `analytics-and-
  reporting` (saves, long clicks, search impressions). **Profile, board setup, alt text, Rich Pins + the
  research tools stay native/human.**
