# The FOUND framework — rank a pin in Pinterest search

Pinterest is a **search engine**, so ranking is keyword + relevance + engagement, not followers. FOUND
structures the SEO. The agent **researches the queries + writes the keyworded title/description + specs the
on-pin keyword + advises the board/link**; **WoopSocial publishes the pin's title + description + board +
link**; **profile, board setup, alt text, Rich Pins, and the research tools are native/advised.**

## F — Find the real queries
- **Pinterest autocomplete + Guided Search bubbles + Trends/Predicts.** **Long-tail (3+ words)**; ~97%
  unbranded; think like a searcher. *The agent advises the method — it can't query Pinterest's tools or
  fabricate volume.*

## O — Optimize the pin's words
- **Title:** lead with the primary keyword — `[Keyword] | [Benefit] | [Context]` (≤100). **Description:**
  natural, keyword-rich, ~100–200 chars, **no stuffing.** These are the **publishable SEO surfaces** (via
  WoopSocial). Spec the **on-pin overlay keyword** → render in `ideogram` (text-in-image).

## U — Unify Pin → Board → Page
- The pin, its **semantically-precise board**, and the **destination page** all reinforce the **same keyword
  phrase.** **Claim the site + enable Rich Pins**; the **link must deliver the pin's promise** (long clicks =
  top signal).

## N — Nest keywords across every surface
- **Keyword layering:** profile name/bio (broad) → board titles/descriptions (topic) → pin title/description/
  alt text/file name (long-tail). *Most are native/advised; WoopSocial publishes the pin's title + description
  + board + link.*

## D — Deploy fresh, in clusters, on a seasonal clock
- **Fresh keyword-optimized pins** (not dupes — each a new ranking chance); publish **related clusters**;
  **seasonal 45–90 days ahead** via Trends; optimize for **saves + long clicks**; compounds over the ~4-month
  pin life.

## The SEO brief a request should fill
```
QUERIES: seed -> autocomplete + Guided Search bubbles + Trends; pick long-tail (3+ words) with intent (method only; no fabricated volume)
TITLE: [Primary Keyword] | [Benefit] | [Context] (<=100)   DESCRIPTION: natural, keyword-rich, 100-200 chars, no stuffing
ON-PIN: the keyword in the overlay (-> ideogram)            BOARD: semantically precise name (advised; native to set)
ALIGN: Pin -> Board -> Page reinforce one phrase; claimed site + Rich Pins (native); link delivers the promise
DEPLOY: fresh (not dupes) + clusters + seasonal 45-90 days ahead; optimize for saves + long clicks
PUBLISH (WoopSocial): title + description + board (pinterestBoardId) + link (<=2048). Rest native/advised; never fabricate volume/rankings.
```
