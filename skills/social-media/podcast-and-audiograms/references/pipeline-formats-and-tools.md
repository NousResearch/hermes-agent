# Pipeline, formats, tools + two worked examples

## Production pipeline
```
1 record -> 2 transcribe (Descript/Castmagic) -> 3 timestamp standout moments (+ retention spikes) ->
4 generate 5-8 clips/audiograms (Opus Clip/Choppity/Headliner) -> 5 add hook + captions + branding ->
6 strategic CTA -> 7 WoopSocial publishes across platforms on a cadence. (Full episode stays on the host.)
```

## Format decision + specs
| You recorded | Format | Spec |
|---|---|---|
| Video | video-podcast clip | 9:16 (1080x1920), reframe to active speaker, captions, 30-90s |
| Audio only | audiogram | cover art + animated waveform + captions + title; 9:16 / 1:1 / 16:9 |
| One great line | quote card | on-brand graphic (-> design-and-templates) |

## Tool table (verify-quarterly)
| Job | Tool |
|---|---|
| Edit the episode | Descript (text-based, filler removal, publishes to Spotify/Apple/YT) |
| Auto-clip video | Opus Clip (virality score, reframe) / Choppity (best conversational accuracy) / Kapwing (free) |
| Audiograms | Headliner (waveform builder, Eddy AI, RSS) / Podsqueeze / Opus.pro |
| Written repurposing | Castmagic (show notes/blog/captions/quotes) |
| Caption burn-in (video clips) | -> captions-and-clipping / clipping.md |
| Distribution scheduling | **WoopSocial** (publishes the finished files) |
Honest: **Opus Clip is not an editor** -- little creative control; add the hook/overlay/CTA in another editor or via captions-and-clipping.

## Audiogram anatomy
```
[ cover art / brand background ]  [ animated waveform: bars/circles/lines ]  [ burned-in captions ]  [ episode title + handle ]
Save a template so every episode's audiograms match (-> design-and-templates). Export 9:16 / 1:1 / 16:9.
```

## CTA library (a reason to listen -- not "check out the full episode")
```
"Find out why [guest] changed their mind -- full episode linked."   "We argued about [topic] for 20 minutes. Hear who won."
"The part that surprised me is in the full episode."                 "What would you do here? Full story in the episode."
```

## WoopSocial flow
```
agent plans the clips (retention-based) + writes hooks/CTAs + the cadence -> tool clips/generates -> creator finalizes
-> WoopSocial publishes the finished clips/audiograms on schedule. WoopSocial does NOT record/edit/transcribe/clip/
generate audiograms/host the podcast/pull retention. Captions non-optional. Never fabricate virality.
```

## Worked example 1 - video podcast (blunt indie-founder voice)
```
60-min video episode. I check YouTube Studio for the two replay spikes, pull those + 4 transcript moments = 6 clips. Opus Clip
reframes to the speaker; I fix the hooks + add a real CTA ("hear who won the argument -- full ep linked"). Captions on all of
them, no exceptions. WoopSocial schedules them Tue/Thu/Sat across Reels/Shorts/TikTok + a LinkedIn quote card. The full ep stays on my host.
```

## Worked example 2 - audio-only show (warm studio voice)
```
An audio-only interview show. We pick three warm, quotable moments from the transcript and build audiograms in Headliner -- our
cover art, a gentle waveform, captions, the episode title -- all from a saved template so they match. Each ends with a reason to
listen, linked to the episode. We hand the finished audiograms to WoopSocial to publish across the week. Recording + hosting stay where they already live.
```

Both: retention/transcript-led selection; the right format (clip vs audiogram); hook + captions (always) + a reason-to-listen
CTA; on-brand template; WoopSocial publishes the finished files on a cadence; the full episode stays on the podcast host.
