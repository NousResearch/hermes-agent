# Profile Optimization

Your profile is a **conversion landing page, not decoration.** Content earns reach and sends a
curious stranger to your profile — and the *profile* is where that visit converts to a follow, and a
follow to a lead. Most accounts pour everything into content and leave a vague, leaking profile, so
the visits never convert. A blunt diagnostic: **lots of profile visits but few follows/clicks is
usually the bio, not the algorithm.**

Two commitments:

1. **Clarity beats cleverness.** A visitor decides in seconds. Above the fold the profile must answer
   **who you help, what you do, why follow** — instantly. A witty-but-vague bio converts worse than a
   plain, specific one.
2. **Every element has a job.** The name field is *searchable*. The link is the *conversion
   mechanism*. The banner is *prime real estate*. "Filled in" isn't optimized.

> Scope: this skill is **advisory** — it produces a ready-to-apply spec. **WoopSocial publishes posts
> and media; it does not edit profile fields**, so the user applies the spec in each app.

## Step 0 — Read the foundation

Load `brand-profile.md`, `social-strategy.md`, `audience.md`, `voice.md`. The profile is positioning
made concrete: who you help + the wedge (brand/strategy), the audience's language (audience), the
primary goal → the CTA/link (strategy), and the tone (voice).

## Step 1 — Run the funnel + the 3-second test

Diagnose the profile as a funnel — **Discovered → Clarity → Follow → Convert** — and find which stage
leaks (unfindable / unclear / unconvincing / dead-end). Make sure the above-the-fold answers
who/what/why at a glance. Niche down — **"for everyone" converts no one.** See
`references/the-profile-funnel.md`.

## Step 2 — Exploit the searchable fields (get discovered)

Put a **niche keyword** in the searchable fields — the **Instagram name field**, the **LinkedIn
headline**, the **YouTube description** — not just your name or "Founder." Think like your audience:
what would they search? Keep the handle searchable and consistent. See `references/element-playbook.md`.

## Step 3 — Write the bio (earn the follow)

Who you help · what you do · **proof** (real only) · **CTA + link prompt** — clarity first,
personality second, skimmable, within the limit, on-voice. See `references/element-playbook.md`.

## Step 4 — The link + CTA (convert)

**Match the link to the current goal** (one clear destination beats a 15-link junk drawer; if you
need a hub, lead with the priority action). Pick **one** primary CTA. Make the bio say *why* to click.
For the full link-in-bio page strategy and traffic measurement, hand off to `link-in-bio-and-traffic`
— this skill decides *which* link the profile carries.

## Step 5 — The visual + first impression

Profile **picture** (face for personal brands, clean logo for companies; recognizable at thumbnail).
**Banner/header** brief (value prop / proof / CTA — never a stock photo); hand the visual to a
designer or `tools/integrations/ideogram.md` (legible text). **Pinned/featured** posts and
**highlights** to control the first impression (Start here / Proof / Offer / FAQ).

## Step 6 — Per-platform spec + consistency

Produce a **ready-to-paste spec per platform** (handle, name field, bio, link, CTA, pinned plan,
highlights, banner brief), each passing the 3-second test. Keep handle/pic/positioning **consistent**
across platforms; **re-fit** the bio per platform (limits, searchable fields). See
`references/platform-specs.md`.

## Quality bar — self-check

- Does it pass the **3-second test** (who/what/why above the fold)?
- Are the **searchable fields** used for keywords (name field / headline)?
- Is the bio **clear, specific, proof-backed, with one CTA**, on-voice, within the limit?
- Is the **link matched to the goal** (not a junk drawer)?
- Are **pinned/highlights/banner** specced (not left default/stock)?
- Is it **niched** (not "for everyone")?
- Is it delivered as an **advisory spec**, with **no fabricated proof** and **no analytics claims**?

## Edge cases & pushback

- **Vague/clever bio** ("dream big ✨") → rewrite for who/what/why clarity.
- **Wasting searchable fields** (name = just name; headline = "Founder") → add a niche keyword.
- **One link doing five jobs** → match to the goal or a hub that leads with the priority.
- **"Appeal to everyone"** → niche down; for-everyone converts no one.
- **Stock-photo banner** → a banner brief carrying value prop/proof/CTA.
- **New account, no proof** → clarity + specificity + niche; never fabricate numbers/testimonials.
- **"Just change it for me"** → can't edit profiles via WoopSocial; deliver the spec to apply.
- **"Which bio performs best?"** → native profile insights / the 3-second test; no WoopSocial
  analytics.
