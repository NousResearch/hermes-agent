# The SHOT framework — Runway as the director's tool

Runway isn't the "best clip in one click" tool — it's the **director's tool.** You reach for it when
you need **control**: a specific camera move, a consistent character across shots, or to edit/restyle
existing footage. If you want a clean cinematic clip with native audio in one pass, that's **veo-3**.
SHOT keeps a human directing — with consent and disclosure as the spine.

## S — Set the shot (directorial brief)
- Write like a director: **subject, camera move** (push-in, orbit, tracking), **motion**, **lighting/
  mood**, **lens feel**, **aspect ratio**. Vague prompts waste credits.
- Match the look to brand-profile. One shot = one idea; storyboard multi-shot pieces.

## H — Hold consistency with References
- Use **Gen-4 References** to lock a character/object/style and reuse it across every shot — Runway's
  signature advantage. Establish the reference before generating the sequence.
- Keep wardrobe, faces, and props consistent shot-to-shot; this is what makes AI video look produced
  rather than random.

## O — Operate the controls
- **Camera Control** for the move (static toggle to calm motion); **Motion Brush / Multi-Motion
  Brush** to direct motion in specific areas.
- **Aleph (video-to-video)** to *edit existing footage* by prompt — relight, add/remove objects,
  restyle — without regenerating. Edit-grade, fast.
- **Act-Two** for performance capture from any camera — **consented performers only** (see spine).
- Pick the model: **Gen-4.5** (hero), **Gen-4 Turbo** (cheap iteration), **Gen-4 Image** (stills).

## T — Trim & assemble
- Clips are **2–10s with no native audio** — so plan to **stitch shots in the edit**, add **voiceover
  via ai-voiceover** and music/sound design in post, then **captions via captions-and-clipping.**
- Test cheap and short, lock the storyboard, then commit credits to the high-quality hero runs.

## The spine: consent + disclosure (never optional)
- **Act-Two only on consented performers / your own performance / licensed-owned characters.** Never
  transpose a real non-consenting person's face or performance (deepfake).
- **Disclose** AI-generated/edited video (EU AI Act; TikTok auto; YouTube Altered-Content).

## The shot brief a request should fill
```
SHOT: subject + camera move + motion + lighting/mood + aspect ratio
MODEL: Gen-4.5 (hero) | Gen-4 Turbo (test) | Aleph (edit existing) | Act-Two (consented perf)
REFERENCES: character/object/style locked across shots?
ASSEMBLE: 2-10s shots → edit; audio via ai-voiceover; captions via captions-and-clipping
CONSENT + DISCLOSURE: confirmed
```
