# Building the moment calendar + two worked examples

## The two gates (run every candidate moment through both)
```
FIT GATE:   Does it match our brand / audience / goals? Would our audience expect/welcome us here?
            Can we add something beyond "happy [day]"? -> if no, SIT OUT.
AUTHENTICITY GATE (identity/cause moments): Do we have genuine YEAR-ROUND commitment + a real stake?
            "Why us, why this moment?" -> if no real answer, STAY QUIET (silence > performative noise).
```

## Tier table (match effort + tone to the moment)
| Tier | Examples | Approach |
|---|---|---|
| 1 — commercial / fun | BFCM, Halloween, Valentine's, Mother's Day, fitting food/internet days | go; promo OK; multi-week series for the big ones |
| 2 — authentic-alignment | Pride, Earth Day, awareness months | only with real year-round commitment; substance, not a logo swap |
| 3 — cultural / solemn | MLK Day, Juneteenth, Ramadan/Holi, remembrance days | non-promotional respect; never a sales hook; or sit out |

## Lead-time table (verify-quarterly)
```
MAJOR (BFCM, Christmas, Valentine's, big launches): 8-12 weeks  | brief creative early; multi-week series; paid for BFCM
MINOR (awareness/social/fun days):                  2-4 weeks   | lighter touch, single or few posts
Seasonal milestones: brief Back-to-School in May; lock Halloween briefs in Aug / creative by early Oct
Run on quarterly (13-week) cycles; review planned-vs-actual each quarter -> next brief
```

## Per-moment plan (one row per chosen moment)
```
MOMENT | DATE (2026, market) | CATEGORY | TIER | FIT? why-us | ANGLE | FORMAT(S) | CHANNEL(S) | LEAD TIME | GOAL | measure
```

## WoopSocial flow
```
agent maps moments + gates fit/authenticity + tiers + plans angle/lead-time
-> big commercial moment? -> campaign-and-launch-planning (+ paid)   |   cultural-moment craft -> meme-and-culture
-> visual -> image tools / design-and-templates
-> feed the content-calendar -> WoopSocial SCHEDULES the planned content AHEAD. Leave ~50% open for trend-jacking.
WoopSocial does NOT pick moments, judge authenticity, build the calendar, or run paid.
```

## Worked example 1 - e-commerce brand, Q4 (blunt indie-founder voice)
```
I'm not posting every food day. My calendar: Halloween (Tier 1, light), BFCM (Tier 1, the big one), Christmas (Tier 1, series).
BFCM is a 3-week campaign -> campaign-and-launch-planning, briefed in September, with paid. I draft the series now, schedule it
ahead in WoopSocial, and keep ~half the calendar open for whatever trends in November. Pride? We don't do year-round work there, so we don't post -- I'm not rainbow-washing for reach.
```

## Worked example 2 - wellness studio (warm studio voice)
```
We pick a small handful that fit -- World Mental Health Day (we genuinely do this work year-round, so we have something real to
say), the seasonal shift into cozy autumn, and our own studio anniversary. Each gets a thoughtful angle, not a "happy day"
graphic. We plan them 4-8 weeks out, build the visuals in our template, and schedule them ahead -- leaving room to respond to the moment. The days we have no real reason to join, we let pass.
```

Both: the few that fit (not every holiday); the authenticity gate honored; tiered + planned ahead; big moments as campaigns;
scheduled in advance with room left for reactive; performative participation refused; measured against a real goal.
