# The DATES framework — plan the few moments that fit, far in advance

The planned counterpart to `trend-jacking`. The agent **maps the moments + gates fit/authenticity + tiers +
plans the angle/lead-time + feeds the content-calendar**; big commercial moments → `campaign-and-launch-
planning`; **WoopSocial schedules the planned content ahead.**

## D — Decide the moments that matter
- Build **YOUR brand's** moment calendar from the 500+ out there: seasons, retail anchors, **relevant**
  awareness months, industry events, company milestones. **Not every internet holiday** — "not every holiday
  deserves a post."

## A — Audit for fit + standing
- **Fit gate:** does it match **brand / audience / goals**? **Authenticity gate:** for identity/cause moments
  (Pride, MLK, Juneteenth, Earth Day) — **genuine year-round commitment?** If you can't answer **"why us, why
  this moment?"** with something real, **stay quiet.** No rainbow-washing.

## T — Tier by weight + sensitivity
- **Tier 1** commercial/fun (go — BFCM/Halloween/Valentine's, strongest ROI) · **Tier 2** authentic-alignment
  required (Pride/Earth Day) · **Tier 3** cultural/solemn (non-promotional respect — religious/remembrance
  days). **Match effort to payoff:** big commercial = a **campaign** → `campaign-and-launch-planning`.

## E — Engineer it early
- The predictable-moment advantage: **8–12 weeks** ahead for major, **2–4** for minor. Run big moments as a
  **multi-week series**, not one post. Brief creative/offers in advance. (Opposite of `trend-jacking`'s
  reactivity.)

## S — Slot it in + measure
- Feed the **`content-calendar`**; **schedule ahead via WoopSocial**; leave **~50% open** for reactive
  (`trend-jacking`); **measure vs the moment's goal** (engagement vs sales); **quarterly** review
  planned-vs-actual. Never fabricate.

## The moment plan a request should fill
```
MOMENT + DATE (confirm 2026 date/market) | CATEGORY (commercial/cultural/awareness/fun) | GEO
FIT: brand/audience/goal match? "why us, why this moment?"  -> if no real answer, SIT OUT
TIER: 1 commercial/fun | 2 authentic-alignment-required | 3 cultural/solemn (non-promotional)  | brand-safety: safe/sensitive/caution
ANGLE + FORMAT + CHANNEL (one date -> several formats); beyond "happy [day]"
LEAD TIME: major 8-12 wks / minor 2-4 wks; multi-week series for big moments (-> campaign-and-launch-planning + paid)
SLOT (WoopSocial): schedule ahead via content-calendar; GOAL + how measured. Leave ~50% open for trend-jacking.
```
