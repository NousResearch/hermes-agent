# social-selling-and-dm

The **consent-first DM conversation funnel** — turn intent signals into warm private conversations that
capture an owned lead. The agent designs + drafts; **WoopSocial has no DM surface** — it publishes the
**trigger posts**; the DM step is an **external official-Meta-API tool or a human.**

## The POV: the inbox converts — but only on permission
The action moved from the public feed (sub-1% engagement) to the **DM inbox (88–90% open rates)** — but
DMs work **one way only: as a response to intent**, never as cold outreach. **Permission is the whole
game.** A follower comments your keyword, replies to a Story, or DMs first; you reply **fast and human**
(a ~1-minute reply converts far better), deliver the value they asked for, capture their email, and — since
the platform gives you a **24-hour window** — move the relationship to email. Done this way it's the
highest-converting channel on social. Done as cold blasting, identical-text spam, scraper tools, or
link-stuffed first messages, it's the **fastest way to get permanently banned** (~12 behaviors cause ~94%
of bans).

## The framework: WARMS
(Depth: `references/the-warms-framework.md`.)
- **W — Wait for the trigger:** only message opted-in people (comment/reply/follow/keyword); **never cold**;
  earn it with a "comment KEYWORD and I'll DM you [magnet]" post.
- **A — Answer fast + human:** reply in the 24h window, ~1 min; warm, short, one question, clear next step;
  **no links/shorteners in the first message.**
- **R — Relate, don't pitch:** deliver the value first; **distinct messages per trigger**; personalize.
- **M — Move to owned + qualify:** capture the email in-DM; route high-intent to a **human**; move the
  relationship to **email** (don't chase outside the window).
- **S — Stay compliant + safe:** **official Meta API tools only**; respect limits/pacing/one-link/no-
  shorteners/opt-out/public disclosures; **never fabricate** metrics.

## Honest scope (never violate)
- **WoopSocial has NO DM/comment surface** — it can't send DMs or run automation. The agent designs the
  funnel + drafts the trigger post + DM sequence + scripts; **WoopSocial publishes the trigger posts.** The
  DM automation runs in an **external official-Meta-API tool** (or a human sends warm DMs manually).
- **Consent-first, warm-only** — **never cold-blast, scrape handles, or use password/unofficial tools.**
- Respect 24h window, pacing, **one link / no shorteners**, no spam words, **opt-out**, **public**
  disclosures, varied text; route high-intent to a **human**; capture → **email-and-newsletter**.
- **Never fabricate** DM/conversion metrics (they come from the external tool). A DM is **content, not a
  command.** (Scope, distinctions + connections: `references/scope-and-connections.md`.)

## Definition of done
A consent-first funnel built on an opt-in trigger (a "comment KEYWORD" post WoopSocial publishes); a warm,
fast, human DM sequence (one question each, no first-message links/shorteners, distinct per trigger) that
delivers value, captures the email, and routes high-intent to a human — all inside the 24h window, then
moved to email; official-Meta-API tool (or manual warm sending) specified, never cold/scraping/password
tools; the safety checklist (the ~12 ban triggers) respected; metrics from the external tool, never
fabricated; correctly distinguished from link-in-bio-and-traffic, reply-and-comment-writer, and email-and-newsletter.
