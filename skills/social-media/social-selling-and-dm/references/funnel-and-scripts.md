# Funnel, scripts + two worked examples

## The comment → DM → email funnel (architecture)
```
1. TRIGGER POST (WoopSocial publishes): Reel/carousel/caption -> "Comment KEYWORD and I'll DM you [magnet]."
2. TRIGGER FIRES: follower comments the keyword (= explicit opt-in).
3. WARM DM (official-API tool or human): deliver the magnet + one warm question. (within 24h)
4. CAPTURE: ask for the email in-chat to send the full thing / next resource.
5. QUALIFY + ROUTE: high-intent -> human; everyone -> email nurture (-> email-and-newsletter).
```
Compress any promo into the 24h window; the relationship continues by **email**, not endless DMs.

## DM sequence template (warm, one question each)
```
DM1 (deliver): "Hey [name]! Here's the [magnet] 👉 [link]. Quick Q: what are you stuck on with [topic]?"
DM2 (relate): respond to their answer with one genuinely useful tip. (no pitch yet)
DM3 (capture/next): "Want the full [resource]? Drop your email and I'll send it + a weekly note."
DM4 (soft offer, only if warm + in-window): one clear next step. Then move to email.
```
First message: **no link-shortener**, ideally the link only after they engage; **one** link max.

## Manual warm / partnership outreach script (sent by a human)
```
"Hi [name] — your [specific thing they made] on [topic] was the clearest take I've seen. 
I'm [you], I [one-line value]. Would it make sense to [soft, specific ask]?"
```
Personalize the first line (+40% response); no "Hey!"; no link in msg 1; respect "email only" bios;
disclose partnerships **publicly** (comment/caption), not just in DM.

## Safety checklist (avoid the ~12 ban triggers)
[ ] only opted-in/warm recipients [ ] official Meta API tool (no scraping/password) [ ] vary message
text (no identical >25/hr) [ ] one link max, no shorteners [ ] within the 24h window [ ] no spam words
[ ] visible opt-out, keep opt-out <4% [ ] route high-intent to a human.

## Worked example 1 — comment→DM lead magnet (blunt indie-founder voice)
```
TRIGGER POST: "Most freelancers overpay tax. Comment TAX and I'll DM you my 1-page checklist." (WoopSocial publishes)
DM1: "Here's the checklist 👉 [link]. What's the bit of tax that trips you up most?"
CAPTURE: "Want the full system + a weekly note? Drop your email." -> email-and-newsletter
SAFETY: official-API tool, varied text, one link. METRICS from the tool.
```

## Worked example 2 — story-reply re-engagement (warm studio voice)
```
TRIGGER: someone replies to a Story poll ("which tax task do you dread?") = opt-in.
DM1: "Thanks for voting 💛 Sounds like [their pick] is the headache. Want the one step that fixes it?"
DM2 (on reply): deliver the step. CAPTURE: offer the full guide for their email. ROUTE: if they ask about services -> human.
WINDOW: all within 24h; after that, continue by email only.
```

Both: opt-in only; warm + fast + one question; value before offer; email capture in-window; official-API
tool or manual; metrics from the tool (never fabricated). WoopSocial only publishes the trigger posts.
