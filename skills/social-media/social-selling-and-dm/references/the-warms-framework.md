# The WARMS framework — warm, consent-first DM selling

The action moved to the inbox (88–90% open rates), but DMs only work as a **response to intent**, never
as cold outreach. WARMS is the consent-first funnel: earn the trigger, reply warm and fast, deliver value,
move to an owned channel, stay compliant. The agent designs + drafts; **WoopSocial has no DM surface** —
it publishes the trigger posts; the DM step is an external official-API tool or a human.

## W — Wait for the trigger (consent-first)
- Only message people who **opted in**: commented your keyword, replied to a Story, followed, or DM'd you.
  **Never cold.** Earn the opt-in with a **"comment KEYWORD and I'll DM you [magnet]"** trigger post.

## A — Answer fast + human
- Reply **inside the 24h window**, ideally within ~1 minute (massively higher conversion). **Warm, short,
  specific, one question, a clear next step.** **No links or URL shorteners in the first message.** Never
  ticket-speak.

## R — Relate, don't pitch
- **Deliver the value they asked for first.** Map **distinct messages to distinct triggers** (a "pricing"
  comment ≠ a Story reply) — one generic flow feels like spam. Personalize; build the relationship before
  any offer.

## M — Move to owned + qualify
- **Capture the email natively in the DM**; qualify intent; **route high-intent to a human.** Compress any
  promo into the **24h window**, then move the relationship to **email** (→ `email-and-newsletter`) — don't
  chase outside the window.

## S — Stay compliant + safe
- **Official Meta API tools only** (never scraping/password/unofficial — ~27× the ban risk). Respect
  **limits/pacing**, **one link max**, **no shorteners**, **no spam words**, **consent + opt-out**,
  **public disclosures**. **Never fabricate** DM/conversion metrics.

## The DM-funnel brief a request should fill
```
TRIGGER: the opt-in CTA ("comment KEYWORD") + the post that carries it (WoopSocial publishes this)
DM SEQUENCE: warm reply -> deliver value -> capture email -> one next step (within 24h)
TRIGGER-MATCHED: distinct messages per trigger; personalized; one question each
HANDOFF: high-intent -> human; relationship -> email (off-platform after 24h)
SAFETY: official Meta API tool (or manual warm sending); limits, one link, no shorteners, opt-out, disclosures
MEASURE: DM conversations / email captures from the external tool (never fabricated)
```
