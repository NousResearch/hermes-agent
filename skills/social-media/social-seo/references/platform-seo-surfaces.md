# Platform SEO Surfaces

The crown jewel: exactly what each platform indexes for search, and how to optimize each. The point
is that **the SEO surface differs per platform** — give platform-specific guidance, never one generic
answer.

> Re-verify quarterly; indexed fields and search features evolve.

## TikTok — audio + on-screen + caption

A primary search engine for Gen Z. TikTok **transcribes spoken audio** and **reads on-screen text**, so
the technique is the **triple mention** (see `keyword-research-and-technique.md`):

- **Spoken audio** — say the primary keyword **clearly, in the first few seconds.**
- **On-screen text** — show the keyword as a headline overlay (keywords, not decorative text).
- **Caption** — captions now allow long text (~thousands of chars); write it like a **searchable
  description** (TikTok weighs the description over the comments), primary phrase early.
- **Hashtags** — a category signal (3–5 niche), not the lever → `hashtag-strategy`.
- Research: TikTok **autocomplete**, the **"others searched for"** carousel, Creative Center.

## Instagram — caption + the name field + alt text

Keyword search now outranks hashtags for discovery. Indexed surfaces:

- **Name / display-name field** — *separately searchable from the @handle and heavily weighted.* Put
  your core keyword/category here (e.g., "Maya · Vegan Meal Prep"), not just your name.
- **Caption** — primary keyword in natural language, early (wins the search match + the see-more).
- **On-screen text & audio** — increasingly read (caption your Reels).
- **Alt text** — add descriptive, keyword-aware alt text (SEO + accessibility).
- **Bio** — searchable; lead with the value prop + keyword.
- Public **professional accounts are now Google-indexable** — captions/alt text travel.
- Hashtags capped at **5** → `hashtag-strategy`.

## YouTube — the deepest SEO surface

The 2nd-largest search engine, integrated with Google. Optimize, in order of weight:

- **Title** — keyword-led and *descriptive* ("How to Build a Content Calendar in Notion" beats a vague
  curiosity hook in search). Front-load the phrase.
- **Description** — treat as a **200–300 word short article**: natural keyword-rich context, related
  questions, links. Feeds in-platform *and* Google.
- **Transcript / closed captions** — indexed; upload accurate captions (don't rely on auto only).
- **Chapters / timestamps** — descriptive labels ("02:10 What Social SEO Is") help YouTube index
  segments and can appear as **Google rich results.**
- **Tags + descriptive file name** — supporting signals. **Thumbnail** drives CTR (a ranking input).
- Applies to **Shorts and long-form**. Research: YouTube autocomplete (seed + wildcard), TubeBuddy/VidIQ.

## Pinterest — a pure keyword search engine

The most search-driven platform; **hashtags are largely deprecated → keywords are the whole game.**

- **Pin title + description** — keyword-rich, descriptive, intent-matching.
- **Board names + descriptions** — keyword-organized (boards are topic clusters).
- **Alt text + on-image text** — describe the pin in searchable terms.
- Pinterest content is evergreen and surfaces for months — strong for inspiration/planning intent.

## LinkedIn — profile + topic keywords

A top B2B search/discovery surface:

- **Profile** — the **headline and About are heavily searchable**; lead with niche + value keywords.
- **Post keywords** — feed the **topic-matching** ("topic DNA") that distributes you to the right
  professionals (search + recommendation overlap). Stay in your lane → `linkedin-growth`.
- 3–5 niche hashtags as supporting signals.

## X / Facebook (briefly)

- **X** — real-time keyword search; **bio + post text searchable**, indexed by Google; 1–2 hashtags.
- **Facebook** — local-business / group / community search; complete the Page fields with keywords.

## Cross-cutting (every platform)

- **Subtitles / captions** on every video — indexed *and* most people watch sound-off.
- **Alt text** wherever supported — searchable + accessible.
- **Descriptive file names** before upload.
- **Profile fields** — a **consistent branded handle** (append a keyword/location if taken:
  `@oakandlinen.home`); searchable name/display field; keyword-aware bio.
- **Native uploads** (not links to other platforms) get preferential treatment.
