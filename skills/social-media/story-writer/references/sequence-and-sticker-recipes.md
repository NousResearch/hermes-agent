# Stickers, sequences + two worked examples

## Pick the sticker by goal
| Goal | Sticker | Note |
|---|---|---|
| Quick feedback / opinion | Poll or Slider | low-friction; binary or 0–100 |
| Educate / segment audience | Quiz | one right answer; reveal teaches |
| Start conversations (→ DMs) | Question box | spin answers into a follow-up AMA |
| Real deadline / launch | Countdown | tap-to-subscribe = warm retarget list |
| Drive traffic | Link sticker | add a "Tap here" overlay; end of sequence |
| Social proof / participation | UGC reshare / "add yours" | reshare tags with a thank-you |
| Exclusivity / warm inner circle | Close Friends drop (green ring) | VIP/early access; invite in via a public Story |

## The sequence template (one goal)
```
F1  Hook — problem or outcome (sound-off; the reason to stay)
F2  Proof — one stat / step / before-after / BTS moment
F3  Sticker — poll/quiz/question (turn watchers into tappers)
F4  Payoff — the answer / the takeaway
F5  Action — ONE next step (link sticker + "Tap here", or reply prompt)
```
Mini-series: split a tutorial across 3 days, each installment a distinct takeaway + a hook for the next.

## Highlights
Group proven sequences into **Highlights** with clear covers + context (e.g. "Start here", "FAQs",
"Wins"). The evergreen tail on a 24-hour surface; refresh as content improves.

## Worked example 1 — value mini-tutorial → link (blunt indie-founder voice, 5 frames)
```
GOAL: clicks to the new guide
F1 (hook): "Most freelancers overpay tax. One missed step." [sound-off text card]
F2 (proof): "I moved 30% of every invoice to a second account. Saved a brutal April." [BTS clip]
F3 (sticker): Quiz — "How much should you set aside? 15% / 30% / 45%" (answer: 30%)
F4 (payoff): "30%. Boring. Works."
F5 (action): Link sticker -> guide + "Tap here 👆" overlay
AFTER: Highlight under "Money". DM anyone who replies with a question.
```

## Worked example 2 — BTS + question → DMs (warm studio voice, 4 frames)
```
GOAL: replies (start conversations)
F1 (hook): "Tax season making your stomach drop? You're not alone." [soft photo]
F2 (proof): "Here's the one rule we give every client." [desk clip]
F3 (sticker): Question box — "What's the part of tax that stresses you most?"
F4 (action): "Reply and I'll send you the exact step for your situation." [DM prompt]
AFTER: answer each reply personally in DMs; spin common answers into tomorrow's AMA sequence.
```

Both: read brand-profile + voice-builder first; one goal; sound-off legible; one sticker; one clear
action; Highlight + DM plan. Frames designed in `image-prompt`/`ideogram`/`nano-banana`; published via
`scheduling-and-queue → WoopSocial` (base frames) with stickers added natively in-app.
