# The FRAME framework — Stories that deepen the relationship

Stories aren't disposable filler and they aren't a reach play — they're the **intimate, interactive
surface** where your warmest followers give you fast, low-polish attention. FRAME builds a sequence
that earns the tap-through, converts watchers into tappers, and drives one clear action.

## F — First frame earns the tap-through
- Open with a **sound-off hook** stating the problem or outcome (most exits happen on frame 1).
- 9:16, key content in the **safe zone**, **text sparingly**, on-brand. One reason to stay.

## R — Rhythm: one beat per frame
- Build a **3–5 frame arc** (or a multi-day mini-series); **one beat per frame**, each a distinct
  takeaway, building progressively. Segments can run to 60s, but a short beat (~15s) holds attention.
- Vary the frames (photo, clip, text card) so it doesn't feel like one flat slideshow.

## A — Activate with a sticker
- Add an **interactive sticker** — the single most effective Stories tool. Pick by goal: **poll/slider**
  (feedback), **quiz** (educate/segment), **question box** (AMA → DMs), **countdown** (real deadline).
- Each tap is a **relationship signal** and free audience research.

## M — Move to one action
- **One goal per sequence.** If the goal is replies → a question. If a link click → problem → solution
  → **link sticker + "Tap here" overlay** at the end. If engagement → poll/quiz before the payoff.
- Don't ask viewers to do three things; the clearer the single action, the stronger the result.

## E — Evergreen the winners + engage the replies
- **Highlight** proven sequences (with context) so an ephemeral surface gets an evergreen tail.
- **DM every reply** personally — that conversation is the real relationship (and a strong signal).
- Read **completion / exits / sticker taps** natively to learn which arcs and stickers land; repeat
  the winners.

## The Story brief a request should fill
```
GOAL (one): replies | link click | profile visit | poll feedback
ARC: 3–5 frames, one beat each; F1 = sound-off hook (problem/outcome)
FRAMES: copy per frame (brand voice), sound-off legible, safe zone
STICKER: which one + exact copy (poll/quiz/question/countdown/link)
ACTION: the single next step + "Tap here" overlay if a link
AFTER: Highlight if it's evergreen; DM-reply plan
```
