# Scope, distinctions + connections

storytelling-and-narrative is the **narrative-craft layer** — find the real story, structure the arc, anchor
it in specifics, land the meaning, and shape it to the format. It **feeds the format writers**; **WoopSocial
publishes**; serialized arcs map into the **content-calendar.**

## Honest scope (never violate)
- **The agent** finds the **real story**, structures the **arc** (setup → turning point → payoff; audience as
  hero, brand as guide), **anchors specifics**, **tunes the emotion/meaning**, and **shapes it to the format.**
- It **routes** format mechanics to the **format writers** (`reels-script`, `carousel-writer`,
  `linkedin-post-writer`, `thread-writer`, `caption-writer`), the opening to `hook-writer`, and the visual to
  the **image tools**/`design-and-templates`. **WoopSocial publishes**; **serialized arcs map into the
  `content-calendar`.**
- **Never fabricate a story or testimonial** (truth + consent — real ones → `social-proof-and-testimonials`/
  `ugc-and-influencer`). **Authenticity over polish.** **Not every post needs a story** (forcing it =
  melodrama). **Story metrics = saves/shares/comments/profile visits, not likes.** **Never guarantee
  virality.** **Verify-quarterly** (platform framing + cited stats).

## Distinct from its siblings
- **storytelling-and-narrative (this)** — the **narrative CRAFT/structure** across **all** formats.
- **story-writer** — the **IG/FB Stories FORMAT** (ephemeral frame sequences). *Different sense of "story."*
- **hook-writer** — the **opening line / scroll-stopper** (the **entry** to the arc — **they pair**).
- **caption-writer / carousel-writer / thread-writer / linkedin-post-writer / reels-script / tiktok-script** —
  the **format mechanics** (this provides the **structure** that goes into them — it **feeds** them).
- **brand-profile / voice-builder** — the **voice/identity** (this reads them; keeps narrative voice
  consistent).
- **content-pillars / social-strategy** — the **topic strategy** (this is **how** to tell a topic as a story).
- **social-proof-and-testimonials** — the **testimonial/case-study content** (this is the **narrative craft**
  applied to them).
- **campaign-and-launch-planning** — the **launch arc across posts** (serialized storytelling **feeds** it).
- **viral-reverse-engineering** — **deconstructs** virality (this **builds** narrative).

## Where this connects
- **Reads first:** `brand-profile` + `voice-builder` (voice/identity + real proof points).
- **Feeds:** the **format writers** (the arc → the post/Reel/carousel/thread), `hook-writer` (the open),
  `content-calendar` (serialized arcs), `image-prompt`/`design-and-templates` (the visual of the beat).
- **Pulls true material from:** `social-proof-and-testimonials`, `ugc-and-influencer`,
  `behind-the-scenes-and-founder`, `audience-research`.
- **Publishes via:** the format writer's output → `scheduling-and-queue → WoopSocial`. **Measure with:** native
  + `analytics-and-reporting` on **saves/shares/comments/profile visits** (never fabricated).
