# The BEATS framework — narrative craft for any format

A craft layer that **feeds the format writers.** The agent **finds the story + structures the arc + anchors
specifics + tunes emotion/meaning + shapes it to the format**; the **format writers** build the mechanics;
**WoopSocial publishes**; serialized arcs map into the **content-calendar.**

## B — Begin with the real story
- Find the **human truth/tension** worth telling: a transformation, a conflict, real stakes. **Not every post
  is a story** — reserve narrative for content that has one. **Never fabricate** it.

## E — Establish the arc
- **Setup/problem → turning point → payoff/transformation.** Make the **audience/customer the hero**, the
  **brand the guide** (StoryBrand). Or BAB / 3-Act / Hero's Journey. Keep it tight — a micro-arc, not a
  speech.

## A — Anchor in specifics
- **Concrete sensory detail = believability + resonance.** Replace "I was stressed" with the specific scene.
  **Show, don't tell.** One real detail beats ten generalities.

## T — Tune the emotion + meaning
- Lead with **one** emotional goal (comfort/pride/relief/belonging). Land the **universal point** they carry
  away + **see themselves in.** Authentic, not a movie trailer.

## S — Shape it to the format + serialize
- Compress the arc to the format (**Reel / carousel / post / thread**) → the **format writers**; the **hook is
  the entry** → `hook-writer`. **Serialize** big arcs into the `content-calendar`. **Measure saves/shares**,
  not likes. **WoopSocial publishes.**

## The story brief a request should fill
```
STORY: the real tension/transformation (is there genuinely one? if not -> not a story, route to the writers)
ARC: setup/problem -> turning point -> payoff; HERO = the audience/customer, GUIDE = the brand (or BAB / 3-act)
SPECIFICS: 1-3 concrete sensory details (show don't tell); cut the abstractions
EMOTION + MEANING: the one feeling; the point they carry away + see themselves in (authentic, not a trailer)
FORMAT: Reel / carousel / post / thread -> the format writer; the hook -> hook-writer; visual -> image tools/design-and-templates
SERIALIZE + MEASURE: single or a mapped series (content-calendar); metric = saves/shares/comments. Never fabricate a story.
```

## Quick structures
```
BAB:        Before (the pain) -> After (the better world) -> Bridge (how you get there)
3-Act:      Setup -> Confrontation/turning point -> Resolution
StoryBrand: Hero (customer) wants X, faces problem -> meets Guide (brand) with a plan -> success / avoided failure
Template:   "When [customer] faces [problem], [brand] helps them [outcome] because we believe [value]."
```
