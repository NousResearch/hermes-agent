# Scope, distinctions & connections

## Honest scope (never violate)
- **The agent** runs the fit test, writes the spoken-word script (locked before render), plans scenes/brand
  kit/localization + the QA gates, and — **where the API is connected** (Creator+ tier) — can drive generation
  programmatically. Where it isn't, exact steps for the human in-app. No pretended automation; **no unreviewed
  auto-publish.**
- **The human approves every video** — the agent can't watch a render and never fabricates "that looks
  natural"; native-speaker QA per localized language.
- **WoopSocial publishes** the finished exports (measurement: the platforms' native analytics); it does **not** generate avatars or
  edit video. LMS/SCORM distribution is separate (Enterprise; the human's LMS).
- **The consent spine:** stock avatars = consented paid actors; personal avatars = the owner's live consent
  recording (single-take source, never spliced); **never** an avatar of anyone without verified consent — no
  celebrities/politicians/competitors, no fake endorsements (impersonation prohibited by platform and stack).
- **Disclosure, always:** a synthetic presenter is labeled (YouTube altered-content, TikTok AI tag, EU AI Act
  synthetic-media obligations from Aug 2026, C2PA where available). **YMYL:** avatar delivery doesn't lower the
  claim bar — health/finance content keeps sourcing + not-professional-advice framing, and regulated topics may
  hit 12–24h moderation review (plan for it). **Never fabricate** tiers, gates, render times, or capabilities —
  verify in-app (verify-quarterly).

## Distinct from its siblings (route correctly)
- **heygen** = the creator/social-native avatar lane (more casual TikTok feel; this = the enterprise/L&D/
  localization lane — test both on your format; state trade-offs, don't fabricate a winner).
- **talking-head-and-piece-to-camera** = the REAL human on camera (trust-led content routes there; the hybrid
  split is the pro move).
- **ai-video / luma / veo-3 / kling** = cinematic/generative footage (no presenter); Synthesia's AI Playground
  embeds Veo 3.1 (and, until OpenAI's Sora API sunsets Sept 24 2026, Sora 2) for B-roll inside its editor.
- **ai-voiceover / elevenlabs** = voice-only narration (no face); **descript** = editing recorded talk content
  (its avatars/Eye Contact patch a recording; this generates the presenter).
- **short-form-video-script / educational-content-and-how-to** = the scripts this renders.
- **capcut** = post-render captions/pace where needed.

## Where this connects
- **Reads first:** the content skill (educational-content-and-how-to / short-form-video-script) +
  brand-profile + voice-builder (the script's voice) + design-and-templates (brand kit).
- **Feeds:** capcut (captions/pace), youtube-publishing-and-metadata / tiktok-video-publishing /
  instagram-reels-publishing (the finished file), email-and-newsletter (embedded explainers),
  lead-magnets-and-funnels (course/onboarding video).
- **Publishes via:** export → scheduling-and-queue → **WoopSocial** (social); the LMS (training — human).
- **Tool file:** `tools/integrations/synthesia.md` (tiers, gates, the consent architecture, API).
- **Measure with:** native + analytics-and-reporting on completion/watch-through — never fabricated.
