# The HUMAN framework — avatar video with human standards

The presenter is synthetic; the standards stay human. Each letter is a gate; most avatar failures happen at H
(an avatar where a real face belonged) or M (essay prose read by a robot).

## H — Have a reason for an avatar
The fit test before anything renders. **Avatar-right:** training/onboarding, explainers, FAQ/support,
localization at scale, faceless educational series, high-volume consistency (the presenter never has a bad
day). **Avatar-wrong:** trust-led founder content, testimonials, emotionally-nuanced persuasion — avatars read
polished-but-clinical, and the parasocial trust those formats build comes from a real human → route to
`talking-head-and-piece-to-camera`. The hybrid is the pro move: the founder films the trust layer; the avatar
scales the informational layer.

## U — Use consented likeness only
The consent architecture is the point, not friction: stock avatars are real paid actors who agreed; a personal
avatar requires **your** live consent recording (same person as the source media; single-take source, never
spliced). **Never** an avatar of a competitor, celebrity, politician, or anyone who hasn't verifiably
consented — impersonation and fake endorsements are prohibited by the platform and by this stack. Governance:
share the avatar's outfits/spaces, keep edit rights and the voice with the owner.

## M — Make the script spoken-word
**The script is most of avatar quality.** Write for the ear: short sentences, contractions, one idea per
sentence, conversational rhythm — never essay prose pasted into the script box. Use SSML for pauses,
pronunciation, and emphasis; pick the voice + emotional register deliberately; frame the avatar closer
(lip-sync reads better per the docs). **Lock the copy before generating:** a comma-level edit forces a full
~8–12-min re-render that eats the minute cap — read it aloud, get sign-off, then render once.

## A — Assemble scenes + localize
Brand kit + template once → scenes with B-roll (the AI Playground — use the Veo 3.1 lane; the Sora API
sunsets Sept 24 2026), screen recordings,
interactivity (quizzes/hotspots) where the format earns it. **Localization is the superpower:** lock the
master → 1-click translation / AI dubbing (voice-clone consistency across languages) → **a native-speaker QA
pass per language** (machine translation is a draft, not a deliverable) → localized on-screen text + subtitles.
One master, tracked variants — never twenty divergent scripts.

## N — Note the disclosure + publish
A synthetic presenter is **disclosed, always**: YouTube's altered-content label, TikTok's AI tag, the EU AI
Act's synthetic-media obligations (from Aug 2026), C2PA provenance where available. Then the human approves the
video, export → `capcut` if captions/pace need work → `scheduling-and-queue` → **WoopSocial publishes** the
finished file (it does not generate avatars). Build deadline buffer — render/audio-sync failures are reported
near deadlines; regulated topics may sit in 12–24h moderation review.
