# Growth plays, the funnel + two worked examples

## The reply flywheel (the #1 lever — human / community-management)
```
1. Pick 5-15 accounts/conversations in your niche (similar size + a few bigger).
2. Reply with genuine value FAST (be early; the first replies on a rising post get seen most).
3. Reply to every comment on YOUR posts in the first hour (your replies count toward the post).
4. Leap into trending niche conversations same-day. Positive/constructive only.
-> Run by a human (or community-management). WoopSocial publishes your original posts; it doesn't reply.
```

## Niche/angle worksheet
```
One sharp value promise: "we make X simpler" / "we clarify Y" / "we find Z first".
1-2 topic areas only -> the interest-graph classifies you + the audience knows what they're following.
```

## Cadence + timing
```
3-5 posts/week (NOT >3/day). Post when YOUR audience is awake (strong windows e.g. Wed 7am, Thu/Fri am - verify).
Stay for the first hour to reply. 60-90 day horizon before momentum compounds.
```

## Format mix + tags
```
Photos +60% > text-only; video w/ captions best; links +17% (under media). ONE topic tag (not hashtags).
Keyword in natural language in the first two lines. Original + positive. (The actual post -> threads-post.)
```

## Threads -> Instagram funnel
```
Threads = discovery (topical reach) -> Instagram = conversion (Reels/carousels, commerce).
Route the most interested users to an IG asset; repurpose a top Thread within 24-72h while momentum lasts.
Benchmarks (verify): Threads->IG profile-visit conv ~6-12%; reply rate >~2%/post.
```

## Metrics dashboard (native analytics)
```
Reach/post | REPLIES/post (track replies / reach -- the heaviest signal) | follower-growth rate | profile visits
High reach + flat follower growth -> hook/value problem. Replies < ~2% -> reassess messaging.
```

## Worked example 1 - solo founder, B2B niche (blunt indie-founder voice)
```
NICHE: "make bookkeeping less painful". 4 posts/week, Wed 7am. REPLY ENGINE (me, daily): reply into 10 finance
conversations + every comment on my posts in the first hour. FORMAT: one chart photo + one topic tag. WoopSocial
publishes the originals on schedule; I run the replies. Threads -> route to my IG Reels. Track replies/reach weekly. No bait, no dunks.
```

## Worked example 2 - small brand, starting cold, no IG (warm studio voice)
```
NICHE: one promise, one topic. Interest-graph means I don't need a following to start. 3-5 posts/week, positive tone,
photos + one tag. The growth is the replying -- leaping into relevant conversations early (human). 60-90 day horizon.
WoopSocial publishes my posts; Communities/DMs I handle natively. Watch reach + follower growth, adjust the hook.
```

Both: conversation-first, reply-more-than-post; one niche; first-hour velocity; original + positive; 3-5/week
compounding; WoopSocial publishes the posts while the reply engine is human; metrics native (never fabricated).
