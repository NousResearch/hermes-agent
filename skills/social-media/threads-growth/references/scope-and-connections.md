# Scope, distinctions + connections

threads-growth is the **account-strategy keystone** above `threads-post` — it sets the conversation-first
channel strategy (niche, cadence, the reply-more-than-post engine, format mix, the Threads→IG funnel,
metrics). The agent **strategizes + drafts the original posts + can draft suggested replies**; **WoopSocial
publishes the original posts**; the **reply flywheel, Communities, DMs, dashboards, and analytics are
human/native.**

## Honest scope (never violate)
- **The agent** sets the strategy (niche/angle, cadence, velocity plan, format mix, the funnel, metrics),
  **drafts the original posts**, and **can draft suggested replies.**
- **WoopSocial publishes** **ONE** Threads post (text + media, **≤500 chars**, one topic tag in the text; no
  postType/link-penalty/poll fields per spec) on a **schedule** — the publish bridge for **original posts.**
- **The reply flywheel — the #1 Threads growth lever — is human / `community-management`** (there's **no
  reply surface** in WoopSocial). **Communities**, **DMs**, the **Account Status dashboard**, **Threads
  analytics**, and **"Dear Algo"** are **native.**
- **No engagement-bait** (actively downranked); **original, not recycled/spun** (originality prioritized);
  **positive/constructive tone** (negativity throttled); an **IG following ≠ automatic Threads success.**
  **Never fabricate metrics**; **growth compounds (60–90 days), not overnight.** **Verify-quarterly.**

## Distinct from its siblings
- **threads-growth (this)** — the **account STRATEGY** (conversation-first, reply-more-than-post cadence,
  niche, funnel, metrics).
- **threads-post** — the **single-post CRAFT** (one ≤500-char post; the REPLY framework for a post).
- **community-management** — the **reply execution** + audience→community (the **reply flywheel is run
  here**).
- **x-growth** — **X** (news velocity, dunks/controversy) — a different culture and algorithm.
- **instagram-growth** — the **conversion side** of the Threads→IG funnel.
- **caption-writer** / **hook-writer** — the copy lines; this skill owns the **channel strategy.**

## Where this connects
- **Reads first:** `brand-profile` (niche/voice), `goals-and-kpis` (the growth goal + metric).
- **Routes craft to:** `threads-post` (the post), `caption-writer`/`hook-writer` (lines),
  `nano-banana`/`ideogram` (the +60% photo), `community-management` (the reply flywheel + Communities/DMs).
- **Funnels to:** `instagram-growth` (conversion), `cross-platform-repurposing`/`content-recycling`
  (repurpose top posts in 24–72h), `link-in-bio-and-traffic` (the route off-platform).
- **Publishes via:** `scheduling-and-queue → WoopSocial` (original posts) + `platform-specs-and-validation`.
- **Measures with:** native **Threads analytics** + `analytics-and-reporting` (reach, replies/reach, follower
  growth). **The reply flywheel, Communities, DMs, dashboards + analytics stay human/native.**
