# Promise template, design checklist, A/B plan + two worked examples

## The promise sentence (write this first)
```
This video shows [audience] how/why [specific outcome or problem] by revealing [specific mechanism].
-> Thumbnail SHOWS the hook visually; Title TELLS the context. They never repeat.
```

## Design checklist (evaluate before handing off the brief)
```
[ ] One clear focal point (1-2 hero elements); minimal/blurred background
[ ] Face: genuine expression + gaze toward the key element (or no face if it adds nothing)
[ ] Contrast: complementary pair, avoid YouTube red/white, 60-30-10, passes the B&W test, OK in light + dark
[ ] Text: 0-4 bold sans-serif words + outline, ~20-30% of frame, does NOT duplicate the title
[ ] Mobile: legible at ~168x94 px; competitor-preview for the target keyword
[ ] Safe zones: nothing critical in the bottom-right (duration badge) or bottom 15% / corners
[ ] Brand: consistent font/palette/layout with the channel's other thumbnails
```

## Spec block
```
Size 1280x720, 16:9, JPG or PNG. Cap is 50MB since early 2026 (was 2MB; the extra headroom is for 4K/TV). RGB.
Created in an image/design tool (nano-banana / ideogram / Canva / a designer) -- NOT by WoopSocial.
YouTube custom thumbnail: uploaded NATIVELY in YouTube Studio (WoopSocial has no thumbnail field).
TikTok / IG-Reel COVER: different -- a frame/card set via WoopSocial's `cover` field (tiktok-video-publishing / IG skill).
```

## A/B test plan template (native Test & Compare)
```
Variant A: [promise/emotion 1]   e.g. surprised face + "$0 to $10K"
Variant B: [promise/emotion 2]   e.g. object-only product hero, no text
Variant C: [promise/emotion 3]   e.g. before/after split
Rule: change ONE meaningful variable across the set; each tests a different reason to click.
Winner: YouTube picks by WATCH-TIME SHARE (not CTR), up to ~14 days. Not for Shorts. Needs Advanced
Features + traffic (<1k impressions/week -> inconclusive). Test & Compare can also test TITLES or
title+thumbnail combos (since Dec 2025) -- test the packaging as the unit it is.
A HUMAN uploads + runs it in Studio. Log the result for next time.
```

## Worked example 1 — tutorial, established face (blunt indie-founder voice)
```
PROMISE: shows freelancers how to run their business in Notion in 20 min. TITLE tells "Notion for Freelancers (2026)".
THUMB shows: my genuine "wait, that's it?" face (gaze -> the dashboard), one clean dashboard hero, dark bg,
yellow accent, text "20 MIN SETUP" (not repeating the title). Mobile-checked at 168x94. Brief -> image tool; I upload + Test&Compare 3 emotions.
```

## Worked example 2 — faceless, abstract topic (warm studio voice)
```
PROMISE: shows small studios why their cash flow stalls. No face (concept-focused) -> the hero is a simple
red-line-going-flat chart on a deep navy background, one arrow pointing at the dip. No text, or just "THE GAP".
High contrast, passes the B&W test, reads on a phone. Raster by the design tool; uploaded natively; best-practice + preview (low traffic, A/B may be inconclusive).
```

Both: promise written first; thumbnail+title as a unit; one focal point; honest emotion; high contrast +
short/no text; mobile-legible + safe zones; raster made by an image tool/designer; YouTube thumbnail
uploaded + tested natively; CTR from native analytics (never fabricated).
