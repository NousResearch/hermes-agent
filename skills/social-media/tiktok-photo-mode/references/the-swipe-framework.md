# The SWIPE framework — a Photo Mode carousel that earns completion

Photo Mode wins on **completion rate**, the primary signal TikTok applies to carousels — so every choice
serves "make them swipe to the end." SWIPE builds the carousel AND sets the WoopSocial PHOTO publish
config. The agent writes the **plan + overlay copy + caption + config**; the **images are made by a human
or an image skill**, and **WoopSocial publishes the native PHOTO post**.

## S — Stop the scroll on slide 1
- Slide 1 is the **thumbnail**: a bold visual or text-overlay **hook** (provocative question/claim) that
  **promises a payoff** ("the worst one is #5"). It decides most of the reach.

## W — Win the niche fit
- Pick a **swipeable content type that fits the niche** (listicle / before-after / tutorial / hot take /
  photo dump / story / myth-bust). **Honest:** photo mode is high-ceiling but **niche-dependent**,
  outnumbered ~5:1 by video, with declining average performance — it must **earn its place**, not be forced.

## I — Itemize for completion
- **One idea per slide, progressive reveal, no repeats**, with **cliffhangers between slides.** **5–7
  slides** (max 35). Design **9:16 1080×1920**, key content **centred** in the safe zone.

## P — Pay off + prompt
- **Reward on the final slide** (best insight/punchline); deliver any upfront promise; then **one clear
  CTA** (save / comment / follow). Put a **question in the caption** (+comments); **don't beg for likes**.

## E — Equip the publish config (WoopSocial PHOTO)
- Set the TikTok PHOTO fields: **`postType=PHOTO`**, **`privacyLevel`** (from the account's platform-inputs),
  **`allowComment`**, **`autoAddMusic`** (applies to PHOTO), and the disclosure flags **`isYourBrand` /
  `isBrandedContent`** set **truthfully**. (`allowDuet`/`allowStitch` are required by the API but **ignored
  for PHOTO**; there's **no `cover`** for photos.) Choose **`DIRECT_POST`** vs **`MEDIA_UPLOAD`** (inbox-to-
  finish). Add **1–2 hashtags** + **text overlays** (TikTok SEO). **Validate before publish.** AI images →
  WoopSocial auto-discloses on TikTok.

## The carousel brief a request should fill
```
ANGLE: swipeable content type + niche fit; the goal/KPI
SLIDE 1: the hook (visual + overlay) + the payoff promise
SLIDES 2-n: one idea each, progressive reveal, cliffhangers (5-7 slides, 9:16 1080x1920, centred)
LAST SLIDE: reward/punchline + one CTA; caption question; 1-2 hashtags + overlay keywords
PUBLISH (WoopSocial PHOTO): privacyLevel + allowComment + autoAddMusic + truthful isYourBrand/isBrandedContent + postMode; validate
IMAGES + METRICS: images made by human/image skill (not WoopSocial); native analytics (never fabricated)
```
