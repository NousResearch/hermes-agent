# The REACH framework — configure a TikTok VIDEO publish for reach + discovery + safe disclosure

The publish config is the **most controllable reach/SEO layer** of a TikTok video — the caption is search,
duet/stitch are free distribution, the cover wins discovery, disclosure keeps you safe. REACH configures
the publish AND writes the search caption. **The video FILE is an input** (filmed by a human or made by the
video skills); **WoopSocial publishes via `postType=VIDEO`** and auto-discloses AI on TikTok.

## R — Rank the caption (caption = search)
- **Lead-load the primary keyword** in the first ~100 chars (the actual topic, not a teaser), then a
  value-prop line, then secondary keywords + **niche hashtags**. **Long-tail.** Mirror it in on-screen text.

## E — Engage-open settings
- Keep **`allowComment` / `allowDuet` / `allowStitch` ON** — duets/stitches are **free distribution**,
  comments are the **engagement engine.** Restrict only for genuine brand-safety (know the reach cost).

## A — Attract with the cover
- Set a **clickable cover frame** — a legible **title card** that wins the **profile grid + search.**
  WoopSocial sets the `cover` image as the video's **cover/thumbnail** (1080×1920, key text centred).

## C — Confirm disclosure (truthfully)
- **`isBrandedContent`** (third-party paid) / **`isYourBrand`** (own products) set **truthfully**; **#ad
  up front.** AI content → WoopSocial **auto-discloses on TikTok**, but **prohibited AI uses** (fake
  endorsements, unlabeled deepfakes of real people) **stay prohibited.** **Branded content can't be private.**

## H — Handle mode + specs + validate
- **`privacyLevel`** from platform-inputs; **`postMode`** `DIRECT_POST` vs **`MEDIA_UPLOAD`** (inbox →
  add a trending sound natively). **1080×1920 9:16, MP4/MOV ≤1GB**, length to goal, cap from
  `maxVideoPostDurationSec`. **Validate** before publish; **no update** → delete + recreate.

## The publish brief a request should fill
```
INPUTS: the video file (external) + script/topic; brand-profile voice; the goal (reach/saves/shop)
CAPTION: primary keyword first -> value-prop -> secondary keywords + niche hashtags; mirror in on-screen text
SETTINGS: allowComment/allowDuet/allowStitch ON (unless brand-safety); privacyLevel from platform-inputs
COVER: the title-card image (cover/thumbnail, 1080x1920, centred)
DISCLOSURE: isBrandedContent/isYourBrand truthful + #ad up front; AI auto-disclosed; prohibited AI stays out
MODE + CHECK: DIRECT_POST or MEDIA_UPLOAD (trending sound); validate; no update -> delete+recreate; native analytics only
```
