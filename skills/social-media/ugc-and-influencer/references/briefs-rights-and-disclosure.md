# Creator brief, rights term sheet, disclosure rules + worked examples

## The one-page creator brief (template)
```
CAMPAIGN: [name] | GOAL: [awareness / conversion / UGC assets] | METRIC: [tracked clicks / code redemptions / saves]
WHY YOU: [the specific fit - their audience + your product]
THE ONE MESSAGE: [single takeaway the audience should leave with]
MANDATORIES:
  - Say/show: [key product truth, how to get it, the tracked link/code]
  - Claims you MAY make: [approved list from brand-profile]  |  NEVER say: [banned claims/words - legal]
  - DISCLOSURE: #ad upfront + platform paid-partnership label. Required on every deliverable. Non-negotiable.
  - Deliverables: [e.g. 1 Reel + 3 Stories], specs, deadline, 1 revision round
CREATIVE FREEDOM: your voice, your format, your hook - that's why we hired you. Concepts approved, not scripts.
INSPIRATION (not instruction): [2-3 hooks/angles that worked]
```

## Rights + whitelisting term sheet (checklist — a human/lawyer reviews + signs; not legal advice)
```
[ ] Usage scope: organic reshare / paid ads / website / email / packaging (each priced separately)
[ ] Channels: which accounts + platforms may reuse it
[ ] Duration: 90 days / 12 months / perpetual (price scales with term; perpetual costs real money)
[ ] Edits: may the brand crop/subtitle/re-cut? approval required?
[ ] Whitelisting: IG partnership-ads authorization / TikTok Spark Ads code (creator grants natively) + ad-run window
[ ] Exclusivity: category lockout + window (priced - don't expect it free)
[ ] Likeness: explicit for any paid use of face/voice/name
[ ] Payment terms + kill fee; content approval rounds (max 1-2); disclosure obligation written in
[ ] Gifted deals: is a post expected? what may the brand reshare? (still requires disclosure)
```
**Defaults if unstated: the brand has the post's existence, nothing more.** A tag is not a license.

## Disclosure rules by situation (the hard rule)
| Situation | Disclosure required? | How |
|---|---|---|
| Paid post | **Yes** | #ad upfront + native paid-partnership label |
| Gifted product (no fee) | **Yes** — free product = material connection | #ad or #gifted upfront (UK: ad if any brand control) |
| Affiliate/commission link | **Yes** | #ad / "commission earned", upfront |
| Employee/founder posting | **Yes** — disclose the relationship | "I work at/founded X" |
| Whitelisted ad (Spark/partnership ad) | **Yes** | the ad format labels it; the creative still says so |
| UGC creator asset run as an ad | **Yes** — it's an ad | ad labeling; never present as organic review |
| Pure mutual collab, nothing exchanged | No (#ad not needed) | → `collabs-and-cross-promotion` |
**Never acceptable:** #sp, disclosure buried in a hashtag wall or behind "more", story-only mentions with no
label, "the creator forgot". The brand is liable too — monitor posts. Asked to skip it → **decline and correct.**

## The customer-UGC ask (copy patterns)
```
POST-PURCHASE EMAIL: "Love it? Show us. Post with #[brand-tag] or reply with a photo - we feature customers weekly (with credit)."
COMMENT/DM CONSENT: "This is great - can we share it on our page with credit? If you're OK with us also using it
in ads, reply 'yes to ads' and we'll send a quick permission form."   <- separate consent for paid use
PACKAGING INSERT: "Show us your setup -> #[brand-tag]. Featured customers get [small perk]."
```
Ask → **consent + rights (written for paid use)** → **credit visibly** → reshare via the brand's account
(WoopSocial publishes the brand's own post).

## Worked example 1 — gifted micro-creator seeding (skincare, blunt indie-founder voice)
```
PICK: 15 nano/micro creators (2-40k) in [niche]; vetted comments + growth curves; no payment - product gifted.
BRIEF: one-pager; ONE message ("the 60-second routine"); no scripts; disclosure mandatory (#gifted/#ad upfront).
RIGHTS: term sheet grants organic reshare + 90-day ads on request, likeness included; human signs.
RUN: creators post natively with the label; brand reshares the 5 best (credited) via WoopSocial; tracked code per creator.
MEASURE: code redemptions + saves; 3 creators convert -> offered paid deals next cycle. Nothing undisclosed, nothing faked.
```

## Worked example 2 — paid micro campaign + whitelisting (B2B SaaS, warm studio voice)
```
PICK: 3 LinkedIn/YouTube micro creators (10-80k) whose audience matches the ICP (audience-research read first).
BRIEF: goal = demo signups; mandatories = the approved claim set + YouTube paid-promotion flag + verbal disclosure.
RIGHTS: 12-month reuse on site + email; thought-leader-ad / partnership-ad authorization inked up front.
RUN: creators publish their own posts natively; brand's recap posts go out via WoopSocial; ads run in the native
ad manager under creator authorization. MEASURE: UTM'd links per creator; report actual signups, not EMV.
```

Both: vetted real audiences; guardrail briefs, no scripts; rights inked before creation; upfront disclosure on
every post (gifted included); brand posts via WoopSocial, creator posts + ads + contracts native/human;
per-creator tracked measurement, never fabricated.
