# The Deconstruction Framework

A systematic teardown of a viral (or overperforming) piece — the layers to analyze, then how to
isolate which layer actually drove it. The goal is the **mechanism**, not a description.

## The layers — tear down each one

Go through every layer and note what the piece did:

1. **Hook (first 1–3 sec / first line)** — what stopped the scroll? The opening claim, image,
   tension, or pattern interrupt. (See `hook-writer`.)
2. **Emotional / share driver** — what did it make people *feel* (awe, anger, humor, inspiration,
   recognition)? This is usually the real engine — see `why-things-spread.md`.
3. **Retention structure** — how did it hold attention to the end (open loops, pacing, payoff,
   loop)? High completion/rewatch is a core distribution signal.
4. **Format / packaging** — the format (talking head, storytime, listicle, carousel), the title/
   thumbnail/cover, on-screen text, length.
5. **Topic / angle** — the specific take. Was it contrarian, novel, timely, deeply relatable?
6. **Share-trigger** — *why did people send it to someone else?* (Identity, "this is so us,"
   usefulness, social currency.) Virality = shares, so this layer is decisive.
7. **Distribution factors** — the things *around* the content: the creator's existing audience size,
   trending sound, posting time, a one-time news moment, platform boosts. Often miscredited as the
   content's merit (see `replicability-and-application.md`).

Write a one-line note per layer. Resist the urge to praise everything — most layers are competent
but not the *cause*.

## Isolate the real driver (the counterfactual test)

A viral piece has many features; usually **only one or two actually drove it.** To find them, run
the counterfactual on each notable feature:

> **"Remove this — does it still pop?"**

- Remove the trending sound → would a strong, relatable hook + story still have spread? If yes, the
  sound was incidental, not the driver.
- Swap the hook for a flat one → does it die? If yes, the hook was load-bearing.
- Strip the emotional turn → is it just a nice video? If yes, the *emotion* was the engine.

Whatever the piece **can't lose without collapsing** is the driver. Whatever it could lose and still
work is noise. **Most bad analysis credits the noise** (the sound, the topic, the surface format) and
misses the load-bearing element (usually the hook + the emotional/share trigger).

## Rate each layer: driver vs incidental

For each layer, tag it:

- **DRIVER** — load-bearing; the piece fails without it. (Usually 1–2 layers.)
- **SUPPORTING** — helped, but not the cause.
- **INCIDENTAL** — present but didn't matter; don't copy it as if it did.
- **CONFOUND** — a distribution factor (audience size, luck, one-time moment) that isn't a content
  lesson at all → flag for the replicability check.

## The output of a teardown

A clean teardown produces: the **1–2 real drivers**, the **share-trigger**, the **confounds to
discount**, and a one-sentence statement of the **mechanism** ("a load-bearing relatable hook + an
anger/justice emotional trigger drove the shares; the sound and topic were incidental"). That
mechanism is what you carry into `replicability-and-application.md`.
