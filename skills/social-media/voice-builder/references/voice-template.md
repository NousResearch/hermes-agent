# voice.md Template

The output of this skill. It must be **operational** — rules a writer or another skill can
follow — not a personality essay. Every rule should trace back to a sample. Keep it tight;
downstream skills read it on every task.

Copy everything below the line into `voice.md` and fill it in.

## How downstream skills should use this

Read the **fingerprint**, the **never** list, and the **do/don't rewrites** on every task —
those three carry most of the voice. Use the **tone map** to adjust register for the platform.
When unsure, match the **calibration anchors**. If a section is empty or low-confidence, write
conservatively and flag it rather than inventing voice.
