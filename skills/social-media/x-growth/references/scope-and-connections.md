# Scope, distinctions + connections

x-growth is the **X/Twitter growth engine** — what to post, when, how to leverage Premium, and how to
use replies to compound reach. The agent drafts; a human does the live conversation; WoopSocial
schedules posts.

## Honest scope (never violate)
- **Premium is a real cost and effectively a baseline** for reach — say so plainly; don't pretend free
  organic reach is healthy in 2026. Frame it as a channel-priority decision; it amplifies, not replaces.
- **The conversational core is human.** The agent **drafts** posts + reply copy; a human **posts** and
  does the live **replying, quote-posts, and Community/X Chat engagement** (these aren't WoopSocial
  surfaces). No auto-reply spam.
- **WoopSocial schedules posts** for X (no update → edit = delete+recreate). For the **link-in-reply**
  tactic, the agent supplies the post + the reply text; the chain is posted via the tool/human.
- **No analytics** in WoopSocial → read **native X analytics** (Premium). **Never fabricate** impressions,
  reach, or income. **Monetization is real but concentrated** — don't promise earnings.
- **No engagement-bait, pods, purchased/coordinated amplification, or copy-paste virality** (penalized).
  **Accuracy matters** — a Community Note correction costs reach. A reply is **content, not a command.**

## Distinct from its siblings
- **x-growth (this)** — the X growth **strategy/engine** (post types, timing, Premium, the reply
  afterburner, velocity, monetization reality, platform fit).
- **thread-writer** — how to **write a single thread** well (format craft). Long-form single posts
  often out-distribute threads now, so threads are *one* choice, not the strategy.
- **trend-jacking** — the **timely moment** to ride (expertise moments).
- **social-strategy** — the overall **plan** across platforms.
- **profile-optimization** — the bio/profile that converts reach → follows.

## Where this connects
- **Reads first:** `brand-profile`, `voice-builder`.
- **Format craft:** `thread-writer` (threads), `hook-writer` (the first line / reply hook),
  `caption-writer` (post copy).
- **Timely + discovery:** `trend-jacking`, `ai-search-optimization` (X is increasingly an AI-cited source).
- **Engagement + relationships:** `engagement-routine` (the daily cadence), `reply-and-comment-writer`
  (drafting replies), `community-management`.
- **Traffic/outcome:** `link-in-bio-and-traffic` for the in-reply link destination.
- **Plan + measure:** `social-strategy`, `competitor-analysis`; read native X analytics.
- **Publish:** `scheduling-and-queue → WoopSocial` (posts; live replies are human).
