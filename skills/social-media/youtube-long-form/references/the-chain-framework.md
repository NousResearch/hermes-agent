# The CHAIN framework — build every video as a link, not an island

Long-form is the opposite of Shorts: no swipe to win, but a **packaging gate** (the click) and a
**retention gate** (do they stay — and watch more). And the dominant 2026 signal isn't your
video's watch time, it's whether your video makes the **session** longer. So build each upload as
a link in a CHAIN.

## C — Click (packaging earns the impression → CTR)
- **Package before you produce.** Write the title and sketch the thumbnail *before* scripting. If
  you can't make the packaging compelling, the idea isn't strong enough yet.
- **Clarity beats clickbait beats clutter.** The fastest CTR lifts usually come from *removing*
  clutter — one clear idea, readable at mobile size, accurate to the video.
- **A/B test** title/thumbnail variants in Studio. Target a healthy niche CTR (~4–10%).

## H — Hook (the first 30 seconds pay off the promise)
- **Open with the payoff, the stakes, or the question.** No logo animation, no "hey guys."
- Deliver *exactly* what the packaging promised, immediately. A steep early drop is read as
  clickbait-that-didn't-deliver and chokes distribution. (Lines → hook-writer.)

## A — AVD (structure holds retention)
- **Re-hook every 60–90 seconds:** open loops, pattern interrupts, B-roll, angle/tone changes.
- **One topic, no padding.** Match length to the idea (8–15 min when retention holds). Cutting
  length is often the strongest single fix.
- Watch the retention curve for the cliffs and fix those specific moments.

## I — Iterate (diagnose with three numbers)
- **CTR** = packaging. **30-sec retention** = hook. **AVD %** = structure. These three tell you
  exactly what to fix next.
- **Test one variable at a time** (hook, then thumbnail, then topic, then timing). Intentional
  testers grow markedly faster than random posters. Improve one element per upload.

## N — Next (engineer session contribution — the dominant signal)
- End every video by **chaining to the next watch**: a specific end-screen video, a playlist, a
  series with clear progression, a "watch next" that continues the session.
- Make the next-video watch time *high* — if viewers bounce off your end screen, you're killing
  sessions. Pick the chain target deliberately.
- **Bridge from Shorts:** each Short should reference a specific long-form (the click-through is
  tracked). The chain spans formats. (Sibling: youtube-shorts.)

## The blueprint a plan should fill
```
PACKAGE   working title + thumbnail concept (before script)
COLD OPEN  payoff/stakes in the first 30s, matches the package
BODY       segmented value, re-hook every 60–90s, no padding, target length
CLOSE      single CTA + an explicit NEXT (end screen / playlist / series)
SHIP WITH  keyword-aligned description + chapters (Search), captions,
           Altered-Content disclosure if AI-generated
```
