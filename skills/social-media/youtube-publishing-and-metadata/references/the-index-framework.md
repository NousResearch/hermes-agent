# The INDEX framework — YouTube publish metadata that ranks

Metadata is the **index card the algorithm reads first** — it's the launchpad before user behavior kicks
in. INDEX writes the title/description/tags and sets category/privacy/madeForKids. The **video FILE +
script are inputs**; **WoopSocial publishes via the YouTube fields**; the **thumbnail + A/B testing are
native Studio**.

## I — Intent-match the title
- **Primary keyword in the first ~40 chars**, ~**50–60** total. **Two jobs:** rank (keyword) + click
  (clarity/curiosity). Power words help; **autocomplete/long-tail**; **clarity over cleverness.**

## N — Nail the description above-the-fold
- **Line 1 = value/hook**; **primary keyword in lines 2–3**; **300–500 words** natural (no stuffing).
  **Keyword-named chapters/timestamps**; **3–7 links** (internal first); **affiliate disclosure** if any.
  (The description is `content.text`.)

## D — Direct the tags
- **First tag = exact primary keyword**; then secondary + niche. **Relevant-only** (YouTube's AI checks);
  tags are a minor signal now, so don't over-invest — get the first one right.

## E — Elect category + privacy
- Pick the **accurate `category`** (correct grouping/recommendation). Set **`privacy`** (`public` for
  reach / `unlisted` link-only / `private`) to the goal.

## X — eXamine the kids-flag + validate
- Set **`madeForKids` truthfully** per **COPPA/FTC** (child-directed content → made-for-kids; it disables
  comments/personalized ads/etc.). **Never mislabel.** Then **validate** (`YOUTUBE_PRIVACY/CATEGORY/TAGS`,
  TITLE, DESCRIPTION) before publish. **No update** → delete+recreate (or edit in Studio post-publish).

## The metadata brief a request should fill
```
INPUTS: the video file + script (external); brand-profile voice; the goal (search reach / subs / watch time)
TITLE: primary keyword in first ~40 chars; ~50-60 total; rank + click; power word; clarity
DESCRIPTION (content.text): line 1 value -> keyword lines 2-3 -> 300-500 words; chapters; 3-7 links + disclosure
TAGS: first = exact primary keyword; secondary + niche; relevant-only
CATEGORY + PRIVACY: accurate category; public/unlisted/private per goal
KIDS + CHECK: madeForKids set truthfully (COPPA); validate; thumbnail + A/B = native Studio; metrics native (never fabricated)
```
