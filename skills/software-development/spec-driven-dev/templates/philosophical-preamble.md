# Philosophical Preamble

Per-project. Lives between `docs/worldview.md` (standing, general) and the
Spec Kit constitution (non-negotiable principles). Answers one question:
**why does this project exist** — not what it does or how, those belong
in spec.md and plan.md.

Keep this short — a few paragraphs, not a design document. If it starts
accumulating technical detail, that detail belongs in spec.md/plan.md
instead.
