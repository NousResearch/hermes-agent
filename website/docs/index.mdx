# Ares

**Ares is an evidence-native, Hermes-compatible AI workbench maintained by RecursiveIntell.** It is a downstream distribution of [Hermes Agent](https://github.com/NousResearch/hermes-agent), not an official Nous Research product.

Ares preserves the familiar `hermes` package and CLI while adding a distinct installer, an isolated `~/.ares` default home, and documented integration boundaries for evidence-oriented local services.

## Start here

1. Read the [Ares distribution boundary](/ares) to understand what is fork-owned, optional, or merely Hermes-compatible.
2. Follow the source-reviewed bootstrap in the [Ares README](https://github.com/RecursiveIntell/hermes-agent#quick-start).
3. Configure a provider through `ares setup`; the bootstrap does not create credentials or select a provider for you.
4. Add optional services only after their own lifecycle and verification gates pass.

## Ares-specific capability model

| Layer | State | Evidence needed before relying on it |
|---|---|---|
| Ares runtime | Hermes-compatible | A fresh `ares --version` / `ares doctor` check |
| Plugin | Installed | Fresh plugin discovery and tool registration |
| Service | Configured | Reachable service with typed configuration |
| Governed execution | Exercised | Bounded run plus daemon-derived verification facts |

A selected or registered component is not necessarily exposed in the current session; an exposed component is not proof of a successful real-world run.

## Hermes-compatible reference documentation

The rest of this site documents the Hermes-compatible base. It remains relevant for the CLI, configuration, tools, skills, gateway, and desktop surfaces that Ares has not replaced. Where this documentation names upstream distribution URLs or upstream support channels, treat those as **upstream Hermes references**, not Ares delivery or support commitments.

## Important boundaries

- Ares does not claim production readiness, security certification, or universal provider/platform support.
- Plugins and hooks execute with the authority of the Ares/Hermes agent process; review them before installation.
- Operating-system or whole-process isolation—not prompts, receipts, or tool allowlists—is the containment boundary for hostile-input workloads.
- Recursive Agent, semantic memory, Agent Graph, Claim Ledger, CEA Graph, and Pilot Bridge are separate services/projects. Their source presence does not make them installed or active.

```powershell
iex (irm https://hermes-agent.nousresearch.com/install.ps1)
```

See the full **[Installation Guide](/getting-started/installation)** for what the installer does, the per-user vs root layout, and Windows-specific notes. For the complete platform support matrix, see **[Platform Support](/getting-started/platform-support)**.

:::tip Fastest path to a working agent
After installing, run `hermes setup --portal` — one OAuth covers a model plus all four Tool Gateway tools (web search, image generation, TTS, browser). See [Nous Portal](/integrations/nous-portal).
:::

## What is Hermes Agent?

It's not a coding copilot tethered to an IDE or a chatbot wrapper around a single API. It's an **autonomous agent** that gets more capable the longer it runs. It lives wherever you put it — a $5 VPS, a GPU cluster, or serverless infrastructure (Daytona, Modal) that costs nearly nothing when idle. Talk to it from Telegram while it works on a cloud VM you never SSH into yourself. It's not tied to your laptop.

## Key Features

- **A closed learning loop** — Agent-curated memory with periodic nudges, autonomous skill creation, skill self-improvement during use, FTS5 cross-session recall with LLM summarization, and [Honcho](https://github.com/plastic-labs/honcho) dialectic user modeling
- **Runs anywhere, not just your laptop** — 6 terminal backends: local, Docker, SSH, Daytona, Singularity, Modal. Daytona and Modal offer serverless persistence — your environment hibernates when idle, costing nearly nothing
- **Lives where you do** — CLI, Telegram, Discord, Slack, WhatsApp, Signal, Matrix, Mattermost, Email, SMS, DingTalk, Feishu, WeCom, Weixin, QQ Bot, Yuanbao, BlueBubbles, Home Assistant, Microsoft Teams, Google Chat, and more — 20+ platforms from one gateway
- **Built by model trainers** — Created by [Nous Research](https://nousresearch.com), the lab behind Hermes, Nomos, and Psyche. Works with [Nous Portal](https://portal.nousresearch.com), [OpenRouter](https://openrouter.ai), OpenAI, or any endpoint
- **Scheduled automations** — Built-in cron with delivery to any platform
- **[Bot Mode](/user-guide/bot-mode)** — Build a durable team of specialist Bots that work together in group chats and through `@mentions`
- **Delegates & parallelizes** — Spawn isolated subagents for parallel workstreams. Programmatic Tool Calling via `execute_code` collapses multi-step pipelines into single inference calls
- **Open standard skills** — Compatible with [agentskills.io](https://agentskills.io). Skills are portable, shareable, and community-contributed via the Skills Hub
- **Full web control** — Search, extract, browse, vision, image generation, TTS — one subscription via [Nous Portal](/integrations/nous-portal) bundles all of them
- **MCP support** — Connect to any MCP server for extended tool capabilities
- **Research-ready** — Batch processing, trajectory export, RL training with Atropos. Built by [Nous Research](https://nousresearch.com) — the lab behind Hermes, Nomos, and Psyche models
