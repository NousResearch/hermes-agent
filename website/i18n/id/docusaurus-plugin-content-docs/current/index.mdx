## Instalasi

### Windows atau macOS

Untuk memasang aplikasi command-line dan desktop dengan mudah, [unduh installer Hermes Desktop](https://hermes-agent.nousresearch.com/) dari website kami lalu jalankan.

### Tanpa Hermes Desktop:

Untuk instalasi command-line saja tanpa Hermes Desktop, jalankan:

#### Linux / macOS / WSL2 / Android (Termux)

```bash
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
```

#### Windows (native)

Jalankan di PowerShell:

```powershell
iex (irm https://hermes-agent.nousresearch.com/install.ps1)
```

Lihat **[Panduan Instalasi](/getting-started/installation)** lengkap untuk mengetahui apa yang dilakukan installer, layout per-user vs root, dan catatan khusus Windows. Untuk matriks dukungan platform lengkap, lihat **[Dukungan Platform](/getting-started/platform-support)**.

:::tip Jalur tercepat menuju agen yang siap digunakan
Setelah instalasi, jalankan `hermes setup --portal` — satu OAuth mencakup model sekaligus keempat tool Tool Gateway (web search, image generation, TTS, browser). Lihat [Nous Portal](/integrations/nous-portal).
:::

## Apa itu Hermes Agent?

Hermes bukan coding copilot yang terikat pada IDE atau sekadar chatbot wrapper untuk satu API. Hermes adalah **agen otonom** yang semakin mampu semakin lama digunakan. Ia berjalan di mana pun Anda menempatkannya — VPS $5, cluster GPU, atau infrastruktur serverless (Daytona, Modal) yang nyaris tanpa biaya saat idle. Berbicaralah dengannya melalui Telegram saat ia bekerja pada VM cloud yang bahkan tidak perlu Anda akses sendiri melalui SSH. Hermes tidak terikat pada laptop Anda.

## Fitur Utama

- **Loop pembelajaran tertutup** — Memori yang dikurasi agen dengan dorongan berkala, pembuatan skill otomatis, peningkatan skill selama digunakan, recall lintas sesi dengan FTS5 dan peringkasan LLM, serta pemodelan pengguna dialektik [Honcho](https://github.com/plastic-labs/honcho)
- **Berjalan di mana saja, bukan hanya di laptop Anda** — 6 backend terminal: local, Docker, SSH, Daytona, Singularity, Modal. Daytona dan Modal menawarkan persistensi serverless — environment Anda berhibernasi saat idle sehingga nyaris tanpa biaya
- **Hadir di tempat Anda berada** — CLI, Telegram, Discord, Slack, WhatsApp, Signal, Matrix, Mattermost, Email, SMS, DingTalk, Feishu, WeCom, Weixin, QQ Bot, Yuanbao, BlueBubbles, Home Assistant, Microsoft Teams, Google Chat, dan lainnya — 20+ platform dari satu gateway
- **Dibangun oleh pelatih model** — Dibuat oleh [Nous Research](https://nousresearch.com), lab di balik Hermes, Nomos, dan Psyche. Bekerja dengan [Nous Portal](https://portal.nousresearch.com), [OpenRouter](https://openrouter.ai), OpenAI, atau endpoint apa pun
- **Otomatisasi terjadwal** — Cron bawaan dengan pengiriman ke platform mana pun
- **[Bot Mode](/user-guide/bot-mode)** — Bangun tim Bot spesialis yang persisten untuk bekerja bersama dalam group chat dan melalui `@mentions`
- **Mendelegasikan dan menjalankan secara paralel** — Jalankan subagen terisolasi untuk workstream paralel. Programmatic Tool Calling melalui `execute_code` meringkas pipeline multi-langkah menjadi satu inference call
- **Skill berstandar terbuka** — Kompatibel dengan [agentskills.io](https://agentskills.io). Skill portabel, dapat dibagikan, dan dapat dikontribusikan komunitas melalui Skills Hub
- **Kontrol web lengkap** — Search, extract, browse, vision, image generation, TTS — satu subscription melalui [Nous Portal](/integrations/nous-portal) mencakup semuanya
- **Dukungan MCP** — Hubungkan server MCP apa pun untuk memperluas kapabilitas tool
- **Siap untuk riset** — Batch processing, trajectory export, dan RL training dengan Atropos. Dibangun oleh [Nous Research](https://nousresearch.com) — lab di balik model Hermes, Nomos, dan Psyche

## Untuk LLM dan agen coding

Entry point yang dapat dibaca mesin untuk dokumentasi ini:

- **[`/llms.txt`](/llms.txt)** — indeks terkurasi dari setiap halaman dokumentasi dengan deskripsi singkat. Sekitar 17 KB, aman dimuat ke context LLM.
- **[`/llms-full.txt`](/llms-full.txt)** — seluruh halaman dokumentasi yang digabungkan menjadi satu file Markdown untuk one-shot ingestion. Sekitar 1,8 MB.

Kedua file juga tersedia melalui `/docs/llms.txt` dan `/docs/llms-full.txt`. Keduanya dibuat ulang pada setiap deployment.
