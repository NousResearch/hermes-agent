# Manim 비디오 제작 파이프라인

## 사용 시점

사용자가 애니메이션 설명, 수학 애니메이션, 개념 시각화, 알고리즘 단계별 안내, 기술 설명, 3Blue1Brown 스타일 비디오 또는 기하학적/수학적 콘텐츠가 있는 프로그래밍 애니메이션을 요청할 때 사용합니다. Manim Community Edition을 사용하여 3Blue1Brown 스타일의 설명 비디오, 알고리즘 시각화, 방정식 유도, 아키텍처 다이어그램 및 데이터 스토리를 만듭니다.

## 창작 기준

이것은 교육용 영화입니다. 모든 프레임이 가르침을 전달합니다. 모든 애니메이션이 구조를 드러냅니다.

**코드 한 줄을 작성하기 전에**, 이야기의 흐름을 명확히 설명하세요. 어떤 오해를 바로잡나요? "아하"의 순간은 무엇인가요? 시청자를 혼란에서 이해로 이끄는 시각적 이야기는 무엇인가요? 사용자의 프롬프트는 출발점일 뿐입니다 — 교육학적 야심을 가지고 해석하세요.

**대수보다 기하를 먼저 보여주세요.** 도형을 먼저 보여주고 방정식을 두 번째로 보여주세요. 시각적 기억은 기호 기억보다 빠르게 부호화됩니다. 시청자가 공식보다 먼저 기하학적 패턴을 보면 방정식이 자연스럽게 받아들여집니다.

**첫 렌더링의 완성도는 타협할 수 없습니다.** 결과물은 수정 작업 없이도 시각적으로 명확하고 미적으로 통일되어야 합니다. 무언가가 복잡하거나, 타이밍이 나쁘거나, "AI가 만든 슬라이드"처럼 보인다면 잘못된 것입니다.

**불투명도 레이어링으로 주의를 유도하세요.** 모든 것을 최고 밝기로 표시하지 마세요. 주요 요소는 1.0, 맥락 요소는 0.4, 구조 요소(축, 격자)는 0.15로 설정하세요. 뇌는 시각적 두드러짐을 계층적으로 처리합니다.

**여백을 확보하세요.** 모든 애니메이션 뒤에는 `self.wait()`가 필요합니다. 시청자가 방금 나타난 내용을 흡수할 시간이 필요합니다. 한 애니메이션에서 다음 애니메이션으로 서두르지 마세요. 핵심 공개 후 2초간 멈추는 것은 결코 낭비가 아닙니다.

**통일된 시각 언어를 사용하세요.** 모든 장면은 색상 팔레트, 일관된 타이포그래피 크기, 서로 어울리는 애니메이션 속도를 공유해야 합니다. 모든 장면이 무작위로 다른 색을 사용하는 기술적으로 올바른 비디오는 미적으로 실패한 것입니다.

## 사전 요구 사항

모든 종속성을 확인하려면 `scripts/setup.sh`를 실행하세요. Python 3.10+, Manim Community Edition v0.20+(`pip install manim`), LaTeX( Linux에서는 `texlive-full`, macOS에서는 `mactex`), ffmpeg가 필요합니다. 참조 문서는 Manim CE v0.20.1에서 테스트되었습니다.

## 파이프라인

```
PLAN --> CODE --> RENDER --> STITCH --> AUDIO (optional) --> REVIEW
```

1. **PLAN** — 내러티브 흐름, 장면 목록, 시각 요소, 색상 팔레트, 보이스오버 스크립트가 포함된 `plan.md` 작성
2. **CODE** — 각 장면을 독립적으로 렌더링할 수 있도록 장면당 하나의 클래스를 포함한 `script.py` 작성
3. **RENDER** — 초안은 `manim -ql script.py Scene1 Scene2 ...`, 프로덕션은 `-qh` 사용
4. **STITCH** — 장면 클립을 `final.mp4`로 결합하는 ffmpeg concat
5. **AUDIO** (선택 사항) — ffmpeg를 통해 보이스오버 및/또는 배경 음악 추가. `references/rendering.md` 참조
6. **REVIEW** — 미리보기 스틸을 렌더링하고 계획과 비교하여 확인 및 조정

## 프로젝트 구조

```
project-name/
  plan.md                # Narrative arc, scene breakdown
  script.py              # All scenes in one file
  concat.txt             # ffmpeg scene list
  final.mp4              # Stitched output
  media/                 # Auto-generated by Manim
    videos/script/480p15/
```

### 글꼴

**모든 텍스트에는 고정폭 글꼴을 사용하세요.** Manim의 Pango 렌더러는 모든 크기에서 비례 글꼴의 커닝을 깨뜨립니다. 전체 권장 사항은 `references/visual-design.md`를 참조하세요.

```python
MONO = "Menlo"  # define once at top of file

Text("Fourier Series", font_size=48, font=MONO, weight=BOLD)  # titles
Text("n=1: sin(x)", font_size=20, font=MONO)                  # labels
MathTex(r"\nabla L")                                            # math (uses LaTeX)
```

가독성을 위해 최소 `font_size=18`을 사용하세요.

### 장면별 변주

모든 장면에 동일한 설정을 사용하지 마세요. 각 장면마다 다음을 다르게 하세요.
- 팔레트에서 **주요 색상**을 다르게 선택
- **레이아웃**을 다르게 구성 — 항상 모든 것을 가운데에 배치하지 않기
- **애니메이션 진입 방식**을 다르게 선택 — Write, FadeIn, GrowFromCenter, Create를 번갈아 사용
- **시각적 밀도**를 다르게 구성 — 어떤 장면은 빽빽하게, 다른 장면은 여유롭게

## 워크플로

### 1단계: 계획 (plan.md)

코드를 작성하기 전에 `plan.md`를 작성하세요. 자세한 템플릿은 `references/scene-planning.md`를 참조하세요.

### 2단계: 코드 (script.py)

장면당 하나의 클래스. 모든 장면을 독립적으로 렌더링할 수 있어야 합니다.

```python
from manim import *

BG = "#1C1C1C"
PRIMARY = "#58C4DD"
SECONDARY = "#83C167"
ACCENT = "#FFFF00"
MONO = "Menlo"

class Scene1_Introduction(Scene):
    def construct(self):
        self.camera.background_color = BG
        title = Text("Why Does This Work?", font_size=48, color=PRIMARY, weight=BOLD, font=MONO)
        self.add_subcaption("Why does this work?", duration=2)
        self.play(Write(title), run_time=1.5)
        self.wait(1.0)
        self.play(FadeOut(title), run_time=0.5)
```

핵심 패턴:
- 모든 애니메이션에 **자막** 추가: `self.add_subcaption("text", duration=N)` 또는 `self.play()`의 `subcaption="text"`
- 장면 간 일관성을 위해 파일 상단에 **공유 색상 상수** 배치
- 모든 장면에서 **`self.camera.background_color`** 설정
- **깔끔한 종료** — 장면 마지막에 모든 mobject 페이드 아웃: `self.play(FadeOut(Group(*self.mobjects)))`

### 3단계: 렌더링

```bash
manim -ql script.py Scene1_Introduction Scene2_CoreConcept  # draft
manim -qh script.py Scene1_Introduction Scene2_CoreConcept  # production
```

### 4단계: 결합

```bash
cat > concat.txt << 'EOF'
file 'media/videos/script/480p15/Scene1_Introduction.mp4'
file 'media/videos/script/480p15/Scene2_CoreConcept.mp4'
EOF
ffmpeg -y -f concat -safe 0 -i concat.txt -c copy final.mp4
```

### 5단계: 검토

```bash
manim -ql --format=png -s script.py Scene2_CoreConcept  # preview still
```

## 핵심 구현 참고 사항

### LaTeX에는 원시 문자열 사용
```python
# WRONG: MathTex("\frac{1}{2}")
# RIGHT:
MathTex(r"\frac{1}{2}")
```

### 가장자리 텍스트에는 buff >= 0.5 사용
```python
label.to_edge(DOWN, buff=0.5)  # never < 0.5
```

### 텍스트를 교체하기 전에 FadeOut
```python
self.play(ReplacementTransform(note1, note2))  # not Write(note2) on top
```

### 추가하지 않은 Mobject는 애니메이션하지 않기
```python
self.play(Create(circle))  # must add first
self.play(circle.animate.set_color(RED))  # then animate
```

## 창작적 변주 (사용자가 실험적/창의적/독특한 결과물을 요청한 경우에만 사용)

사용자가 창의적이거나 실험적이거나 관습에 얽매이지 않은 설명 방식을 요청하면, 애니메이션을 설계하기 전에 전략을 선택하고 그 이유를 검토하세요.

- **SCAMPER** — 표준 설명에 새로운 접근을 원할 때
- **가정 뒤집기** — 일반적으로 가르치는 방식을 문제 삼고 싶을 때

### SCAMPER 변환

표준적인 수학/기술 시각화를 가져와 다음과 같이 변환하세요.
- **대체**: 표준적인 시각적 은유를 교체 (수직선 → 굽이치는 경로, 행렬 → 도시 격자)
- **결합**: 두 가지 설명 방식을 결합 (대수적 + 기하학적 동시 표현)
- **역전**: 결과에서 거꾸로 유도 — 결과에서 시작하여 공리로 분해
- **수정**: 매개변수를 과장하여 그 중요성을 표시 (학습률 10배, 표본 수 1000배)
- **제거**: 모든 표기 제거 — 애니메이션과 공간적 관계만으로 설명

### 가정 뒤집기
1. 이 주제를 시각화하는 방식에서 무엇이 "표준적인지" 나열 (왼쪽에서 오른쪽, 2D, 이산 단계, 형식 표기)
