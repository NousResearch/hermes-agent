# บทช่วยสอน: สร้าง Daily Briefing Bot

ในบทช่วยสอนนี้ คุณจะได้สร้าง personal briefing bot ที่ตื่นขึ้นมาทำงานทุกเช้า ค้นหาข้อมูลหัวข้อที่คุณสนใจ สรุปผลที่ค้นได้ และส่ง briefing ฉบับย่อไปยัง Telegram หรือ Discord ของคุณโดยตรง

เมื่อจบบทช่วยสอนนี้ คุณจะมี workflow อัตโนมัติครบวงจรที่ผสาน **web search**, **cron scheduling**, **delegation** และ **messaging delivery** เข้าด้วยกัน — โดยไม่ต้องเขียนโค้ดเลย

:::tip
สูตรนี้ใช้ทั้ง web search, summarization และ TTS (ไม่บังคับ) — รวมอยู่ใน subscription ของ Portal ทั้งหมด วิธีติดตั้งที่เร็วที่สุดคือ `hermes setup --portal` ดูที่ [Nous Portal](/integrations/nous-portal)
:::

## สิ่งที่เรากำลังจะสร้าง

ขั้นตอนการทำงานเป็นดังนี้:

1. **8:00 AM** — cron scheduler เรียกใช้ job ของคุณ
2. **Hermes สตาร์ท** agent session ใหม่เปล่าพร้อม prompt ของคุณ
3. **Web search** ดึงข่าวล่าสุดเกี่ยวกับหัวข้อของคุณ
4. **Summarization** กลั่นข้อมูลเหล่านั้นให้เป็น briefing ที่อ่านง่าย
5. **Delivery** ส่ง briefing ไปยัง Telegram หรือ Discord ของคุณ

ทั้งหมดนี้ทำงานเองโดยไม่ต้องจับตาดู ภาระของคุณมีเพียงอ่าน briefing ควบคู่กับกาแฟยามเช้า

## สิ่งที่ต้องมี

ก่อนเริ่มต้น ตรวจสอบให้แน่ใจว่าคุณมี:

- **Hermes Agent ติดตั้งแล้ว** — ดูที่ [Installation guide](/getting-started/installation)
- **Gateway กำลังทำงานอยู่** — daemon ของ gateway เป็นตัวจัดการการรัน cron:
  ```bash
  hermes gateway install   # Install as a user service
  sudo hermes gateway install --system   # Linux servers: boot-time system service
  # or
  hermes gateway           # Run in foreground
  ```
- **Firecrawl API key** — ตั้งค่า `FIRECRAWL_API_KEY` ใน environment ของคุณสำหรับ web search
- **Messaging ตั้งค่าแล้ว** (ไม่บังคับแต่แนะนำ) — [Telegram](/user-guide/messaging/telegram) หรือ Discord พร้อม home channel

:::tip ไม่มี messaging? ไม่เป็นไร
คุณยังทำตามบทช่วยสอนนี้ได้โดยใช้ `deliver: "local"` Briefing จะถูกบันทึกไว้ที่ `~/.hermes/cron/output/` และคุณเปิดอ่านได้ทุกเมื่อ
:::

## Step 1: ทดสอบ Workflow ด้วยตนเอง

ก่อนจะทำให้อะไรเป็นอัตโนมัติ มาดูกันก่อนว่า briefing ใช้งานได้ เริ่ม chat session:

```bash
hermes
```

แล้วป้อน prompt นี้:

```
Search for the latest news about AI agents and open source LLMs.
Summarize the top 3 stories in a concise briefing format with links.
```

Hermes จะค้นเว็บ อ่านผลลัพธ์ แล้วสร้างสิ่งที่ประมาณนี้:

```
☀️ Your AI Briefing — March 8, 2026

1. Qwen 3 Released with 235B Parameters
   Alibaba's latest open-weight model matches GPT-4.5 on several
   benchmarks while remaining fully open source.
   → https://qwenlm.github.io/blog/qwen3/

2. LangChain Launches Agent Protocol Standard
   A new open standard for agent-to-agent communication gains
   adoption from 15 major frameworks in its first week.
   → https://blog.langchain.dev/agent-protocol/

3. EU AI Act Enforcement Begins for General-Purpose Models
   The first compliance deadlines hit, with open source models
   receiving exemptions under the 10M parameter threshold.
   → https://artificialintelligenceact.eu/updates/

---
3 stories • Sources searched: 8 • Generated by Hermes Agent
```

ถ้าใช้งานได้ คุณพร้อมที่จะทำให้มันเป็นอัตโนมัติแล้ว

:::tip ไล่แต่ง format ไปเรื่อยๆ
ลอง prompt หลายๆ แบบจนได้ output ที่คุณชอบ เพิ่มคำสั่งอย่าง "use emoji headers" หรือ "keep each summary under 2 sentences." อะไรก็ตามที่คุณตกลงใจใช้ จะถูกหอบไปใส่ใน cron job
:::

## Step 2: สร้าง Cron Job

ทีนี้มาตั้งเวลาให้มันทำงานเองทุกเช้า ทำได้สองวิธี

ก่อนสร้าง cron job ตรวจสอบให้แน่ใจว่า Hermes ตั้งค่า default model และ provider ไว้ระดับ global แล้ว ถ้าต้องการให้ job ใดใช้ค่าอื่น ให้กำหนด model/provider override แบบชัดเจนให้ job นั้นตอนสร้าง

### Option A: Natural Language (ใน chat)

แค่บอก Hermes ว่าคุณต้องการอะไร:

```
Every morning at 8am, search the web for the latest news about AI agents
and open source LLMs. Summarize the top 3 stories in a concise briefing
with links. Use a friendly, professional tone. Deliver to telegram.
```

Hermes จะสร้าง cron job ให้คุณผ่าน unified tool `cronjob`

### Option B: CLI Slash Command

ใช้คำสั่ง `/cron` เพื่อควบคุมได้ละเอียดกว่า:

```
/cron add "0 8 * * *" "Search the web for the latest news about AI agents and open source LLMs. Find at least 5 recent articles from the past 24 hours. Summarize the top 3 most important stories in a concise daily briefing format. For each story include: a clear headline, a 2-sentence summary, and the source URL. Use a friendly, professional tone. Format with emoji bullet points and end with a total story count."
```

### กฎทอง: Prompt ต้องพึ่งพาตัวเองได้

:::warning แนวคิดสำคัญ
Cron job ทำงานใน **session ใหม่ที่สะอาดเปล่า** — ไม่มีความจำจากบทสนทนาก่อนหน้าของคุณ ไม่มี context ว่าคุณ "เซ็ตอะไรไว้ก่อนหน้า" Prompt ของคุณต้องบรรจุ**ทุกอย่าง**ที่ agent ต้องการเพื่อทำงานนั้นให้สำเร็จ
:::

**Bad prompt:**
```
Do my usual morning briefing.
```

**Good prompt:**
```
Search the web for the latest news about AI agents and open source LLMs.
Find at least 5 recent articles from the past 24 hours. Summarize the
top 3 most important stories in a concise daily briefing format. For each
story include: a clear headline, a 2-sentence summary, and the source URL.
Use a friendly, professional tone. Format with emoji bullet points.
```

Good prompt ระบุให้ชัดเจนทั้ง **สิ่งที่ต้องค้น**, **จำนวนบทความ**, **format** และ **โทน** ครบทุกอย่างที่ agent ต้องการในครั้งเดียว

## Step 3: ปรับแต่ง Briefing

เมื่อ briefing พื้นฐานใช้งานได้แล้ว คุณสร้างสรรค์ต่อได้เต็มที่

### Multi-Topic Briefings

ครอบคลุมหลายเรื่องใน briefing เดียว:

```
/cron add "0 8 * * *" "Create a morning briefing covering three topics. For each topic, search the web for recent news from the past 24 hours and summarize the top 2 stories with links.

Topics:
1. AI and machine learning — focus on open source models and agent frameworks
2. Cryptocurrency — focus on Bitcoin, Ethereum, and regulatory news
3. Space exploration — focus on SpaceX, NASA, and commercial space

Format as a clean briefing with section headers and emoji. End with today's date and a motivational quote."
```

### ใช้ Delegation วิจัยแบบขนาน

อยากได้ briefing เร็วขึ้น ให้สั่ง Hermes delegate แต่ละหัวข้อไปยัง sub-agent:

```
/cron add "0 8 * * *" "Create a morning briefing by delegating research to sub-agents. Delegate three parallel tasks:

1. Delegate: Search for the top 2 AI/ML news stories from the past 24 hours with links
2. Delegate: Search for the top 2 cryptocurrency news stories from the past 24 hours with links
3. Delegate: Search for the top 2 space exploration news stories from the past 24 hours with links

Collect all results and combine them into a single clean briefing with section headers, emoji formatting, and source links. Add today's date as a header."
```

Sub-agent แต่ละตัวค้นข้อมูลอย่างอิสระและขนานกัน จากนั้น main agent จะรวบทุกอย่างเป็น briefing ชิ้นเดียวที่เรียบร้อย ดู [Delegation docs](/user-guide/features/delegation) สำหรับรายละเอียดว่ากลไกนี้ทำงานอย่างไร

### Weekday-Only Schedule

ไม่ต้องการ briefing ในวันหยุดสุดสัปดาห์? ใช้ cron expression ที่ระบุเฉพาะวันจันทร์-ศุกร์:

```
/cron add "0 8 * * 1-5" "Search for the latest AI and tech news..."
```

### Twice-Daily Briefings

รับภาพรวมยามเช้าและสรุปซ้ำยามเย็น:

```
/cron add "0 8 * * *" "Morning briefing: search for AI news from the past 12 hours..."
/cron add "0 18 * * *" "Evening recap: search for AI news from the past 12 hours..."
```

### เพิ่ม Personal Context ด้วย Memory

ถ้าคุณเปิดใช้ [memory](/user-guide/features/memory) คุณเก็บ preferences ที่คงอยู่ข้าม session ได้ แต่อย่าลืม — cron job ทำงานใน session ใหม่ที่ไม่มีความจำจากบทสนทนา วิธีใส่ personal context คือฝังมันลงใน prompt โดยตรง:

```
/cron add "0 8 * * *" "You are creating a briefing for a senior ML engineer who cares about: PyTorch ecosystem, transformer architectures, open-weight models, and AI regulation in the EU. Skip stories about product launches or funding rounds unless they involve open source.

Search for the latest news on these topics. Summarize the top 3 stories with links. Be concise and technical — this reader doesn't need basic explanations."
```

:::tip ปรับ persona ให้เข้ากับผู้อ่าน
การบอกรายละเอียดว่า briefing นี้*เขียนให้ใคร*ช่วยเพิ่มความตรงประเด็นได้อย่างมาก บอก agent เรื่องบทบาท ความสนใจ และอะไรที่ควรข้าม
:::

## Step 4: จัดการ Job ของคุณ

### ดูรายการ Job ทั้งหมดที่ตั้งเวลาไว้

ใน chat:
```
/cron list
```

หรือจาก terminal:
```bash
hermes cron list
```

คุณจะเห็น output ประมาณนี้:

```
ID          | Name              | Schedule    | Next Run           | Deliver
------------|-------------------|-------------|--------------------|--------
a1b2c3d4    | Morning Briefing  | 0 8 * * *   | 2026-03-09 08:00   | telegram
e5f6g7h8    | Evening Recap     | 0 18 * * *  | 2026-03-08 18:00   | telegram
```

### ลบ Job

ใน chat:
```
/cron remove a1b2c3d4
```

หรือพูดแบบสนทนา:
```
Remove my morning briefing cron job.
```

Hermes จะใช้ `cronjob(action="list")` ค้นหา และ `cronjob(action="remove")` ลบมันทิ้ง

### ตรวจสอบสถานะ Gateway

ตรวจสอบว่า scheduler ทำงานอยู่จริง:

```bash
hermes cron status
```

ถ้า gateway ไม่ได้รันอยู่ job ของคุณจะไม่ถูก execute ติดตั้งเป็น background service เพื่อความน่าเชื่อถือ:

```bash
hermes gateway install
# or on Linux servers
sudo hermes gateway install --system
```

## ก้าวต่อไป

คุณได้ daily briefing bot ที่ใช้งานได้จริงแล้ว ทิศทางที่น่าสำรวจต่อมีดังนี้:

- **[Scheduled Tasks (Cron)](/user-guide/features/cron)** — ข้อมูลอ้างอิงครบถ้วนเรื่องรูปแบบตารางเวลา ขีดจำกัดการทำซ้ำ และตัวเลือกการส่งมอบ
- **[Delegation](/user-guide/features/delegation)** — เจาะลึก workflow sub-agent แบบขนาน
- **[Messaging Platforms](/user-guide/messaging)** — ตั้งค่า Telegram, Discord หรือปลายทางการส่งมอบอื่น
- **[Memory](/user-guide/features/memory)** — context ที่คงอยู่ข้าม session
- **[Tips & Best Practices](/guides/tips)** — เคล็ดลับ prompt engineering เพิ่มเติม

รูปแบบ briefing bot ใช้ได้กับแทบทุกอย่าง: การเฝ้าดูคู่แข่ง สรุป GitHub repo พยากรณ์อากาศ ติดตามพอร์ตโฟลิโอ ตรวจสุขภาพเซิร์ฟเวอร์ หรือแม้แต่มุกประจำวัน ถ้าคุณอธิบายมันเป็น prompt ได้ คุณตั้งเวลามันได้
:::
